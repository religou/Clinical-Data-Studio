# ADR-0003：产品定位转向临床试验数据质量管理平台

- 状态：已接受
- 日期：2026-11-02
- 取代：ADR-0001、ADR-0002

## 背景

本仓库原定位为面向单一组织的数据治理平台（API 资产目录、数据资产目录、业务术语与数据标准、数据质量闭环），见旧版 `CONTEXT.md` 与 ADR-0001、ADR-0002。

经确认（决策 5C / 6A / 12A），产品定位整体转向**对标 Medidata Clinical Data Studio 的临床试验数据质量管理平台**，覆盖多源数据接入、数据审阅、RBQM、信号检测、审计追踪审阅、医学监查与方案偏离管理。

## 决策

1. 产品名沿用 **DataStudio**，定位改为 CDS 类临床试验数据质量管理平台。
2. 旧的数据治理方向（API 资产 / 数据资产 / 业务术语 / 数据标准 / 血缘）**整体放弃**。
3. 旧版 `CONTEXT.md` 内容**永久删除**，由新定位整体覆盖（该目录非 git 仓库，此删除不可恢复，已确认）。
4. 功能需求以 `docs/requirements/medidata-cds-frd.md` 为准；领域词汇以根 `GLOSSARY.md` 为准。
5. ADR-0001、ADR-0002 标记为被本 ADR 取代，保留其记录价值。

## 影响

- 所有基于原数据治理方向的既有设计、术语与验收指标失效。
- 平台主体能力从"元数据治理"转为"临床数据审阅与风险监测"，数据来源、合规约束（GxP/21 CFR Part 11/ICH E6(R3)）与角色模型随之改变。
- 本文档为"基于公开资料重建"，公开信息未覆盖处标注为假设，需后续评审确认。
