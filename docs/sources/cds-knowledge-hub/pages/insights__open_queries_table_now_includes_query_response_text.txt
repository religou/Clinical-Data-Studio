# Insights: Open Queries Table Now Includes Query Response Text

## Insights: Open Queries Table Now Includes Query Response Text
## What Is New?
 The Insights > Open Queries > Open Query Records table and corresponding export file include the following new column:
- Response Text – The site's response to the query. 
## What Is the Impact?
## Users/Roles
 Data managers
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 In previous releases, you had to access individual queries in Rave EDC to read and review the sites' query responses. Now you can quickly and easily view the site responses to all open and answered queries consolidated in one central location.
## Where Do I See the Change?
 You can find the Response Text column in the:
- Insights > Open Queries page > Open Query Records table 
- Open Query Records export file 
## Where Do I Learn More?
 Use the following links to find new and updated content in support of this enhancement:
- View Open and Answered Query Records 
## What Else Should I Know?
 You cannot filter or sort the Open Query Records table by the Response Text column.
