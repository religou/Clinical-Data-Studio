# CSM: Download Rounding Events and Propagation Events Summary Lists

## CSM: Download Rounding Events and Propagation Events Summary Lists
## What Is New?
 You can download the: 
- Rounding Events Summary list 
- Propagation Events Summary list 
- Rounding Events Summary > Patients with Record Events list, and 
- Propagation Events Summary > Patients with Record Events list 
 to a CSV file. 
## What Is the Impact?
## Users/Roles
 Central monitors
## Workflow Process
 No impact to the workflow process. 
## Other Applications
 No impact to other applications. 
## How Do I Benefit?
 Downloading the Rounding Events Summary lists and the Propagation Events Summary lists enables you to:
- Easily exchange the lists externally with stakeholders to facilitate communication. 
- Locally save and archive the lists. 
## Where Do I See the Change?
 On the:
- Centralized Statistical Monitoring (CSM) > Data Veracity > Rounding and Propagation page > Rounding Events tab > Rounding Events Summary section >  
- Centralized Statistical Monitoring (CSM) > Data Veracity > Rounding and Propagation page > Rounding Events tab > Rounding Events Summary section > Patients with Record Events table, 
- Centralized Statistical Monitoring (CSM) > Data Veracity > Rounding and Propagation page > Propagation Events tab > Propagation Events Summary section, and 
- Centralized Statistical Monitoring (CSM) > Data Veracity > Rounding and Propagation page > Propagation Events tab > Propagation Events Summary section, Patients with Record Events table. 
 you can click the Download button. The file opens locally on your machine as a CSV file.
