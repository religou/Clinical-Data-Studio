# Clinical Data Studio Releases History

## Clinical Data Studio Releases History
 The following lists all Clinical Data Studio releases (up to and including the current release) and the features or enhancements introduced in each.
 Important: Release Notes Title Update
 As of 23-May-2025 , the Clinical Data Studio release notes document title format is changed from:  Clinical Data Studio <Month> <Year> Release Notes to: Clinical Data Studio <Release Version Number> <Release Type> Release Notes. 
 Important: Clinical Data Studio Release Notes Rebrand and Structure
 Clinical Data Studio comprises three capability suites: 
- Data Surveillance
- RBQM
- Data Connect
 The former Medidata Detect Release Notes previously documented updates to the capabilities that are now provided in Data Surveillance and RBQM capability suites. Therefore, as of Jun-26-2024, the former Medidata Detect Release Notes are now rebranded to the Clinical Data Studio Release Notes. Meanwhile, updates provided in the Data Connect capability suite are documented in a separate release notes document, the Data Connect Release Notes. 
 Important: All Former Detect Module Release Information Previously Consolidated in One Release Notes Document
 Prior to the Medidata Detect November 2022 release, the former Detect modules of Detect Landing Page, Patient Profiles, Data Reviewer, Centralized Statistical Monitoring, and Detect Configuration Manager were each released as separate products with their own sets of release notes. As of Nov-18-2022, all release notes content for all former Detect modules—that is, Detect Landing Page, Patient Data Surveillance, Centralized Statistical Monitoring, Quality Tolerance Limits, Key Risk Indicators, Utilities, and Detect Configuration Manager—became documented under one release notes document per release beginning with the Medidata Detect November 2022 Feature Release Notes. 
 To view released features prior to the Medidata Detect November 2022, see:
- Detect Landing Page Releases History 
- Data Reviewer Releases History 
- Patient Profiles Releases History 
- Centralized Statistical Monitoring Releases History 
- Detect Configuration Manager Releases History 
 Prior to the Medidata Detect March 2023 release, Risk Management was released as a separate product with its own set of release notes. As of Mar-14-2023, all release notes content for Risk Management became documented under the consolidated release notes beginning with the Medidata Detect March 2023 Release Notes.
 To view released features prior to the Medidata Detect March 2023, see:
- Risk Management Released Features 
 Code Continuity Across Releases
 All Clinical Data Studio releases are cumulative.  That is, each release or software update builds on prior releases as noted in the release notes. For example, Software Update 2020.2.1  includes all of the release   2020.2.0 code, which in turn is based on the  release  2020.1.0 code and so on. The release notes describe any updates between releases or s oftware updates (urgent or otherwise)
