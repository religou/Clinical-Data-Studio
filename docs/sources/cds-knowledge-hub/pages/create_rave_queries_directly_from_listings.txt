# Create Rave Queries Directly from Listings

## Create Rave Queries Directly from Listings
## Description
 You can create Rave queries directly from listings in Data Reviewer. You can select and submit Rave queries for all or some of the records in listings.
## Affected Roles
 All Detect users with access to Rave and Data Reviewer.
## Advantages
 You can save time by creating and posting queries in Rave directly from Data Reviewer. For example, you can now create multiple queries to submit to Rave manually in under a minute, compared to five to seven minutes previously. Similarly, you can review data and generate queries per review cycle in less than one day per person compared to one to two weeks by multiple reviewers.
## User Impact
 On the Data Reviewer > Listings tab, you can build listings.

 If you click Preview while building a listing:
- The listing shows all search results as per the selected variables. 
- The listing saves and appears in the Listing tab when you click Save . 
 Note - You must preview and save to create a listing. You can build a listing without creating a Rave query .
 For a saved listing :
- If you click Submit Queries at the top of the listing, a window shows a list of records with saved queries that you want to submit to Rave for that listing. 
- Each record includes a selection option, the Patient ID, Site, Country, Status, Query Text, Folder, Form, and Field details. 
- If you click Submit , the queries submit to Rave. 
- Records with an existing Rave query contain a icon in the Status column.

## Special Considerations
- You can create Rave queries for only data set variables from Rave and not from derived variables or third-party ingested data or variables that have suffixes, such as  _INT, _TXT . 
- If you create a Rave query with a variable used in the expression builder for the listing, the Folder dropdown includes an additional option: Derived by Expression. 
- You must configure studies in Rave with the marking group Site from DM to create Rave queries from listings.
