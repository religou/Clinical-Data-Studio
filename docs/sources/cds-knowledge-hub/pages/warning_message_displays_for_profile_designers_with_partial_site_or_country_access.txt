# Warning Message Displays for Profile Designers with Partial Site or Country Access

## Warning Message Displays for Profile Designers with Partial Site or Country Access
## Description
 Profile Designers with partial or no access to sites or countries see a warning message when accessing the Design page > Profiles tab. If you have the correct access, no warning message appears.
## Affected Roles
 Patient Profile Designers.
## Advantages
 Using the IDs displayed in warning messages, patient profile designers can contact support to arrange the correct access.
## User Impact
 See Description.
