# Listings: Updated Data Set Variable Types Enable Better Listings and Query Submission Experience

## Listings: Updated Data Set Variable Types Enable Better Listings and Query Submission Experience
## What Is New?
 Listings and Rave-enabled queries now maintain the correct integer, boolean, and float type data set variables in all operations, including listing previews, approved listings, query submissions, and listing results display. Listings also now include date time data set variables. 
## What Is the Impact?
## Users/Roles
 Data managers.
## Workflow Process
 No impact to workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 With accurate data set variable classification and date time variables, data managers can build listings with greater flexibility ensuring study data integrity and accuracy.
## Where Do I See the Change?
 On the Data Surveillance > Listings page > if you click Create Listings , and select a dataset in the expression builder, for example, an audit dataset, datetime variables appear for selection. For date time variable formats supported in Data Surveillance and RBQM see Date Time Variable Formats . Date time variables include operations such as:
- Not Equals (`!=`) 
- Less than (<) 
- Greater than (>) 
- Less than equals to (<=) 
- Greater than equals to (<=) 
- Is Missing. 
- Is Not Missing. 
- Comparison between two date time variables.

 In the Listings expression builder:
- The Equal to ( =) operation is not available for date time variables. 
- The Enable Query option remains disabled if you select a queries dataset.
