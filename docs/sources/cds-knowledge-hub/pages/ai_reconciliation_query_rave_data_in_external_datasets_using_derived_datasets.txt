# AI Reconciliation: Query Rave Data In External Datasets Using Derived Datasets

## AI Reconciliation: Query Rave Data In External Datasets Using Derived Datasets
## What Is New?
 You can now submit queries for externally coded study records that become derived datasets , in AI Reconciliation. 
## What Is the Impact?
## Users/Roles
 Data managers.
## Workflow Process
 No impact to workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 While reviewing reconciliation reports, data managers can raise queries on derived datasets where source variables originate from Rave EDC. This results in faster data reviews and improves data quality. 
## Where Do I See the Change?
 On the Data Surveillance tab > Reconciliation > Conditions or Treatments card > if you select a report, and select a few records, then click Submit Query , the Submit Queries page lists all the selected events. You can then submit a query for the selected events consisting of derived datasets, after selecting a marking group. The Submit Query button remains disabled if the Reconciliation report consisting derived datasets do not contain a Rave data set as source.
