## Change Details
 Product

 Version

 Change Type 
 | Enhancement (Updated Functionality)
 Functionality or Module

 Summary of Changes 
 | 
 As highlighted in the Release Newsletter :   
 In Signals, the Create CTMS Issue window shows an updated user interface with fields indicating none, one, or multiple sites.
 Benefit to Users 
 | Central Monitors can create actionable issues for signals, track, and assign them to personnel based on site information for resolution. This ensures potential issues get checked in time and do not threaten study data integrity.   
 Summary of User Impact 
 | 
 Impact to Users and Roles 
- Central Monitors and Central Statistical Monitors, Clinical Research Associates 
-  Users with View Signals and Manage Signals building blocks. 
 Impact to Workflow Processes 
 No change to workflow processes.
 Impact to Applications 
 No impact to other applications.
 Impact on Interface 
 For both Protocol Deviation (PD) and Non-Protocol Deviation (Non-PD) issues that you raise for signals and choose to resolve with an external issue management system like Rave CTMS, t he Create CTMS Issue page includes a new Issue assignment section that includes site and assignee fields.  
 The page also includes a Category dropdown where you can select the issue category. 
- Non-PD Issue 
- Protocol Deviation issue 
 Impact to Existing Data or Settings 
 No existing data changes; no configuration or permission updates required.
