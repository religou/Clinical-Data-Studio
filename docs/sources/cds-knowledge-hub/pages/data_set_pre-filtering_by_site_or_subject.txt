# Data Set Pre-Filtering By Site Or Subject

## Data Set Pre-Filtering By Site Or Subject
## Description
 In the Data Viewer tab, you can now pre-filter data set variable data by Site Number or Subject ID. The filtering works on full or partial number strings, and shows corresponding study data for data sets with over 50,000 records. 
## Affected Roles
 All roles with the View Data building block. 
## Advantages
 With the the updated filtering options, you can efficiently locate records of interest from a study. 
## User Impact
 In the Data Viewer tab, after a selected data set with over 50,000 record loads, you can use the View menu to pre-filter by Subject ID or Site Name. The filter response differs slightly depending on the selected parameter: 
- If you select Subject ID in the View field and enter the first three characters in the field, the list shows records that include study data with the Subject ID. For example, if you enter 100, the list shows 11371001, 10031023 and so on. You can apply the Column Filter to all columns, except Subject ID. The data set shows records corresponding to the Subject ID you select. 
- If you select Site Name in the View field and enter the first three characters in the   field, the list shows records that include study data with the Site Name. For example, if you enter 100, the list shows 1001, 3100 and so on. You can apply the Column Filter to all columns, except Site Name. The data set shows records corresponding to the Site Name you select.  
## Special Considerations
 None.
