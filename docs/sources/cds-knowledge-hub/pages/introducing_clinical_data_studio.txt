# Introducing Clinical Data Studio

## Introducing Clinical Data Studio
## What Is New?
 Clinical Data Studio is a complete data management tool that provides access to integrated data from Medidata and external sources, using AI to streamline data aggregation, standardization, and management workflows. With Clinical Data Studio, clinical or IT programmers, clinical data management, and clinical operations roles can act on data instantly to reduce user burden, shorten operational timelines, and increase data quality.
 The software capabilities that comprised the former Medidata Detect solution are now part of Clinical Data Studio. Clinical Data Studio includes redesigned and rebranded Detect capabilities available as part of two offerings: Medidata Data Surveillance and Medidata Data Quality Management. 
- Medidata Data Surveillance – Includes the following capability suites:
- Data Surveillance – Provides a drag-and-drop listings builder, automated query generation for Rave EDC-sourced data and issue management for non-Medidata sourced data, AI-powered data reconciliation, patient profiles, and visualizations. Data Surveillance includes the following capabilities:
- Clean Patient Tracker 
- Data Sets 
- EDC Queries  
- Vendor Queries (formerly known as Vendor Issues) 
- Listings 
- AI Reconciliation 
- Patient Profiles 
- Visualizations 
- Oncology 
- Configuration 
- Library 
- Data Connect – Enables self-service data ingestion and no/low-code data transformation capabilities.  
- Medidata Data Quality Management – Includes all the Data Surveillance capabilities above, plus the RBQM capability suite, which provides risk surveillance capabilities supporting a holistic risk-based quality management (RBQM) approach to data quality. RBQM includes the following capabilities: 
- 
- Summary 
- Risk Assessment 
- Risks 
- KRIs 
- QTLs 
- Statistical Monitoring (formerly known as Detect CSM) 
- Configuration 
- Library 
 Tip : For former Medidata Detect users, to learn how Medidata Detect's features and functionalities have been redesigned and reorganized in Data Surveillance and RBQM, see the table describing the differences in the Where Do I See the Change section .
 Note : All your existing permissions in iMedidata and former Detect capabilities remain the same in Clinical Data Studio.

## Other Applications
 Clinical Data Studio also includes an offering, Data Connect , which enables you to import and transform data for use in Data Surveillance and RBQM. 
 Note : Some users may continue to upload study data through Ingestor for use and analysis in Clinical Data Studio. 
 How Do I Benefit? 
 With Clinical Data Studio. you can:
- Ingest any data quickly and easily – CDS provides access to data from Medidata data sources, such as Rave EDC and simplifies importing data from any external source, such as labs or another EDC system. You can configure data transfer agreements into CDS to validate ingested data automatically. 
- Transform Data with Minimal Effort – With Clinical Data Studio, clinical data managers can build complex listings across multiple datasets without the need for programming. Clinical programmers and biostatisticians can use Clinical Data Studio’s no/low-code data transformation capabilities to create custom datasets. Clinical Data Studio maintains complete traceability of all data transformations so you can always see what and how data transformed. 
- Achieve High-Quality Data Faster – Clinical Data Studio delivers accelerated review of data and patient profiles, visualizations, AI-assisted data reconciliation, risk management, site performance monitoring, issue management, anomaly detection, and patient safety overview. 
- The Medidata Advantage – Clinical Data Studio delivers a unified data management and analytics experience for all users, powered by AI and advanced analytics.
