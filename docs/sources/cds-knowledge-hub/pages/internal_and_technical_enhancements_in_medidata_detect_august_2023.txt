# Internal and Technical Enhancements in Medidata Detect August 2023

## Internal and Technical Enhancements in Medidata Detect August 2023
## What Is New?
 Medidata Detect August 2023 includes the following internal and technical enhancements:
- The Detect Landing Page > Risk Management card uses a new data source to pull in the count of overdue risk reviews. 
- The Template Library page > Help menu now includes a Help on This Page option, which navigates you to the Detect Templates Knowledge Hub article. 
- When creating template groups in the Template Library, Detect shows an error message and prevents you from saving if you enter a Group Name or Description exceeding 65 or 500 characters, respectively. 
- The Patient Profiles code updates improve internal performance.

## Where Do I See the Change?

- The Template Library page > Help menu > Help on This Page option. 
- The Template Library page > Template Group window > Group Name field and Description field.
