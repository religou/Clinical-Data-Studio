# Configuration and Reporting: Minor Detect Configuration Manager Enhancements for November 2023

## Configuration and Reporting: Minor Detect Configuration Manager Enhancements for November 2023
## What Is New?
 Detect Configuration Manager includes the following minor enhancements:
- When you click on the Save button for QTLs and KRI configurations multiple times, the configuration is saved only once. 
- When you hover over a QTL name with Active status, the following information shows as hover text:
- "Number of subjects that met QTL out of subjects that the QTL has been calculated against", and 
- "Subjects that met the QTL flag out of total population", that is, Numerator count out of Denominator count, for example, 265 out of 2899 subjects. 
- The App title on the browser now shows KRI Configuration and QTL Configuration, respectively, for each app. 
- When importing templates in KRI Configuration, the Import Templates window > Templates list > Type column shows Numeric for custom numeric KRIs instead of Custom.
