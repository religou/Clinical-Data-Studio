# PDS: Minor Data Reviewer Enhancements for November 2023

## PDS: Minor Data Reviewer Enhancements for November 2023
## What Is New?
- On an approved listing's results table and an AI Data Reconciliation report's table, when you use the table's page navigation, you can filter for Patient ID on all pages. 
- When submitting queries on approved data listings or on AI Data Reconciliation report findings, on the Edit Query window:
- The font used for the Form menu's selected option matches the list of selectable menu options. 
- The Query Text field now has an 500 character limit, and shows the number of characters entered against the character limit. 
- When you create new data listings by importing from a data listing template, the imported listing uses the original template name unless otherwise changed. 
- The AI Data Reconciliation Refresh button always shows on the page even if there is no new data available. 
- Clean Patient Tracker discontinues tracking:
- Deactivated data listings. 
- Edited approved data listings, which after editing and saving, revert to draft status.
