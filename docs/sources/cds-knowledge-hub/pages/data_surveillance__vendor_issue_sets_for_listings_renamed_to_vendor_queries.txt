# Data Surveillance: Vendor Issue Sets for Listings Renamed To Vendor Queries

## Data Surveillance: Vendor Issue Sets for Listings Renamed To Vendor Queries
## What Is New?
 The Vendor Issue Sets page is now renamed to Vendor queries. The page includes additional vendor query status cards showing the count of queries in each state at the top of the page. The Vendor Issues page is now renamed as Submit Vendor Issues. Downloaded vendor query sets include fields corresponding to the vendor query status.
## What Is the Impact?
## Users/Roles
 Study Managers and Data Managers.
 All users with Submit Vendor Issues and Manage Issue Sets access. 
## Workflow Process
 No impact to workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Data managers can reconcile vendor data faster by checking submitted and unsubmitted vendor queries.  
## Where Do I See the Change?
 On the Patient Data Surveillance > Vendor Queries page: 
- Vendor Query Status Cards appear at the top of the page, showing the number of queries in each stage: 
- All 
- The Not Submitted card is now renamed to Draft. 
- Submitted 
- In-progress 
- Completed 
- The vendor query set table includes the following columns: 
- Query Set Name 
- Vendor 
- Status 
- Sent 
- Due 
- Completed 
- Completion Comments 
- Count 
- The Status column shows any of the following: 
- Submitted 
- In-progress 
- Completed 
- Each vendor query includes the following fields:
- Patient 
- Site 
- Country 
- Listing 
- Status 
- Vendor Response 
- Vendor Query 
- Query Description 
- EDC Data 
- Vendor Data 
 If you click the vendor query set hyperlink, all the vendor queries in the set appear. You can click each set to show a slide-out panel with the query and vendor details. The query status shows at the top of the page. Unselected queries get deleted from the query set when you submit a vendor query set. When you submit a vendor query set, a notification with the query set to the vendor's email. When you download vendor query sets, the file includes columns and fields corresponding to the vendor query status. You can search the vendor query sets using the Search option above the table.

## What Else Should I Know?
- To access Vendor Queries, you must have the Submit Vendor Issues and Manage Issue Sets building blocks associated with your role in the Cloud Administration study group. 
- The Status and Vendor Response columns do not appear for vendor queries in draft state.
