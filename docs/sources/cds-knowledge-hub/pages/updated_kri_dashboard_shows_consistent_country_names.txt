# Updated KRI Dashboard Shows Consistent Country Names

## Updated KRI Dashboard Shows Consistent Country Names
## What Is New?
 The updated KRI Dashboard ensures country names displayed in the Country dropdown match those shown in the KRI table.
## What Is the Impact?
## Users/Roles
- Site Monitor 
- Study Manager 
## Workflow Process
 No impact to the workflow process.
## Other Applications
 None impact to other applications.
## How Do I Benefit?
 Site monitors and study managers can filter study data by country easily to review KRIs of interest.
## Where Do I See the Change?
 On RBQM > KRIs > KRI Dashboard, if you select View by Country, country names appear consistent in the dropdown and the KRI table.
