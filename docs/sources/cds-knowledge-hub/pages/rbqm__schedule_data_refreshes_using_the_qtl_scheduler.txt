# RBQM: Schedule Data Refreshes Using the QTL Scheduler

## RBQM: Schedule Data Refreshes Using the QTL Scheduler
## What Is New?
The Clinical Data Studio - QTLs capability includes a QTL Scheduler button which you can use to 
 schedule study data refreshes and perform on-demand data refreshes. The QTL Scheduler page no longer exists in Clinical Data Studio. 
## What Is the Impact?
## Users/Roles
 Users with the Manage QTL Scheduler role. 
 Workflow Process 
 No change in workflow.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Administrators can schedule data refreshes at appropriate times/intervals so that the study shows the most recent QTL data.
## Where Do I See the Change?
 On RBQM > Configuration > QTL Dashboard, the QTL Scheduler button appears on the top right corner of the page.
