# Save and Reuse Custom QTL Configurations as Templates

## Save and Reuse Custom QTL Configurations as Templates
## What Is New?
 You can now create and reuse QTL configuration templates. 
- Reuse existing configuration templates across studies within the same study environment. 
- Edit checks before saving to validate whether the variable is part of a study environment. 
- Use   Export as Template when  you open an existing Percentage QTL Configuration. 
- Use the Import Template button on the   QTL listing page. 
- View all the details associated with a selected Template Group on the Import Templates page. 
- View all the templates associated with a Template Group on the Import Templates page. 
- Import a QTL template to open a QTL configuration. 
## What Is the Impact?
## Users/Roles
 All who can create or update a QTL configuration. 
## Workflow Process
 No impact to the workflow process. 
## Other Applications
 No impact to other applications. 
## How Do I Benefit?
- You can now repurpose configuration templates from other studies within your client division. 
- No need to create QTL configurations from scratch, thus saving time . 
 Where Do I See the Change? 
- QTL Configuration > click Import Template > Template Library 
- QTL Configuration > click Export Template > Export Template popup. 
## Where Do I Learn More?
 The Detect Knowledge Space provides new and updated content to support this feature/enhancement:

- Add Listings, Custom KRIs, and QTLs as Templates to Template Groups

## What Else Should I Know?
- You cannot save templates with the same template name, within the same template group, in the same study. 
- You can save templates with the same template name, within different template groups, in the same study.
