# Visualizations: Additional Aggregations Available For All Charts

## Visualizations: Additional Aggregations Available For All Charts
## What Is New?
 You can now add aggregations to the X and Y axis such as minimum, maximum, and mode values, for all visualizations except tabular charts. For bar charts, you can also add a median line.
 You can now view a median line on Data Surveillance > Visualizations > Bar Charts that represents a visual reference of the aggregations done in the bar chart configuration. If you click the Add median line option, the bar chart includes a median line.
## What Is the Impact?
## Users/Roles
 All study team members. 
## Workflow Process
 No impact to workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Data managers can perform better statistical analysis with minimum, maximum, and mode aggregations, viewing the visual representation in charts, and using the data from the summary tables across study data. With the median line, you can easily locate medium values for data represented in bar charts and take action as required.
## Where Do I See the Change?
 On the Data Surveillance > Visualizations page > if you click Create Visualizations, then select any chart type (except tabular charts), and drag and drop Y-axis variables, you can then select Min, Max, Mode options to add aggregations as per these mathematical operations.
- Min – For example, if you select Min for Age by Site variable, then the chart Y axis shows the calculated minimum age for each site. If you select Min for Age by Site by Sex, the chart shows calculated minimum age for each by sex. The minimum value also appears in the summary table.  
- Max – For example, if you select Max for Age by Site variable, then the chart Y axis shows the calculated maximum age for each site. If you select Max for Age by Site by Sex, the chart shows calculated maximum age for each by sex. The maximum value also appears in the summary table. 
- Mode – For example, if you select Mode for Site variable, then the chart Y axis shows the age value that occurs the most out of all the patients at any given site. The mode value also appears in the summary table. 
 You can now view a median line on Data Surveillance > Visualizations > Bar Charts that represents a visual reference of the aggregations done in the bar chart configuration. If you click the Add median line option, the bar chart includes a median line.
