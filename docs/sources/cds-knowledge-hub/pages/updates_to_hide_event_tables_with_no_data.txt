# Updates to Hide Event Tables With No Data

## Updates to Hide Event Tables With No Data
 Description 
 Event tables with the Hide "No Data" Elements option selected display only if the event tables have data present in a profile design. Also, conditional formatting works as expected in event tables and timelines. 
## Affected Roles
 All. 
## Advantages
 Patient Profiles design reviewers can arrange a patient's profile to hide unneeded data, which reinforces a more targeted data analysis.
