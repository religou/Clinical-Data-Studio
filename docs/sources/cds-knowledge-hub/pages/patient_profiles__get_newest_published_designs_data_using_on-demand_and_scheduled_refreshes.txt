 Impact to Workflow Processes 
- Scheduled refreshes operate on daily, weekly, biweekly, monthly, bimonthly, and quarterly cadences . 
- Patient Profiles allow up to two successful refreshes per day . 
- Conflict prevention rules block multiple on-demand refreshes for the same module on the same snapshot, and block on-demand refreshes while scheduled refreshes run . That is, a record selected for a scheduled refresh is not available for on-demand refresh selection. 
- You can export current refresh configurations into a downloadable PDF report through the Notification Center . 
 Impact to Applications 
- Profile designs included in Unified Scheduler refresh data independently, however a record is available in either a scheduled or on-demand refresh, not both. 
 Impact on Interface 
 On the Data Surveillance > Patient Profiles > Published Designs tab, you can find the following updates.
 On-demand refreshes 
 Refresh – If you click the Refresh button on the top right corner of the page, you can select a published profile design for an on-demand refresh. You can refresh any patient profile design up to a maximum of 2 times per day. The Refresh button remains disabled if the patient profile design uses the latest data snapshot.
 Note : The On-demand refresh page does not show profile designs that currently have a refresh in progress, or are part of a scheduled refresh, or have been recently refreshed and have the most updated data snapshot.
 Scheduled Refreshes 
 View Refresh Schedule  – On the Data Surveillance > Patient Profiles page, if you click the  View Refresh Schedule button, the Unified Scheduler page appears, showing all Patient Profiles refresh schedules for published designs. For more information, see Data Surveillance Configuration: Schedule Data Refreshes Using Unified Scheduler .  
 Note : On the Data Surveillance > Patient Profiles page, you can select any published profile design. If you  click , More icon, and then History , the page shows both on-demand and scheduled refreshes. The refresh table shows the following fields: 
- Refresh Date 
- Refresh Type 
- Snapshot Date 
- Refreshed By 
 If you click Download, you can download the refresh history for the profile design.
 Impact to Existing Data or Settings 
- Neither scheduled nor on-demand data refreshes interfere or break existing schedules.  
- For patient profile designs, records selected for a scheduled data refresh do not appear for selection in on-demand refreshes. The reverse is also true.
