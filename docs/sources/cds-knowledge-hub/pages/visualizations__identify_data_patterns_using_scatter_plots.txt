## Change Details
 Product 
 | Clinical Data Studio
 Version 
 | 2026.1.0
 Change Type 
 | Feature (New Functionality)
 Functionality or Module 
 | Visualizations
 Summary of Changes 
 | 
 As highlighted in the Release Newsletter :  
 Data Surveillance > Visualizations include a new chart type, namely scatter plots that you can use to chart the relationship between two, continuous numerical variables.  The x-axis typically represents the independent variable, while the y-axis represents the dependent variable, with each dot showing the intersection of these two values for a single data point. 
 Benefit to Users 
 | Using scatter plots, study team members can  identify patterns, trends, correlations, and outliers within the data. 
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 Data Managers, and users with the Manage Visualizations building block. 
 Impact to Workflow Processes 
 No impact to the workflow.
 Impact to Applications 
 No impact to other applications.
 Impact on Interface 
 If you click Create Visualization, the Chart Configuration section includes a new  icon, which you can click to create scatter plots. If you click scatter plot, the Visualization page shows the configuration fields, x-axis, and y-axis, which only accept numeric variables. 
 Impact to Existing Data or Settings 
 No existing data changes; no configuration or permission updates required.
 User Impact Assessment 
 | High 
 Learning Resource Updates 
 | The following lists any new or added resources that support this change: 
- Updated Article: Create, Edit, and Delete Visualizations . 
 Special Considerations 
 | Scatter plots only work for integer or float type variables, and do not support any aggregations.
