# Create And View Listings

## Create And View Listings
## Description
 Data managers frequently search for specific patient data within a study; for example, all female patients who have had a serious adverse event. In Data Reviewer, you can now search across data sets and save search criteria as Listings. With Listings you can:  
- Use the expression builder to filter patient data from a single data set. 
- Build and save selection criteria and access the listing when required. 
## Affected Roles
 All roles with the View Data building block. 
## Advantages
 With listings, you can search across data sets to check the patient data you need and take appropriate action. For example, data managers frequently search for specific patient data within a study; such as: all female patients who have had a serious adverse event.

## Special Considerations
 For a listing on the Listing page: 
- You can further filter and sort data by applying column filters to the preview table and saved listings table.  
- You can reposition data set variables for a selected data set by dragging and dropping column headers. 
- As you scroll horizontally through a listing, the Patient ID, Site, and Country columns remain visible as the first three columns of the table. 
 For listings on the Data Viewer page: 
- You can access saved listings by clicking Listings, and then selecting a listing on the left side panel. You can edit a saved listing by selecting the listing on the left side panel and then clicking Edit Listing . You can also create listings by clicking the New Listings button.
