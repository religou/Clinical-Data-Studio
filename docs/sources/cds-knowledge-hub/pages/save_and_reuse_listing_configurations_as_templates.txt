# Save and Reuse Listing Configurations as Templates

## Save and Reuse Listing Configurations as Templates
## What Is New?
 You can now save the Client Division (CD) listing configuration with the aid of:
- An Import Template button on the Data Listings-Draft Listings page.
- When you click Import Template, a pop up opens which allows you to select a Template group, and view the other templates available for that Template Group. This allows you to import selected listings. 
- Each imported listing shows an icon next to its name that indicates that it is imported. 
- You can edit the imported listings. 
- An Export as Template button on the Listing Manager page. 
- Each row in the Listing Manager is selectable. 
- When you click Export as Template, an Export as Template pop up opens, which allows you to select a Template group from the Client Division level, and Export that template.  
## What Is the Impact?
## Users/Roles
 All who can create or update a listing configuration. 
## Workflow Process
 No impact to the workflow process. 
## Other Applications
 No impact to other applications. 
## How Do I Benefit?
- You can now repurpose configuration templates from other studies within your client division. 
- Create configurations from scratch, thus saving time. 
## Where Do I See the Change?
- Data Reviewer > Data Listings > Draft Listings > click Import Template. 
- Data Reviewer > Listing Manager > select a listing > click Import as template.

## What Else Should I Know?
- The name of the template group and template name must be unique. 
- Only users with access to the Global Template Library are allowed to export or add templates to the Global Template Library. 
- Only users with manage_global_templates and manage listings permissions can see the Export button in Manage Listings.
