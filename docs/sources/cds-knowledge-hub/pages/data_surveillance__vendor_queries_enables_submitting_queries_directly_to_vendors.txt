# Data Surveillance: Vendor Queries Enables Submitting Queries Directly To Vendors

## Data Surveillance: Vendor Queries Enables Submitting Queries Directly To Vendors
## What Is New?
 You can now submit queries for issues with vendor data directly to external vendors. Vendors can access and respond to the queries through the Notification Centre.
## What Is the Impact?
## Users/Roles
 All vendors with the Submit Vendor Feedback role.
 Data managers.
## Workflow Process
 Data managers review listings to identify issues with vendor data and submit the query set to the vendor. Vendors receive an email with a hyperlink to access the Clinical Data Studio notification centre. Vendors then add comments, update query status, provide clarification for the queries in the notification centre. The query set gets updated with the vendors' response for further data manager review.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Vendors and data managers have a clear, two way communication channel to clarify questions related to external data. Data managers can send queries directly to vendors for clarification and feedback, enabling faster reconciliation for vendor or external data in listings.  
## Where Do I See the Change?
 Listings page 
 On the Data Surveillance >Vendor Queries page, if you select queries and then click Submit Vendor Queries , the query set shows all the selected queries on the Add Vendor Queries page. If you then complete all the query fields and save the query set, and appears on the Vendor queries page.
 Vendor Queries page 
 If you search the query set, then click the query set name hyperlink, the query set shows a list of all the queries added. The query set is in draft state. You can edit the queries in the query set. You can also download the query set. If you add a due date and then click Submit to vendor , the query set is submitted to vendor group you select. The vendor receives an email with a hyperlink to access the query set from the Notification Centre. The query set status changes to submitted once you click Submit to vendor .

 Notification Centre 
  The vendor can click View in Notification Centre to view the query set message. Image A shows a sample notification. The vendor can respond to the queries, provide comments and update the query status for each individual query.
