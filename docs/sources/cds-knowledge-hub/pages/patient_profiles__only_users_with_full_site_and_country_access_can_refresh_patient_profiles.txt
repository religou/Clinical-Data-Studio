# Patient Profiles: Only Users With Full Site and Country Access Can Refresh Patient Profiles

## Patient Profiles: Only Users With Full Site and Country Access Can Refresh Patient Profiles
## What Is New?
 Patient Profile permissions are updated to only allow users with permission to view all sites the ability to refresh any patient profile design.
## What Is the Impact?
## Users/Roles
 Users with limited site access can no longer refresh any PP design.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 The updated Patient Profile permissions ensure that when you deep link from any other DQM application (for example, Rounding and Propagation), then you do not receive an error message stating that the site cannot be found.
## Where Do I See the Change?
 On the Patient Profile design page, if you do not have access to all sites and countries included in the design, then the Refresh button is inactive for you.

 There are no additional relevant resources.
