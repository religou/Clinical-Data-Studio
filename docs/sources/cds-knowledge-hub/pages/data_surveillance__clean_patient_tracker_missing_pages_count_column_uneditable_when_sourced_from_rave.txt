# Data Surveillance: Clean Patient Tracker Missing Pages Count Column Uneditable When Sourced from Rave

## Data Surveillance: Clean Patient Tracker Missing Pages Count Column Uneditable When Sourced from Rave
## What Is New?
 While configuring missing pages in the Data Surveillance >Configuration > Data Mapping > Missing pages tab, if you select Rave, the missing pages count column in Clean Patient Tracker becomes uneditable (locked).
## What Is the Impact?
## Users/Roles
 Data managers.
## Workflow Process
 No impact to workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 You can ensure the data integrity and accuracy of Rave data ingested into Clean Patient Tracker. Data managers can eliminate the need for manual data entry, and streamline the data tracking process for Clean Patient Tracker.

## What Else Should I Know?
- The missing pages count from Rave is based on missing pages expected to date, not the total number of pages expected per patient. Expected To Date values factor in the folder entry windows, and exclude folders for future visits based on the window dates. 
- If you select either Rave or External while configuring missing pages in the Data Mapping tab, the missing pages count cannot be entered manually for any patient in Clean Patient Tracker.
