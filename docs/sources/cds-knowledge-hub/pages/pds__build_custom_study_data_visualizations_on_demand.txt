# PDS: Build Custom Study Data Visualizations On Demand

## PDS: Build Custom Study Data Visualizations On Demand
## What Is New?
 Visualizations is a Patient Data Surveillance (PDS) capability that enables you to chart the relationship between any combination of datasets on a single visual using real-time study data on demand. 
 You can plot study data in a bar chart, stacked bar chart, line chart, multiline chart, donut chart, or segmented donut chart. 
 You can create, view, edit, and delete study data visualizations. 
## What Is the Impact?
## Users/Roles
 All study team members.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Visualizations enables you to flexibly plot any study data you want to visualize, catering to your specific needs or area of interest depending on your study role. For example: 
- Medical monitors can view the number of adverse events per site.
- Site monitors can track patient enrollment rate.   
- Data managers can view missed visits or data entry delay. 
- CRAs can view, track, and compare patients records for pulse against blood pressure.  
- Study managers can see the number of nonrandomized patients in the study or track the number of study dropouts per month. 
 You can also conveniently view the data in whichever graphical rendering works best for that data—whether in a bar graph, stacked bar graph, line graph, or donut graph. 
 Graphically visualize study data relationships enables you to more effectively: 
- Gain a clearer understanding or perspective of the study data. 
- Identify study trends and patterns. 
- Track study performance. 
- Build and share reports or present on study data metrics using clear, visually appealing graphical renderings. 
 And you can create visualizations on your own anytime you want. 
## Where Do I See the Change?

## What Else Should I Know?
- For visualizations with a large amount of data, we recommend that you add chart filters to narrow your results. If the visualization you want to build experiences slow performance, we recommend that you refresh the page, use additional filters, and then regenerate the preview.
 Tip : For visualizations with many data points on the x-axis, we recommend using a bar graph.
- When selecting a date or text variable for a line chart's x- or y-axis, we highly recommend selecting an aggregation.
- If you do not select an aggregation for a text variable on the y-axis, then the line chart does not render. 
- If you do not select an aggregation for a date variable on the x-axis, then the line chart plots the data for every single day in the database.
 Note : Ideally, we recommend that you use date variables on the x-axis to create a timeline or visualize trends.
- When selecting any variable other than a date variable for the x-axis, if you select an aggregation, then you must select a color series. Otherwise, the chart does not render. 
- When building donut charts, we recommend selecting Percentage as the aggregation for optimal chart readability.
- The donut chart may not chart all patients in a data set if there are missing or incomplete patient records. 
- Saved visualizations update daily based on the latest study data snapshot processed by Data Reviewer. 
- The color palette in the Color Series is read-only.
