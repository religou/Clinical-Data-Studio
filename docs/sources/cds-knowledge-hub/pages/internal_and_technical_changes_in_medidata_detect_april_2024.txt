# Internal and Technical Changes in Medidata Detect April 2024

## Internal and Technical Changes in Medidata Detect April 2024
## What Is New?
 Medidata Detect April 2024 includes the following internal and technical changes:
- Moved QTL Dashboard-related code from the Detect code base to the QTL Dashboard code base. 
- Updated RubyGems version for Risk Management code base. 
- Risk Management only shows KRIs for studies with the minimum required number of sites to populate data within Detect. 
- Improved Risk Management page load time. 
- On the Data Reviewer > Data Sets page, if you add a filter and enter a keyword search, then the search returns matches in real time after entering at least four characters. 
- Upgraded the 1x version from 2.13.1 to 2.15.1 for Data Reviewer and AI Data Reconciliation. 
- For the RBQM Admin UI code base and Patient Profiles code base, Vulcan is now in Artifactory. 
- Patient Profiles URLs now include the study_environment_uuid for patient review requests. 
- Updated API response format to fetch values in datasets, variables, and flags in Patient Profiles.
