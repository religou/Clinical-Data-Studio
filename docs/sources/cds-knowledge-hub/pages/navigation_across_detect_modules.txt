# Navigation Across Detect Modules

## Navigation Across Detect Modules
## Description
 The new Detect Landing Page provides a unified navigation experience, where you can access all the Detect family products from a single page: Centralized Statistical Monitoring (CSM) (formerly Medidata Detect) , Patient Profiles, Data Reviewer, Detect Configuration Manager. When you log into iMedidata, you no longer see an Apps section for individual products. Likewise, the products no longer appear as an option for Actions in Cloud Administration. 
 Detect introduces the following four modules: 
- Patient Data Surveillance (PDS) 
- Data Reviewer 
- Patient Profiles 
- Derived Variables 
- Quality Tolerance Limits (QTLs) 
- QTL Dashboard 
- QTL Configuration 
- Centralized Statistical Monitoring (CSM) 
- Data Veracity 
- Reporting Patterns 
- Exploratory Analysis 
- CSM Configuration 
- History 
- Key Risk Indicators (KRIs ) 
- KRI Dashboard 
- KRI Configuration 
 For more details on individual modules, see User Impact . 
 Rebranded Detect family products and features are as follows:

 Note : All your existing permissions in iMedidata and Detect products remain the same. 
## Affected Roles
 All.
## Advantages
- Access all Detect family products from a single page. 
- The modular layout helps identify applications based on the task you want to perform: review data (PDS), analyze data (CSM), monitor sites (KRIs), monitor risks (QTLs).

## Special Considerations
- You need the appropriate permission set up in iMedidata to access products within a module and between modules. For example, if you have access to Patient Profiles in PDS, but no access to Data Reviewer and Derived Variables, you will only see tabs relevant to Patient Profiles in PDS.  
- The Overview page is no longer available in Centralized Statistical Monitoring (CSM) (formerly Medidata Detect) . You can use the History application in the CSM module to capture snapshots of pages in Data Veracity, Reporting Analysis and Exploratory Analysis. 
 To view Medidata testing documentation for this release, refer to the   Medidata Validation Portal .
