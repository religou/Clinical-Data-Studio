 Summary of Changes 
 | 
 As highlighted in the Release Newsletter :
 The Data Oversight dashboard is now renamed to Task Oversight. Task Oversight serves as a singular place to understand key operational activities like set up, data import, refresh, and data review as documented in Data Connect and Data Surveillance. It also includes key metrics for Custom Graphs, in addition to all published Patient Profile designs, Listings, Vendor Queries, AI Reconciliation reports.  
 Benefit to Users 
 | Task Oversight provides:
- Complete operational transparency – Lead Clinical Data Managers (LCDMs) and Clinical Data Team Leads (CDTLs) can access critical operational metrics and user work compliance from a single page. 
- Flexibility to select key operational metrics – You can select metrics of interest to display on the Task Oversight dashboard, such as:
- Metrics covering reviewed patient profiles, and last refresh date. 
- Visibility into listings created, last refresh date, and records reviewed/not reviewed per listing. 
- Tracking unreviewed AI Reconciliation data per report. 
- Tracking Custom Graphs data for all charts. 
- Tracking reviewed vendor queries per query set. 
- Reduced friction and risk – By centralizing information, Task Oversight avoids the need to switch between multiple capabilities, bringing critical information directly into one page.  
 Summary of User Impact 
 | 
 Impact to Users and Roles 
- Lead Clinical Data Managers (LCDMs) and Clinical Data Team Leads (CDTLs). 
- All users with the View CDS Task Oversight building block. 
 Impact to Workflow Processes 
 Task Oversight reads data from the following modules based on their latest refresh data snapshot.
- Patient Profiles. 
- AI Reconciliation. 
- Listings. 
- Custom Graphs. 
- Vendor Queries, and 
- Data Connect. 
 Updates made to records, such as marking listings as reviewed or unreviewed, or similar actions in any of the modules, reflects in the metrics shown on the Task Oversight dashboard instantly. 
 Impact to Applications 
 Data Oversight reads data from the following capabilities:
- Patient Profiles. 
- AI Reconciliation. 
- Listings. 
- Custom Graphs. 
- Vendor Queries, and 
- Data Connect. 
 Impact on Interface 
 The Task Oversight tab appears with the following details:

If you click the Task Oversight tab, the Task Oversight page appears and displays all the configured modules and their associated metrics. AI Reconciliation or Listings cards include data refresh icons, and if you hover, a tooltip shows the total refreshes for each module. For any metrics card on the Task Oversight dashboard, the last refreshed date and time appear in the user's local time zone.

Custom Graphs shows the total configured visuals in your study. Each row shows a custom graph, its last refreshed date, and the person who refreshed. If you click  View All Custom Graphs , a page shows a list of all custom graphs in the study.
