# Data Reviewer Listings Pages Redesigned For Better Usability

## Data Reviewer Listings Pages Redesigned For Better Usability
## Description
 Data Reviewer 2023.1.0 presents a new User Interface (UI) including redesigned Listings pages.
## Affected Roles
 All roles with the View Data building block. 
## Advantages
 You can now locate on-screen Data Reviewer components with ease and have a better user experience.
## User Impact
 Note: The generated fields, for example, _DTC, _TXT, and so on,  have been removed from the datasets selection list.  For Listings created against generated fields, edit the Listings and select the associated non-generated fields.

## Special Considerations
- You can only view Draft Listings if you have Edit Listing access. 
- You can only approve a listing with < 10,000 records. You must edit the conditional expression in the expression builder if the listing shows >10,000 records. 
- To view Medidata testing documentation for this release, refer to the Medidata Validation Portal .
