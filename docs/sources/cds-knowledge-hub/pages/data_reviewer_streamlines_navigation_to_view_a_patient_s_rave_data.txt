# Data Reviewer Streamlines Navigation to View A Patient's Rave Data

## Data Reviewer Streamlines Navigation to View A Patient's Rave Data
## Description
 Data Reviewer now includes integration with Rave EDC such that authorized Rave EDC users can use the following Rave EDC functionality from the Data Reviewer interface: 
- On the Medidata Detect > Patient Data Surveillance (PDS) > Data Reviewer > Data Viewer page, when you select a patient ID from a data set and then click you can view the patient's data in Rave EDC . 
## Affected Roles
 All Detect users with access to Data Reviewer and Rave EDC. 
## Advantages
 With the integration between Rave EDC and Data Reviewer, data managers can investigate further patient data within data sets and look for anomalies and take further action as required. 
## User Impact
 See Description.
