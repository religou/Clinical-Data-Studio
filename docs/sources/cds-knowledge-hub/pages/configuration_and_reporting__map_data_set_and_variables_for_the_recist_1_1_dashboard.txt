# Configuration and Reporting: Map Data Set and Variables for the RECIST 1.1 Dashboard

## Configuration and Reporting: Map Data Set and Variables for the RECIST 1.1 Dashboard
## What Is New?
 Medidata Detect April 2024 includes a new Response Evaluation Criteria in Solid Tumors (RECIST) 1.1 dashboard that shows the tumor burden change in patients in oncology studies. Medidata Detect > Configuration and Reporting > Detect Mapping includes a new Oncology Mapping page, and a RECIST tab where you can configure data sets and variables that appear on the RECIST 1.1 dashboard. You can use Oncology Mapping to:
- Identify forms and fields for analyzing the tumor burden for RECIST 1.1. 
- View visualizations of oncology study data on the RECIST 1.1 dashboard. 
- Facilitate faster reconciliation of study data. 
 The RECIST Configuration page includes a Help on This Page option, which navigates you to the RECIST Configuration   Knowledge Hub article. 
## What Is the Impact?
## Users/Roles
 Study Managers, Medical Monitors, and Data Managers.
 Detect users with View CSM Configuration and Manage CSM Configuration access. 
## Workflow Process
 No impact to the workflow process.
## Other Applications
 The RECIST 1.1 dashboard in Data Reviewer shows the data sets and variables you configure in Configuration and Reporting > Detect Mapping > Oncology Mapping > RECIST. Source and target variables you configure in Oncology Mapping populate the RECIST 1.1 dashboard and the tumor burden response by patient table. For more information, see  PDS: Track Patient Tumor Burden Data with The RECIST 1.1 Dashboard . 
## How Do I Benefit?
 With RECIST Configuration:
- You can identify the RAVE forms and fields useful in analyzing the tumor burden for the RECIST 1.1 dashboard. 
- Data sets and variables you configure appear on the RECIST 1.1 dashboard. Medical Monitors and Data Managers can use the RECIST 1.1 dashboard to learn about the change in tumor size, individual patient journeys and implement the best course of action as per study protocol.  
- You can facilitate a faster data reconciliation process.
