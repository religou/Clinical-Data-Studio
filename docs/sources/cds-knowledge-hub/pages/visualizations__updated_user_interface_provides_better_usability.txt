# Visualizations: Updated User Interface Provides Better Usability

## Visualizations: Updated User Interface Provides Better Usability
## What Is New?
 The Data Surveillance > Visualizations page:
- If you click Create Visualizations ,
- For any dataset you select from the left-hand menu, the variables you drag and drop into the X-axis, Y-axis, color series, chart filters, or rows and columns based on the chart type, appear highlighted. This is true if you import a template to create a visualization or just edit an existing visualization. The dataset variables in both cases appear highlighted in the left-hand menu. 
- Tooltips appear if you hover over any chart type. 
- The Create Visualization page always includes four components:
- Import template 
- Chart configurations 
- Display settings 
- Preview 
## What Is the Impact?
## Users/Roles
 All study team members. 
## Workflow Process
 No impact to workflow process. 
## Other Applications
 No impact to other applications. 
## How Do I Benefit?
 Graphically visualizing study data relationships in various charts with a cleaner user interface enables you to accurately: 
- Gain a clearer understanding or perspective of the study data. 
- Identify study trends and patterns. 
- Track study performance. 
- Build and share reports or present on study data metrics using clear, visually appealing graphical renderings.
