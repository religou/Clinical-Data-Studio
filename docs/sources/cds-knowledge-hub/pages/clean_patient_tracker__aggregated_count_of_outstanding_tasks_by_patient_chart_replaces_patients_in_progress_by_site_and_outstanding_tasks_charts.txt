## Change Details
 Product 
 | Clinical Data Studio
 Version 
 | 2026.3.0
 Change Type 
 | Enhancement (Updated Functionality) 
 Functionality or Module 
 | Clean Patient Tracker
 Summary of Changes 
 | 
 Clean Patient Tracker no longer includes the following charts:
- Patients in Progress By Site 
- Outstanding Tasks 
 Clean Patient Track now includes the Aggregated Count of Outstanding Tasks by Patient horizontal stacked bar chart, which shows the counts of outstanding tasks per patient. The chart includes outstanding tasks by listings, vendor queries, and page statuses, AI Reconciliation reports, and Rave EDC queries. 
 Benefit to Users 
 | The Aggregated Count of Outstanding Tasks by Patient chart shows all patient-level outstanding tasks enabling you to clean patient data and ensure study data integrity and accuracy.
 Clinical Data Studio's Task Oversight Dashboard includes the Patients in Progress By Site and Outstanding Tasks charts. To avoid duplication across the Clinical Data Studio experience, these charts are removed from Clean Patient Tracker.
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 Data managers. 
 Impact to Workflow Processes 
 You can view the Patients in Progress By Site and Outstanding Tasks charts in Clinical Data Studio's Task Oversight Dashboard instead of in Clean Patient Tracker.
 Impact to Applications 
 No impact to other applications.
 Impact on Interface 
 Clean Patient Tracker no longer includes the following charts:
- Patients in Progress By Site 
- Outstanding Tasks 
 Clean Patient Track now includes the Aggregated Count of Outstanding Tasks by Patient horizontal stacked bar chart, which shows the counts of outstanding tasks per patient.
 Tip : Click image to enlarge.
 You can:
- Sort the chart in ascending, descending, and alphabetical order (default is alphanumeric) based on total count per patient. 
- Scroll the chart vertically. 
- Hover your cursor on any patient row in the chart to display a tooltip that shows the following details:
- Patient ID 
- Listings count 
- Vendor queries count 
- page statuses count 
- AI Reconciliation count 
- Rave EDC Queries count 
 Impact to Existing Data or Settings 
 No impact to existing data or settings.
