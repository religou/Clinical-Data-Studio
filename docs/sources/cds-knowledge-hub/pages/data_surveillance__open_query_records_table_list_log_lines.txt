# Data Surveillance: Open Query Records Table List Log Lines

## Data Surveillance: Open Query Records Table List Log Lines
## What Is New?
 The Open Queries > Open Query Records table now includes the Log Line column. The Log Line column show the specific log line in the form that is queried. The Open Query Records CSV download file also includes the Log Line column.
## What Is the Impact?
## Users/Roles
 Data managers.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Listing the log line improves your ability to locate and analyze the specific line of data within the source log form that is queried.
## Where Do I See the Change?
 Data Surveillance > Open Queries > Open Query Records table > Log Line column.
