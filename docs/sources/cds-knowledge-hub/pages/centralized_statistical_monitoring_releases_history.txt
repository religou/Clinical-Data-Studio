# Centralized Statistical Monitoring Releases History

## Centralized Statistical Monitoring Releases History
 The following lists all Centralized Statistical Monitoring releases (starting with the initial release to up to the 2022.2.0 feature release) and the features and enhancements introduced in each. All Centralized Statistical Monitoring features and enhancements released after Centralized Statistical Monitoring 2022.2.0 are listed in the Clinical Data Studio Releases History .
 Code Continuity Across Releases
 Note : All Centralized Statistical Monitoring releases are cumulative. That is, each release or software update is built on the prior releases as noted in the release notes. For example,  Software Update 2016.2.1  includes all of the release  2016.2.0  code, which in turn is based on the  release  2016.1.0  code and so on. Any updates between releases or s oftware updates (urgent or otherwise)  are described in the release notes. 
## Centralized Statistical Monitoring 2022.2.0 (Jul 2022)
 This release provided the following new features: 
- View Under- and Overreporting Event Trends at the Site and Country Level 
- View Current and Historical QTL Value Trends 
- Preview and Export Comprehensive QTL Reports 
- Export and Download Customizable KRI Table Snapshots 
- Perform Data Refresh from the KRI Dashboard Page 
 This release also provided the following enhancements: 
- View and Create Issues on the Weekend and Holiday Visits Page 
- QTL-related Technical Enhancements

## Centralized Statistical Monitoring (formerly Medidata Detect) 2022.1.0 (Apr 2022)
 Note : As of this release, the product name has been changed from "Medidata Detect" to "Centralized Statistical Monitoring (CSM)". Going forward, Medidata Detect will refer to the overall family of products covering data and risk surveillance tools. See https://learn.mdsol.com/display/DETECTLPprd for details. 
 This release provided the following new features: 
- Improved Navigation and Rebranding in Centralized Statistical Monitoring 2022.1.0 
- Identify Potentially Falsified Visit Data By Viewing Scheduled Patient Visits That Occurred on Non-business Days 
- Uncover Potential Duplicate Patients 
 This release also provided the following enhancements: 
- Error Plots Streamline Navigation to View a Specific Patient's Profile 
- Filter Study Risks By Sites And Countries In The Key Risk Indicators Dashboard 
- Calculation Method Updated for Six System KRIs 
- Column Header Tooltip in Key Risk Indicators Table Shows KRI Details 
 For information about the defects resolved in this release, see: 
- Centralized Statistical Monitoring -formerly Medidata Detect 2022.1.0 Resolved Issues List
