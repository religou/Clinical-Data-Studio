# Data Surveillance: Identify Changed Data Points In Approved Listings After Data Refresh

## Data Surveillance: Identify Changed Data Points In Approved Listings After Data Refresh
## What Is New?
 After a data refresh in Data Listings, changed data points appear with a icon in the Status column for approved listings. 
## What Is the Impact?
## Users/Roles
 Study managers and data managers.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 You can easily track changed data or data marked as reviewed in the study since the last refresh and follow up as required. 
## Where Do I See the Change?
 . In the Data Surveillance > Listings > Approved Listings tab, after a data refresh:
- The Status column shows a icon, to indicate changed data against any data point values that changed. 
- If a record marked reviewed undergoes changes in its data point values, it is marked as unreviewed.
