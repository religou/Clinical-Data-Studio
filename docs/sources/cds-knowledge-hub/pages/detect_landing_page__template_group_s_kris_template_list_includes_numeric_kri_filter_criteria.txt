 Functionality or Module 
 | Detect Landing Page > Library > Templates
 Summary of Changes 
 | 
 As highlighted in the Release Newsletter :
 When configuring custom numeric KRIs, you can build an expression to filter for the specific subset of data that you want the KRI to perform statistical analysis on. To learn more, see  RBQM Configuration: Configure Custom Numeric KRIs That Run Statistical Analysis on Specific Data Subsets .
 In accordance with this functionality, when working in the Template Library, when you view a Template Group, the list of KRIs templates now includes a  Filter Criteria column. If there is an expression built for a custom numeric KRI, then the Filter Criteria column presents the expression in the list of KRI templates.
 Benefit to Users 
 | Adding the Filter Criteria column:
- Supports and aligns the Template Library with the current custom numeric KRI configuration functionality. 
- Provides comprehensive KRI details across studies. 
 Summary of User Impact 
 |

 No impact to other applications. 
 Impact on Interface 
 In RBQM > Library > Templates: when you click a group name from the Template Library, and then click the Template Group window > KRIs tab, the KRIs table includes a new Filter Criteria column.
