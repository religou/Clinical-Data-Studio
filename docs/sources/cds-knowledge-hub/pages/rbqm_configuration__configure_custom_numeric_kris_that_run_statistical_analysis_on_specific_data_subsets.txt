## Change Details
 Product 
 | Clinical Data Studio
 Version 
 | 2026.1.0
 Change Type 
 | Enhancement (Updated Functionality)
 Functionality or Module 
 | RBQM Configuration > KRI Configuration
 Summary of Changes 
 | 
 As highlighted in the Release Newsletter :
 When configuring custom numeric KRIs, you can build an expression to filter for the specific subset of data that you want the KRI to perform statistical analysis on.
 Benefit to Users 
 | In previous releases, you could only create custom numeric KRIs that performed statistical analysis on the full set of data in a selected data set. Now, you can specify data subset populations within a dataset that are meaningful to your study that you want to perform statistical analysis on. For example, you may want to run analysis on SAEs that are grade 3, 4, or 5, and exclude SAEs of grade 1 or 2 from your analysis.
 Therefore, you now have more control over specific study data that you want to track, monitor, and review. 
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 RBQM Configuration Manager Administrators
 Impact to Workflow Processes 
 No impact to the workflow process.
 Impact to Applications 
 KRI Dashboard
 Impact on Interface 
 In RBQM > Configuration > KRIs, when you add or edit a custom numeric KRI, the Custom Numeric KRI window now includes an Add Filter Criteria check box. Selecting the check box reveals and expression builder, which you can use to filter the data population subset that the KRI runs analytics on within the selected data set.
