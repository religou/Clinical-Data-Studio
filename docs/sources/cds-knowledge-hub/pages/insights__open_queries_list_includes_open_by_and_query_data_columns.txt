# Insights: Open Queries List Includes Open By and Query Data Columns

## Insights: Open Queries List Includes Open By and Query Data Columns
## What Is New?
 The Open Query Records list includes two new columns:
- Open By – The user who opened the query. 
- Query Data – The contents of the queried data point. 
 You can filter the Open Query Records list by the Open By column.
## What Is the Impact?
## Users/Roles
 Data manager.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 When viewing the list of open queries, you can quickly determine who opened each query. Therefore, all parties involved can more easily communicate and address open queries.
## Where Do I See the Change?
 On the Insights > Open Queries page > Open Query Records section:
- The list includes the Open By column and Query Data column. 
- The filter options above the list include the Open By filter.

 You cannot filter or sort the Open Query Records list by Query Data.
