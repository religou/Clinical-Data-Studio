# Reconcile Data Accurately Using Data Reviewer Algorithms

## Reconcile Data Accurately Using Data Reviewer Algorithms
## Description
 Data Managers and Central Monitors must reconcile study data collected at sites to ensure data accuracy. However, lack of clinical experience in personnel conducting reconciliation or errors encountered while manually entering data can hamper the reconciliation process or even threaten study integrity. Medidata Detect 2023.1.0 introduces six new AI Data Reconciliation reports that use built-in algorithms to automatically reconcile study data.
## Affected Roles
 All roles with the Manage Data Reviewer building block. 
## Advantages
 As Data Managers and Central Monitors, you can:
- Produce error-free data by avoiding a manual  reconciliation process. 
- Use built-in algorithms to create reconciliation reports, and save time spent on reviewing study data and finding matches for each report. 
- Overcome lack of clinical experience to reconcile study data.

## Special Considerations
- You can view the AI Data Reconciliation page if you have the right access. 
- The Patient ID link on the AI Data Reconciliation page will work only if you have the right Patient Profiles access. 
- You cannot submit Rave queries on the AI Data Reconciliation page and the Submit Queries button does not appear if you do not have a role with the Submit Queries via Detect access.
