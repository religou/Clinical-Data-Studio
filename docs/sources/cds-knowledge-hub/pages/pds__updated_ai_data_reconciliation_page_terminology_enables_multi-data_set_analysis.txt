## What Is the Impact?
## Users/Roles
 Data managers
## Workflow Process
 No impact to the workflow process.
## Other Applications
 You must use Detect Configuration Manager's Event Analysis Mapping to map the data sets that you want AI Data Reconciliation to analyze.
## How Do I Benefit?
 Updating the verbiage to treatment and conditions enables you to configure multiple data sets as references in the Detect Configuration Manager's Event Analysis Mapping. Therefore, AI Data Reconciliation can simultaneously analyze multiple data sets that use similar coding.

 AI Data Reconciliation requires data sets to be coded in MedDRA or WHODrug, respectively.
