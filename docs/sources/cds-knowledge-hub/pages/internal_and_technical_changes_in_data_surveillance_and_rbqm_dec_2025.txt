# Internal and Technical Changes in Data Surveillance and RBQM Dec 2025

## Internal and Technical Changes in Data Surveillance and RBQM Dec 2025
## What Is New?
 The following Data Surveillance and RBQM capabilities include technical changes.
- For Vendor Queries, the Maturity Rank has been increased in DevOps Central. 
- For Clean Patient Tracker, RECIST 1.1 code has migrated to Grafana Cloud 
- For Plan Documents, Risk Management, Signals, Statistical Monitoring, Audit Trail Review, RBQM Home Page, Key Risk Indicators, Quality Tolerance Limits, RBQM Configuration  code has migrated to Grafana Cloud.
