# Patient Profiles Releases History

## Patient Profiles Releases History
 The following lists all Patient Profiles releases (starting with the initial release to up to the 2022.3.3 release) and the features and enhancements introduced in each. All Patient Profiles features and enhancements released after Medidata Patient Profiles 2022.3.3 are listed in the Clinical Data Studio Releases History .
 Code Continuity Across Releases
 Note : All Patient Profiles releases are cumulative. That is, each release or software update is built on the prior releases as noted in the release notes. For example, Software Update 2016.2.1 includes all of the release 2016.2.0 code, which in turn is based on the release 2016.1.0 code and so on. Any updates between releases or software updates (urgent or otherwise) are described in the release notes.
