 Summary of Changes 
 | 
 As highlighted in the Release Newsletter :
 The templates for Listings, KRIs, QTLs, and Custom Graphs (previously known as Visualizations) are no longer accessible from Data Surveillance or RBQM. These are now available in the Platform Library and grouped as Template Groups. 
 Benefit to Users 
 | Platform Library provides  centralized access to the global template library containing all templates from Listings, KRIs, QTLs, and Custom Graphs (previously known as Visualizations) . 
 Summary of User Impact 
 | 
 Impact to Users and Roles 
- Users with access to Listings, KRIs, QTLs, and Custom Graphs (previously known as Visualizations). 
- Users who referenced the template libraries previously.  
 Impact to Workflow Processes 
 To access Template Groups in Platform Library, you require the following permissions: 
- Manage Detect Templates 
- View Detect Templates 
 Impact to Applications 
 The templates for Listings, KRIs, QTLs, and Custom Graphs (previously known as Visualizations) are no longer accessible from Data Surveillance or RBQM. You must navigate to the Platform Library to view and manage Template Groups. 
 Impact on Interface 
 The Template Library capability is no longer accessible in Data Surveillance or RBQM.
 You can view and manage your Listing, KRI, QTL, and Custom Graph templates by accessing the Platform Library tab on the Medidata App Navigation Tab Barand then selecting the Template Groups from the left-hand menu.
