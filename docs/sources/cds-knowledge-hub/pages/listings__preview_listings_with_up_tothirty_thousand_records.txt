## Change Details
 Product 
 | Clinical Data Studio
 Version 
 | 2026.1.0
 Change Type 
 | Enhancement (Updated Functionality)
 Functionality or Module 
 | Listings
 Summary of Changes 
 | 
 You can now preview listings with up to 30,000 records.
 Benefit to Users 
 | Data managers can review a larger number of records during review cycles.
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 Data managers.
 Impact to Workflow Processes 
 No impact to workflow processes.
 Impact to Applications 
 No impact to other applications.
 Impact on Interface 
 On the Data Surveillance > Listings page, if you create or edit a listing and then click Preview , the listing preview can show up to 30,000 records.
 Impact to Existing Data or Settings 
 No existing data changes; no configuration or permission updates required.

 | Medium
