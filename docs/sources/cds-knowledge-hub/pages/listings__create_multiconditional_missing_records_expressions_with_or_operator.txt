 Summary of Changes 
 | 
 As highlighted in the Release Newsletter :
 You can use the OR operator to build multiconditional missing records. This allows you to find unique records that are missing at least one of your specified criteria under missing records.
 Benefit to Users 
 | 
 Using the OR operator allows to capture records with partial mismatches previously hidden by using only AND logic. This ensures accuracy and reliability of the clinical trial data. 
 Summary of User Impact 
 | 
 Impact to Users and Roles 
- Study managers and data managers. 
- All users with Manage Data Reviewer and View Data Reviewer building blocks. 
 Impact to Workflow Processes 
 You can now track and review partial mismatches  by using the OR operator for building multicondition expressions under missing records in both   Draft   and   Approved   listings. 
 Impact to Applications 
 No impact on other applications.
 Impact on Interface 
 You can use the OR operator from the dropdown under Missing Records to build multiconditional missing records.
 Tip: Click the image to enlarge. 
 Number 
 Description 
 | 1 
 | 
 The OR operator - When the Missing Records is enabled in a listing, a  dropdown containing the  AND  and  OR  options appear between criteria rows when you click  to add a second or subsequent row. The operator dropdown disappears automatically when you delete criteria and revert to a single row. 
 Note : Editing an approved listing to add missing record criteria using the OR operator automatically creates a new draft and moves the listing to draft listings. 
 Impact to Existing Data or Settings 
 No impact on existing data or settings; no configuration or permission updates required.
