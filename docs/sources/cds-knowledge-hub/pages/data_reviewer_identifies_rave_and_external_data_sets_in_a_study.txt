# Data Reviewer Identifies Rave And External Data Sets In A Study

## Data Reviewer Identifies Rave And External Data Sets In A Study
## Description
 Data Reviewer 2022.1.1 distinguishes between and identifies data sets from Rave EDC and external sources in a study.
## Affected Roles
 All.
## Advantages
 Identifying the origin of data sets enables you to group data set variables of interest from a study and investigate anomalies or discrepancies.
## User Impact
 The Data Set tab on the Medidata Detect >Patient Data Surveillance (PDS) > Data Reviewer > Data Viewer page or Listings page now includes a Rave or External label to identify the origin of the data set. You will also see similar labels for data sets on the Medidata Detect > Patient Data Surveillance (PDS) > Data Reviewer > Derived Variables page.
