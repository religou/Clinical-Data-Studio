## Change Details
 Product 
 | Clinical Data Studio
 Version 
 | 2026.3.0
 Change Type 
 | Enhancement (Updated Functionality) 
 Functionality or Module 
 | Configuration
 Summary of Changes 
 | 
 In Data Surveillance and RBQM: On the Configuration > Data Mapping > Oncology tab, you can no longer map to enriched date variables such as DTC, INT, or DT dates.
 Benefit to Users 
 | Removing enriched data variables from Oncology Mappings ensures that you select mappings supported by Clinical Data Studio.
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 Data managers. 
 Impact to Workflow Processes 
 No impact to workflow process. 
 Impact to Applications 
 No impact to other applications. 
 Impact on Interface 
 In Data Surveillance and RBQM: On the Configuration > Data Mapping > Oncology tab, enriched data variables are no longer available to select from the configuration mapping dropdown lists.
 Impact to Existing Data or Settings 
 For mappings configured with enriched dates, the dates will remain but be nonconformant. Users must be able to remediate.
 User Impact Assessment 
 | Low
