# Listings: Obtain Latest Listings Study Data With Simultaneous Refresh

## Listings: Obtain Latest Listings Study Data With Simultaneous Refresh
## What Is New?
 Data managers can now get the most updated study data in listings by refreshing all listings simultaneously. 
## What Is the Impact?
## Users/Roles
 Data managers.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 With the most recent study data populated in all the listings in a study, data managers can ensure greater efficiency in the data reconciliation process.
## Where Do I See the Change?
 On the Data Surveillance tab > Listings page > Approved Listings tab> if you select all listings, and then click the Refresh All Listings button above the listings table, all the listings are refreshed. Once the refresh process initiates, the Refresh All Listings button becomes disabled. You can however continue to work with any listing. However the data updates you see match study data before the refresh started.
