# Data Reviewer Releases History

## Data Reviewer Releases History
 The following lists all Data Reviewer releases (starting with the initial release to up to the 2022.3.0 feature release) and the features and enhancements introduced in each. All Data Reviewer features and enhancements released after Data Reviewer 2022.3.0 are listed in the Clinical Data Studio Releases History .
 Note :  Code Continuity Across Releases 
 All Data Reviewer releases are cumulative. That is, each release or software update is built on the prior releases as noted in the release notes. For example,  Software Update 2016.2.1  includes all of the release  2016.2.0  code, which in turn is based on the  release  2016.1.0  code and so on. Any updates between releases or s oftware updates (urgent or otherwise)  are described in the release notes.
