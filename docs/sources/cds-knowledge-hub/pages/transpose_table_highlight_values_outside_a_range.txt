# Transpose Table Highlight Values Outside a Range

## Transpose Table Highlight Values Outside a Range
## Description
 Transposed tables highlight high and low variable values that lie outside a specified normal range. You can set these limits without choosing graphs for the transposed tables.  A ( ) displays next to variable values exceeding the upper limit. A ( ) displays next to variable values below the lower limit.
## Affected Roles
 All. 
## Advantages
 With high and low values shown with red and blue markers respectively, Patient Profile design reviewers can easily identify outliers in a study. 
## User Impact
 On the Design page > Elements tab:  
- When working in Transposed Tables: 
- The Normal Range section always displays at the bottom of the page. 
- The DATA OPTIONS tab allows you to drag-and-drop upper and lower limit variables into the Variable column in the Normal Range section. The Display column shows the upper limit in red and the lower limit in blue. These colors are set by default and cannot be changed. 
 On the Design page > Profiles tab: 
- If you specify both upper and lower limit variables, high and low variables outside the specified normal range display with a  or icon respectively, for a patient. A legend appears at the bottom of the table. The legend and markers do not display if no upper or lower limit is set. 
- If you specify only upper limit variables, high variables outside the specified normal range display with a  icon for a patient. A legend  appears at the bottom of the table. The legend and markers not display if no upper limit is set. 
- If you specify only lower limit variables, low variables outside the specified normal range display with a icon for a patient. A legend  appears at the bottom of the table. The legend and markers do not display if no lower limit is set. 
- When you export patient profile designs in a study to PDF, h igh and low variables that lie outside the specified normal range display with a or icon respectively.  A legend  appears at the top of the page. The legend and markers not display if no upper or lower limit is set. 
## Special Considerations
 Transposed tables indicate high and low values outside a range only if upper and lower limit variables have been defined for the selected test. If a variable is exactly equal to either the set upper or lower limit, a visual marker does not appear next to the variable as this it is within the specified range.
