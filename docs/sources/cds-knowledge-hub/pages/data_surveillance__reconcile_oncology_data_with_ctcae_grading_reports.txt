## Data Surveillance: Reconcile Oncology Data With CTCAE Grading Reports
## What Is New?
 Common Terminology Criteria for Adverse Events (CTCAE) grading is used to assess the severity of side effects experienced during medical treatments, typically cancer therapy. It assigns a grade from 1 to 5, with 1 being mild and 5 being death. This consistent rating system enables researchers and doctors to effectively compare treatment outcomes and ensure patient safety.  To know more about CTCAE grading, see CTCAE v 5.0 .
 AI Data Reconciliation includes two new reports based on the CTCAE version 5.0 grading: 
- Missing Lab for CTCAE Grading – The report includes findings where adverse event (AE) grades depend on lab values, and where AEs have the correct CTCAE grades but with no appropriate lab data collected between AE Start Date and AE End Date. 
- Invalid CTCAE Grade – The report includes findings where adverse events (AEs) have grades not acceptable as per CTCAE criteria v5, or where grade is present but not required, or where no grade is present but is required.

- Patient ID 
- Site 
- Country 
- Data set 
- Status 
- Reported Term 
- Preferred Term 
- Start Date 
- End Date

 You can download both reports. A slide out window appears showing additional records if you click the number hyperlink in the Same Time Frame Labs or Outside Time Frame Labs columns in the CTCAE reports.

## What Else Should I Know?
- Data sets must be mapped in Event Analysis, otherwise the data sets will not appear in the reports or be processed through AI Data Reconciliation's algorithms. 
- CTCAE reports work only if you: 
- Map Grade in Data Surveillance > Configuration > Data Mapping > Event Analysis > Condition Mapping.
- Configure lab measurements in Data Surveillance > Configuration > Data Mapping > Lab Measurements. For more details, see Data Surveillance: Configure The Data Sets And Variables Used In CTCAE Reports . 
- To view Medidata testing documentation for this release, refer to the  Medidata Validation Portal .
