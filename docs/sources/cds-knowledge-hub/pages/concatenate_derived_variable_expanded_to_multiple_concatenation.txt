# Concatenate Derived Variable Expanded to Multiple Concatenation

## Concatenate Derived Variable Expanded to Multiple Concatenation
## Description
 You can concatenate multiple text data set variables with the Concatenate derived variables workflow. Additionally, the text entered into the Prefix and Suffix fields now each appear once in the derived variable.
## Affected Roles
 All roles with the Manage Derived Variables permission.
## Advantages
 You can create more robust text derived variables to use in MEDS Data Viewer and other applications.
## User Impact
 The concatenation workflow now accepts multiple text data set variables. When you add variables into the available fields, another row of fields appear.
 Additionally, the text entered in the Prefix field only appears once at the beginning of the derived variable. Likewise, the text entered in the Suffix field only appears once at the end of the derived variable.
## Special Considerations
 None.
