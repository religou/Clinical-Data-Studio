# Derived Variables Updates Ensure Accurate Data Set Selection While Merging

## Derived Variables Updates Ensure Accurate Data Set Selection While Merging
 What Is New? 
 A review data set merge warning message appears when you create and save a merge type derived variables.
## What Is the Impact?
## Users/Roles
 All Clinical Data Studio users.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 None.
## How Do I Benefit?
 You can check and ensure that the data sets you merge are correct.
## Where Do I See the Change?
 In Data Surveillance or RBQM > Configuration > Derived Variables, or RBQM > Configuration > Derived Variables, when you create and save a merge type derived variable, the following message appears.
 Please review and confirm that you have selected the correct merge type for the dataset. Otherwise, Data Surveillance and RBQM cannot refresh with the latest data.
