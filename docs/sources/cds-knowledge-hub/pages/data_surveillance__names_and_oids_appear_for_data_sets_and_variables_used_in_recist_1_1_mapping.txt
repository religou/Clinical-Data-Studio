# Data Surveillance: Names And OIDs Appear For Data Sets And Variables Used In RECIST 1.1 Mapping

## Data Surveillance: Names And OIDs Appear For Data Sets And Variables Used In RECIST 1.1 Mapping
## What Is New?
The data set and variable names and Object Identifiers (OIDs) appear when you map data sets and variables that appear on the RECIST 1.1 dashboard.
## What Is the Impact?
## Users/Roles
 Study Managers, Medical Monitors, and Data Managers.
 Detect users with View CSM Configuration and Manage CSM Configuration access. 
## Workflow Process
 No change to workflow process.
## Other Applications
 The RECIST 1.1 dashboard in Oncology shows the data sets and variables you configure in Configuration > Detect Mapping > Oncology > Oncology Mapping. Source and target variables you configure in Oncology Mapping populate the RECIST 1.1 dashboard and the tumor burden response by patient table. For more information, see Track Tumor Burden and Response Calculation . 
## How Do I Benefit?
 You can easily identify the data sets and variables to use to configure the data that appears on the RECIST dashboard, which in turn, enables:
- You to Identify the RAVE forms and fields useful in analyzing the tumor burden for the RECIST 1.1 dashboard. 
- Medical Monitors and Data Managers to use the RECIST 1.1 dashboard to learn about the change in tumor size, individual patient journeys and implement the best course of action as per study protocol.  
- You to facilitate a faster data reconciliation process. 
## Where Do I See the Change?
 The Data Surveillance > Configuration > Oncology > Oncology Mapping includes a form, target, and source fields. You can select a data set as the RAVE form. Then map the appropriate data set source fields to the variable target field to ensure that the RECIST 1.1 dashboard analyzes, visualizes, and prioritizes oncology study data ingested from RAVE EDC. The OID and name appear for all saved fields for both data sets (target field) and corresponding fields (source field).
