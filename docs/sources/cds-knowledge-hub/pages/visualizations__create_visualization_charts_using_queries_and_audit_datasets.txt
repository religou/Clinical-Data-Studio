## Change Details
 Product 
 | Clinical Data Studio
 Version 
 | 2026.1.0
 Change Type 
 | Enhancement (Updated Functionality)
 Functionality or Module 
 | Visualizations 
 Summary of Changes 
 | 
 As highlighted in the Release Newsletter :   
 You can now create visualizations using the queries dataset as well as audit datasets published from Audit Trail Review . 
 Benefit to Users 
 | Data managers can use non-standard datasets to build visualization charts to gain better insight into study data and identify important trends and patterns.
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 All study team members.
 Impact to Workflow Processes 
 No impact to workflow.
 Impact to Applications 
 No impact to other applications.
 Impact on Interface 
 On the Data Surveillance > Visualizations page, if you click Create Visualization , the left-hand side Data Sets menu shows both Audit datasets and the Queries dataset for line, donut, bar, scatter charts. These datasets do not appear for Tabular Visualizations. Also, cross-dataset visualizations do not work.
 Impact to Existing Data or Settings 
 No existing data changes; no configuration or permission updates required.
 User Impact Assessment 
 | Medium

- Updated Article: Create, Edit, and Delete Visualizations .
