# Centralized Statistical Monitoring Enhancements

## Centralized Statistical Monitoring Enhancements
## Description
 Centralized Statistical Monitoring (CSM) includes the following enhancements:
- The Potential Duplicate Patients feature includes a new Export button that allows you to download a listing of the patients identified as duplicates in a Comma Separated Values (CSV) file. 
- Error Plots has been renamed Data Anomaly Detection. 
## Affected Roles
- Central Monitors 
- Data Managers. 
## Advantages
- The ability to export the details of patients identified as duplicates in a CSV file. 
- Alignment with the essence of the Data Anomaly Detection feature. 
## User Impact
- An Export button has been added on the Potential Duplicate Patients page (Detect Landing Page > Central Statistical Monitoring (CSM) > Data Veracity > select Potential Duplicate Patients from the left-hand menu). 
- Error Plots has been renamed Data Anomaly Detection.
