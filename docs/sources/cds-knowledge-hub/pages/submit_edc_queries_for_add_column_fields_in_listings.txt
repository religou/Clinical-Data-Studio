# Listings: Submit EDC Queries For Add Column Fields In Listings

## Listings: Submit EDC Queries For Add Column Fields In Listings
## What Is New?
 You can now submit EDC queries for data sets (fields) you add using the Add Column option while creating or editing listings. 
## What Is the Impact?
## Users/Roles
 Data managers. 
## Workflow Process
 No impact to the workflow process. 
## Other Applications
 No impact to other applications. 
## How Do I Benefit?
 Data managers can submit queries for additional datasets used in listings, and get information about EDC data, enabling faster study data reconciliation. 
## Where Do I See the Change?
 On the Data Surveillance tab > Listings page > Approved Listings or Draft Listings tab > for a query-enabled listing, the Query Details section shows fields added using the Add Column option in the listing expression builder. If you then select the relevant form, field, folder, and marking group, you can submit queries for fields added using the Add Column option, for Rave and EDC studies.

## What Else Should I Know?
 You must have the Manage Data Reviewer building block added to your role in Cloud Administration to submit queries for listings.
