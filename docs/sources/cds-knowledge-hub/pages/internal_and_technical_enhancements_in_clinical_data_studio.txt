 User Impact Assessment 
 The impact of the change on system behavior and on the user's interaction with it.
- Low – There is no change to current software behavior.
- Moderate – Change includes corrections or improvements that may change user interaction with the software, such as minor UI or minor functionality changes.
- High – Change includes software changes which require review of existing settings, workflow and/or operational procedures to ensure correct user interaction with the software.
