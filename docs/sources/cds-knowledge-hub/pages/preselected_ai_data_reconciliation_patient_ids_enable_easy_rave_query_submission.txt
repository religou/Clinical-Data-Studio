# Preselected AI Data Reconciliation Patient IDs Enable Easy Rave Query Submission

## Preselected AI Data Reconciliation Patient IDs Enable Easy Rave Query Submission
## What Is New?
 Patient IDs you select in any report, appear as preselected rows in the Submit Queries window when you submit Rave queries on the AI Data Reconciliation page.
## What Is the Impact?
## Users/Roles
 Data Managers.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 You can save time and effort due to preselected patient IDs while submitting Rave queries.
## Where Do I See the Change?
 See the Description section.

## What Else Should I Know?
- Data sets must be mapped in Detect Mapping's Event Analysis and must use   MedDRA and WHODrug coded data set terms. Otherwise, the data sets will not appear in the reports or be processed through AI Data Reconciliation's algorithms. 
- You must have Rave query access to submit Rave queries for AI Data Reconciliation reports. 
 To view Medidata testing documentation for this release, refer to the  Medidata Validation Portal .
