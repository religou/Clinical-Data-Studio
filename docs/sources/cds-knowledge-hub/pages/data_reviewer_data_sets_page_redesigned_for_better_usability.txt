# Data Reviewer Data Sets Page Redesigned For Better Usability

## Data Reviewer Data Sets Page Redesigned For Better Usability
## Description
 Data Reviewer 2023.1.0 includes a redesigned Data Sets page, which provides a improved user experience.
## Affected Roles
 All roles with the View Data building block. 
## Advantages
 You can now locate on screen Data Reviewer components with ease and have a better user experience.

## Special Considerations
- You need the appropriate RAVE access to access patients from within the Data Sets grid in RAVE. 
- You can view a patient's details in RAVE EDC when you click the Patient ID link only if the data set originates in RAVE. 
- To view Medidata testing documentation for this release, refer to the Medidata Validation Portal .
