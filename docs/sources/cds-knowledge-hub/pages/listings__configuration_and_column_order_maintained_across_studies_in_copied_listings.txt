## Change Details
 Product 
 | Clinical Data Studio
 Version 
 | 2026.2.0
 Change Type 
 | Enhancement (Updated Functionality) 
 Functionality or Module 
 | Listings 
 Summary of Changes 
 | 
 The listing configuration, including any specific sequence, and column ordering defined in the source study or template, remains intact when you copy a listing to a new study group. The Add Column toggle prioritizes the listing's expression sequence over source configurations; columns appear in the order they you define while copying listings across study groups. 
 Benefit to Users 
 | Data managers can save time and ensure study data accuracy by copying listings across study environments, without the need to modify column ordering.  
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 Data managers.
 Impact to Workflow Processes 
 No impact to the workflow process.
 Impact to Applications 
 No impact to applications.
 Impact on Interface 
 On the Data Surveillance > Listings page, if you select an approved listing, and click Copy , you can copy the listing across study environments. The listing configuration, column ordering etc is carried forth into the copied listing. 
 Impact to Existing Data or Settings 
 None.
