# Generate Patient Profiles PDF in Bulk Based on Permissions

## Generate Patient Profiles PDF in Bulk Based on Permissions
## Description
 You can export all patient profile designs in a study to PDF in bulk only if you have the appropriate permissions.  
## Affected Roles
 Patient Profile Designers.
## Advantages
 Permission-based bulk PDF generation privileges safeguards the external exchange of patient profiles designs and data between designers and reviewers. 
## User Impact
 On the Design   page >   Elements tab, the   button   displays only if you have permissions to bulk export patient profile designs to PDF. Otherwise, this button does not display. 
 If the   button  displays, you can s elect   All Patients   in the   PDF Export   window, and then click   Export .   When   the requested PDFs  are ready to download, you receive an email with a link to  download a zip file with the study name and current date. The zip file contains separate PDF files for each patient profile in the study that was exported.  The link expires after   seven days. The email   also includes   patient IDs that fail to export to PDF.  
## Special Considerations
  Bulk PDF export p rocessing times may vary depending on the number of patient profiles in your study. The minimum time taken is one hour.
