# Detect Configuration Manager Released Features

## Detect Configuration Manager Released Features
 Detect Configuration Manager is a cloud -based application that serves as a centralized repository for platform-wide standard KRIs and user-defined custom KRIs. You can use Detect Configuration Manager to create and activate custom KRIs for use in Medidata Detect . 
 Detect Configuration Manager includes the following:
 Add and Edit Custom QTLs 
- 
 Add and Edit Custom QTLs in RBQM Configuration Manager 
 Activate and Deactivate QTLs 
- 
 Activate and Deactivate QTLs in RBQM Configuration Manager 
 Add and Edit Custom KRIs 
- 
 Add and Edit Custom KRIs in RBQM Configuration Manager 
- 
 Add and Edit Custom Percentage KRIs 
- 
 Improved Percentage KRI Configuration Logic 
 Activate and Deactivate KRIs 
- 
 Deactivate System KRIs from Displaying in Medidata Detect 
- 
 Activate and Deactivate KRIs in RBQM Configuration Manager 
 Key Risk Indicators Table 
- 
 View, Filter, and Sort the Key Risk Indicators Table in RBQM Configuration Manager
