# PDS: Build Data Listings to Identify Records Present in Rave EDC But Missing from External Lab Data

## PDS: Build Data Listings to Identify Records Present in Rave EDC But Missing from External Lab Data
## What Is New?
 You can build data listings to identify and report patient records that exist in Rave EDC but are missing from external lab data. 
## What Is the Impact?
## Users/Roles
 Data managers
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 You can very quickly and easily reconcile Rave EDC data and external lab data to accurately identify missing lab data. You can then create vendor issues directly from the data listing results to communicate data issues and queries with vendors. This helps ensure that you account for and acquire the lab data you need for your study.
## Where Do I See the Change?
 In the Data Reviewer > Data Listings page > New Listing window or Edit Listing window > Define Listing section, the   Missing Records   toggle button shows on the right side. When you activate the Missing Records button, the   Missing Records   section shows beneath the Definite Listing column. In the Missing Records section, you can build conditional expressions defining the source target datasets and the external datasets you want the data listing to search, compare, and report on.

## What Else Should I Know?
 In the Missing Records section:
- The data set on the left side of the conditional expression must be the source data set; typically the data from Rave EDC. The data set on the right side of the expression must be the target data set; typically external data from the lab. 
- The source data set and the target data set must be the same data type. 
- The list of available source datasets that you can select only include data sets currently used in the core data listing expression. 
- You can only select "=" as the comparator. 
- You can only select AND when building multiconditional missing records expressions. 
- When building multiconditional missing records expressions, the list of target data sets that you can select only includes the data set currently used in the original missing records expression.
