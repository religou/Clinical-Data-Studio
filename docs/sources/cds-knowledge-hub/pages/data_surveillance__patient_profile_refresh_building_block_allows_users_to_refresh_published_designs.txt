# Data Surveillance: Patient Profile Refresh Building Block Allows Users to Refresh Published Designs

## Data Surveillance: Patient Profile Refresh Building Block Allows Users to Refresh Published Designs
## What Is New?
 Data Surveillance now includes the Patient Profile Refresh building block. When assigned the Patient Profile Refresh building block, you can refresh published patient profile designs to reflect the latest available study data .
## What Is the Impact?
## Users/Roles
 Data managers.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 The Patient Profile Refresh building block enables administrations to grant data managers the ability to refresh patient profile designs without granting full patient profile administration rights.
## Where Do I See the Change?
 No changes to the user interface.
