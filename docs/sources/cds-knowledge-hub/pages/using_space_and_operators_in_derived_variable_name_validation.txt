# Using Space And Operators In Derived Variable Name Validation

## Using Space And Operators In Derived Variable Name Validation
## Description
 The derived variable creation workflow now expands Name field validation to disallow blank space and AND/OR operators. 
## Affected Roles
 All roles with the View Data building block.
## Advantages
 The expanded validation ensures that you do not accidentally name derived variables with names such as derived variable and derived AND OR variable .  
## User Impact
 A warning message appears when you attempt to save a derived variable that has a blank space or uses AND/Operators without an underscore in the Name field.
## Special Considerations
 Within a given data set, you can use an  underscore  to add blank space or AND/OR operators to derived variable names. For example,  Sample_dv_and_or_name  is permitted but not Sample dv and or name.
