 Summary of Changes 
 | 
 As highlighted in the Release Newsletter :
 The KRI Dashboard now includes an additional system KRI called Modification Rate. The Modification Rate KRI calculates as:
- (The Total  Number of Data Point Modifications Made by Non-system Users Across All Study Data Sets) / (The Total Number of Data Points Across All Study Data Sets). 
 In other words, the Modification Rate KRI calculates the average number of non-system user (manual) modifications per data point. Clinical Data Studio uses a statistical model to calculate site risk based on the Modification Rate, and the KRI Dashboard color-codes each site KRI value to alert you to the KRI risk level: 
- Red** indicates that the KRI value at the site has an average quantile value of less than 5% or greater than 95% for a given KRI value. This means that there is a strong association indicating that there may be an underlying cause at the site resulting in its KRI value to be an extreme outlier. The risk being monitored may warrant investigation at the site level. 
- Yellow* indicates that the KRI value at the site has an average quantile value between 5% and 15% or between 85% and 95% for a given KRI value. This means that there is a strong association indicating that there may be an underlying cause at the site resulting in its KRI value to be an outlier. The risk being monitored may warrant investigation at the site level. 
- Green indicates that the KRI value at the site has an average quantile value between 15% and 85% for a given KRI value. This suggests that there is nothing about the study data at the site that would raise alarm about the risk being monitored. The site is likely operating and reporting data as expected. 
- Gray indicates that there are fewer than two patients at the site, which is not enough data to determine risk level. 
 Benefit to Users 
 | The Modification Rate KRI helps you identify sites that disproportionately modify data more or less than other sites, and helps you:
- Gauge site-level data entry quality and transcription error rate 
- Determine sites that may require an adjustment to their source data verification (SDV) strategy.

 Anyone who is assigned to track risks can use the Key Risk Indicators table such as CRAs or site users. 
 Impact to Workflow Processes 
 No impact to the workflow process.
 Impact to Applications 
 No impact to other applications.
 Impact on Interface 
 The KRI Dashboard now includes the Modification Rate system KRI listed in the table by default under the Data Collection category.
 Impact to Existing Data or Settings 
 No existing data changes; no configuration or permission updates required.
 Note : The Modification Rate system KRI is activated by default; however, you can deactivate system KRIs .
