 Product

 Version

 Change Type 
 | Enhancement (Updated Functionality)
 Functionality or Module

 Summary of Changes 
 | 
 As highlighted in the Release Newsletter : 
 The Signals table now shows two new columns, Issue Type and Target Issue that show improved issue visibility.
 Benefit to Users 
 | Central monitors, CRAs, and study managers can identify if an issue is a protocol deviation or a non-protocol deviation and whether it was sent to an external issue management system or resolved internally within Signals, and filter to find signals of interest.
 Summary of User Impact 
 | 
 Impact to Users and Roles 
- Central Monitors and Central Statistical Monitors, Clinical Research Associates. 
- Users with View Signals and Manage Signals building blocks. 
 Impact to Workflow Processes 
 No impact to workflow processes.
 Impact to Applications 
 No impact to other applications.
 Impact on Interface 
 The Signals table includes two new columns: 
- I ssue Type : The column indicates if the signal issue is a protocol deviation or non-protocol deviation type. 
- Target Issue: The column reads External or Internal, indicating if the signal issue is sent to an external issue management system, or resolved internally within the Signals UI. 
 Impact to Existing Data or Settings 
 No existing data changes; no configuration or permission updates required.
