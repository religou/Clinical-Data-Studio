# Derived Variables Updates

## Derived Variables Updates
## What Is New?
 Added validation for derived variables, which ensures that "source" and "target" fields match, and they represent the same variables. 
## What Is the Impact?
## Users/Roles
 Data managers.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Provides target field validation for merge type derived variables.
## Where Do I See the Change?
 Detect >  Derived Variables > Create Derived Variable > Derived Variable Type > Select Merge 
## Where Do I Learn More?
 The Detect Knowledge Space provides content to support this feature/enhancement: 
 Derived Variables 
## What Else Should I Know?
 Only effects merge type derived variables.
