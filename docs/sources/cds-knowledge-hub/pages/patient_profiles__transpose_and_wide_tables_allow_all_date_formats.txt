## Change Details
 Product 
 | Clinical Data Studio
 Version 
 | 2026.1.0
 Change Type 
 | Enhancement (Updated Functionality)
 Functionality or Module 
 | Patient Profiles 
 Summary of Changes 
 | 
 Transpose and wide table elements in any patient profile design now include all date formats.
 Benefit to Users 
 | 
 Data managers can build profile designs with transpose and wide tables using any date format. 
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 Data manager. 
 Impact to Workflow Processes 
 No impact to workflow processes.
 Impact to Applications 
 No impact to other applications. 
 Impact on Interface 
 On the Data Surveillance > Patient Profiles > Draft Designs page, if you click Create Design , and then click Add Elements , you can add any date format while adding wide or transpose tables. 
 Impact to Existing Data or Settings 
 No existing data changes; no configuration or permission updates required.
 User Impact Assessment 
 | Low
