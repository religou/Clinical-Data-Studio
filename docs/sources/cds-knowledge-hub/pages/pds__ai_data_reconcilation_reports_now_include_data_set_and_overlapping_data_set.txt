# PDS: AI Data Reconcilation Reports Now Include Data Set and Overlapping Data Set

## PDS: AI Data Reconcilation Reports Now Include Data Set and Overlapping Data Set
## What Is New?
 AI Data Reconciliation includes the following enhancements:
- All reports include the Data Set column. 
- The Overlapping Conditions report, Overlapping Non-worsening Conditions and Ongoing MH report, and Overlapping Treatment report include the Overlapping Data Set column. 
- The Same Timeframe Treatments slide-out panel includes the Data Set column. 
## What Is the Impact?
## Users/Roles
 Data managers.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 You can quickly determine which data sets and overlapping data sets the report finding are associated with.

## What Else Should I Know?
 Data sets must be mapped in Detect Mapping's Event Analysis and must use   MedDRA and WHODrug coded data set terms. Otherwise, the data sets will not appear in the reports or be processed through AI Data Reconciliation's algorithms. 
 To view Medidata testing documentation for this release, refer to the  Medidata Validation Portal .
