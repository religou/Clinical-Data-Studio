## Change Details
 Product 
 | Clinical Data Studio
 Version 
 | 2026.1.0
 Change Type 
 | Technical Change
 Functionality or Module 
 | Oncology 
 Summary of Changes 
 | 
 You can now refresh data on the RECIST dashboard up to two times per day.
 Benefit to Users 
 | Data managers can observe an improved performance and no data degradation due to the new limit of two refreshes per day. 
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 Data managers.
 Impact to Workflow Processes 
 No change to workflow process.
 Impact to Applications 
 No impact other applications.
 Impact on Interface 
 The Data Refresh button at the top right corner of the Data Surveillance > Oncology page, gets disabled after two successful refreshes per day.
 Impact to Existing Data or Settings 
 No existing data changes; no configuration or permission updates required.
 User Impact Assessment 
 | Medium

- Updated Article: Refresh RECIST 1.1 Dashboard Data.
