# Add Listings, KRIs, and QTLs as Templates to Template Groups

## Add Listings, KRIs, and QTLs as Templates to Template Groups
 You can add and store listing, QTL,  custom numeric KRI, or custom percentage KRI configurations as templates to study-level template groups. Adding and using specific listings, QTLs, and custom KRIs as templates: 
- Enables you and your team to quickly and easily reapply common data listings ,  QTLs, and custom KRIs as needed across study configurations. 
- Promotes faster study start time. 
- Ensures consistency and accuracy in listing ,   QTL, and custom KRI details across studies. 
 Note : You need the Manage Data Reviewer building block to add listings as templates. You need the Manage Detect Templates and View Detect Templates buildilng blocks to add QTLs and KRIs as templates. 
 For more information see Data Surveillance Building Blocks and Permissions .
## Add Listings as Templates to Template Groups
- 
 If necessary, access the Manage Listing page. 
- Access Data Surveillance , and then click Listings in the left-hand menu.
The Data Listings page shows. 
- Click Manage Listing on the upper-right side of the Data Listings page.
 The Manage Listing page > Listings table shows all draft and approved listings in your study and each listing's associated details. 
- In the Listings Manager page > Listings table, select the listing that you would like to store as a template. 
- Click Export as Template . 
- Select the Template Group within your organization's global template library where you would like to store the listing template. 
- Enter a Name . 
- Click Export .
A confirmation message appears at the top of the page. You can now find the listing template in your organization's global template library stored in the selected template group. You can also now import and use the listing template when creating listings in other studies across multiple client divisions (CD) . 
## Add Custom Numeric QTLs as Templates to Template Groups
 You can add and store QTL  configurations as templates to study-level template groups. Adding and using specific custom QTLs as templates:
- Enables you and your team to quickly and easily reapply common custom QTLs as needed across study configurations. 
- Promotes faster study start time. 
- Ensures consistency and accuracy in custom QTL details across studies. 
 To learn more about templates, see Data Surveillance Template Library .
- Access RBQM , and then click Configuration > QTLs in the left-hand menu.
- On the Quality Tolerance Limits page, click any QTL name in the Parameter column.
 Note : You can only export existing custom QTLs as a template. When creating custom QTLs, you must first save the QTL, and then open the QTL from the table on the QTL listing page > QTL Configurations tab.
- At the bottom of the Quality Tolerance Limit window, click Export as Template . 
- Select the Template Group within your organization's global template library where you would like to store the custom QTL template.
 The list of template group names   shows in parentheses the client division name that the template group belongs to. 
 Tip : For more information about template groups, see  View, Add, and Manage Template Groups .
- Optional : If necessary, update the Template Name . 
- Click Export .
A confirmation message appears at the top of the page. You can now find the QTL template in your organization's global template library stored in the selected template group. You can also now import and use the QTL configuration template when creating QTLs in other studies within the same client division (CD) . 
## Add Custom KRIs as Templates to Template Groups
 You can add and store custom numeric KRI or custom percentage KRI  configurations as templates to study-level template groups. Adding and using specific custom KRIs as templates: 
- Enables you and your team to quickly and easily reapply common custom KRIs as needed across study configurations. 
- Promotes faster study start time. 
- Ensures consistency and accuracy in custom KRI details across studies. 
 To learn more about templates, see Data Surveillance Template Library .
- Access RBQM , and then click Configuration > KRIs in the left-hand menu.
- In the Configuration and Reporting card, click KRI Configuration . 
- On the KRI Risk Indicators page > KRI Configurations tab, click any custom numeric or percentage KRI in the Name column.
 Note : You can only export existing custom KRIs as a template. When creating custom KRIs, you must first save the KRI, and then open the KRI from the table on the KRI Risk Indicators page > KRI Configurations tab.
- At the bottom of the Custom Numeric KRI or Custom Percentage KRI window, click Export as Template . 
- Select the Template Group within your organization's global template library where you would like to store the custom KRI template.
 The list of template group names   shows in parentheses the client division name that the template group belongs to. 
 Tip : For more information about template groups, see  View, Add, and Manage Template Groups .
- Enter a Template Name . 
- Click Export .
A confirmation message appears at the top of the page. You can now find the custom KRI template in your organization's global template library stored in the selected template group. You can also now import and use the KRI configuration template when creating custom KRIs in other studies within the same  client division (CD) .
