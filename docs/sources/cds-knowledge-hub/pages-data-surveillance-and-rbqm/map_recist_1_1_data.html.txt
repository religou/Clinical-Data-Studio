# Map RECIST 1.1 Data

## Map RECIST 1.1 Data
 The RECIST 1.1 Dashboard is a visualization and reporting tool that captures treatment response and disease progression metrics for patients in oncology studies based on the Response Evaluation Criteria in Solid Tumors ( 
 RECIST 1.1 
 ) methodology.  With t 
 he RECIST 1.1 Dashboard you can: 
- Quantify tumor burden and outcome calculations for patients. 
- Summarize the total count of patients, and those in various stages of treatment response at the selected scan visit type and site. 
- Track tumor burden over a period, and identify discrepant records. 
- Assess the accuracy of RECIST 1.1 calculations and safety monitoring. 
 With Oncology Mapping, you can configure the variables from data sets in your study environment which Data Surveillance's microservice algorithms consume. Based on the analytics and configuration, the RECIST 1.1 Dashboard generates configuration data analysis and produces visualization output as waterfall and spaghetti plots. 
 Note : We recommend you map data on the RECIST tab only if you have access to the RECIST 1.1 Dashboard in Data Surveillance.
- Access Data Surveillance or RBQM , and then click Configuration > Data Mapping in the left-hand menu.

 Note :
- You can select mapped variables, including derived variables, from different data sets to map to the reference source fields.  However, derived variables created within Data Surveillance for the Visit Date field, do not work as they are not enriched fields. For  derived variables created in Data Connect, you must activate the dataset using the same variable as the Visit Date. This enables the Visit Date to appear as the Performed Event Date in Data Surveillance.
- If the Longest Diameter Unit or Short Axis Diameter Unit fields are empty, Data Surveillance uses  millimeter (mm)  as the unit of measurement.
- If diameter field has a "not recorded" value in Medidata Rave, it stores as a ND/ NA/ UK value. You must configure derived variables to store ND/NA/UK values as null values in the diameter fields to produce the RECIST 1.1 Dashboard.
