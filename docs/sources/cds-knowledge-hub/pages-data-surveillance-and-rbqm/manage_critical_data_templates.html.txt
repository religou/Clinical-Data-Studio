# Manage Critical Data Templates

## Manage Critical Data Templates
 RBQM administrators can create study-level critical data templates for critical data elements that the study team plans to include in the risk assessment for multiple studies.
 RBQM administrators can also update template details and activate and deactivate critical data templates for use across all studies in the study group.
 Using critical data templates:
- Reduces time and effort when creating risk assessments. 
- Ensures accurate, consistent critical data details across multiple studies. 
 Note : Study users create critical data at the study level. If study users want to copy a template for use in a study, the RBQM administrator must first activate the template.

## Create a Critical Data Template
- Access your study-level Critical Data Templates Library . 
- Click  Create Template .
- Enter values for these fields:
- Name - Enter up to 255 characters as the name of the Critical Data template, for example, Tumor Assessment. 
- Category - This is a required field.

- Group Name - Enter up to 225 characters describing the type of critical data, for example, Oncology. The group name does not have to be unique and can be used to group similar critical data entries. 
- Description - Enter up to 3000 characters to provide a more detailed description of the critical data. For example, "CT scan of a tumor at visit 5." This description appears when your mouse hovers over the name in the critical data listing page. 
- Rationale - Enter up to 3000 characters to provide the reason for using the critical data. For example, "Data supports the primary endpoint of the study." 
- Click Save .
 Note : B efore making the template available to the studies, you must activate it by moving the gray toggle to the right so it turns blue .  
## Activate or Deactivate a Critical Data Template
 You must activate a template before it can be used in a study.
- Access your study-level Critical Data Templates Library . 
- To activate a template, find the template you want to activate and move the toggle in the Activate column from gray  to blue .
- To deactivate a template, find the template you want to deactivate and move the toggle in the Activate column from blue to gray . 
 Note : Click All to activate or deactivate all templates in the list.
## Edit a Critical Data Template
 You must deactivate a template before you can edit it.
 Note : For templates that are activated, the OK button appears at the bottom instead of Save . Activated templates are read-only at the study group level.
- Access your study-level Critical Data Templates Library . 
- Ensure the toggle in the Activate column is gray  before you select the template to be edited. 
- Change the field values in the template. 
- Click Save . 
## Delete a Critical Data Template
 The Delete button only appears for a template that is deactivated and has never been activated in the past.
- Access your study-level Critical Data Templates Library . 
- Select the template to be deleted. 
- Click the Delete button.
The message, "Critical Data Template deleted successfully," confirms deletion of the template.
