# Generate Data Anomaly Detection Plot Audit Reports

## Generate Data Anomaly Detection Plot Audit Reports
 You can generate audit reports to view the history of: 
- Issues created on the study's top 100 outlier data points. 
- Track review actions made on the study's top 100 outlier data points. 
 Audit reports:
- Enable sponsors to quickly and easily show compliance with clear, comprehensive audit details of actions performed in Statistical Monitoring. 
- Provide sponsors with greater oversight to ensure study data is being monitored correctly. 
- Allows for a quick view of the review status of Data Anomaly Detection points in bulk in tabular format. 
- If necessary,  Access the Data Anomaly Detection page . 
- Click next to the Data Anomaly Detection page header.
A new browser tab opens to the Audit Viewer > Medidata Detect Plots Audit Report page.
 Tip : In Audit Viewer, you can click Export and then  Excel , CSV , or PDF to view the report offline or sort data by column headings.
