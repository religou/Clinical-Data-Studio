# Merge Variables to Data Sets

## Merge Variables to Data Sets
 You can merge a data set variable from one data set into a target data set. The target data set  lists the merged data set variable as a derived variable within the variable list. Use Merge derivations to bring variables from one dataset into another, that is, to m erge a  data set variable   from one data set into a target data set.   These derivations vary depending on which types of datasets you use to perform the merge (multiple record per patient datasets vs. single record per patient datasets). When merging from MRPP to MRPP, a “linking” variable must be present in the dataset to ensure the merge functions as designed. 
   In Data Surveillance and RBQM, the list of available datasets and variables that you can view and select from include derived variables at the bottom of the list.   Merging options include: 
- Single-Record Variable to Single-Record Data Set  – Merge a data set variable containing singular records over multiple visits with another data set containing singular records over multiple visits. For example, merging a Demographics data set variable to the Eligibility Criteria data set. 
- Single-Record Variable to Multiple-Record Data Set  – Merge a data set variable containing singular records over multiple visits with another data set containing multiple records over multiple visits. For example, merging a Demographics data set variable to the Adverse Events data set. 
- Multiple-Record Variable to Single-Record Data Set  – Merge a data set variable containing multiple records over multiple visits with another data set containing singular records over multiple visits. For example, merging an Adverse Events data set variable to Demographics data set. 
- Multiple-Record Variable to Multiple-Record Data Set  – Merge a data set variable containing multiple records over multiple visits with another data set containing multiple records over multiple visits. For example, merging an Adverse Events data set variable to the Chemistry data set.
