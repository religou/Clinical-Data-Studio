# Data Surveillance and RBQM

## Data Surveillance and RBQM
 Data Surveillance and RBQM are   comprehensive data and risk surveillance   software capability suites   provided by the Clinical Data Studio solution. Data Surveillance encompasses a drag-and-drop listings builder, automated query generation for Rave sourced data, issue management for non-Medidata sourced data, AI-powered data reconciliation, patient profiles, and visualizations. RBQM   supports a holistic   risk-based quality management (RBQM)   approach to data quality.
