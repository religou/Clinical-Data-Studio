# Investigate Data Using Data Anomaly Detection Plots

## Investigate Data Using Data Anomaly Detection Plots
 You can use the various Data Anomaly Detection features and capabilities to help you to determine outliers , anomalies, risks, and trends in your study data. 
 Tip : Data Anomaly Detection visualizations and capabilities vary depending on the type of data analysis Statistical Monitoring applies to the variables you select to view. Therefore, being able to identify which data analysis you are viewing in a Data Anomaly Detection plot helps you effectively use and interpret plots.
 While reviewing Data Anomaly Detection plots, you can:
- View individual patient profiles 
- Flag, track, and audit reviewed study data 
- View Rave Queries in Data Anomaly Detection Plots 
- Log, track, and manage issues   discovered based on Statistical Monitoring's data analysis. 
 Note: Last Updated Timestamp
 The Last Updated timestamp reflects the date and time when the most recent data snapshot generation process started. It does not represent the date and time when the data in Data Anomaly Detection was last refreshed. Therefore, the Last Updated timestamp may be earlier than the time at which the refreshed data becomes available in Data Anomaly Detection.

## Sort, Filter, and Zoom In on Data Anomaly Detection Data
 The Data Anomaly Detection visualization tool provides a unique set of plot sorting, filtering, and zoom options based on which type of data analysis RBQM applies to the selected variable. You can use the sorting, filtering, and zoom options to:
- View and interpret your study data from multiple view points,  
- Find and drill down on specific data. 
 Click a data analysis type below to learn how you can sort, filter, and zoom in on plot data based on which type of data analysis you are viewing.
 Text Analysis 
 Sort the Plot Data 
 You can sort the data in the Text Analysis plot visualization using the following options:
- High - Low Score – Shows text values on the x-axis from left to right in descending order based on error score. That is, the text values with the highest error scores show the left; the text values with the lowest error scores show on the right. This is the default plot setting. 
- Low - High Score – Shows text values on the x-axis from left to right in ascending order based on error score. That is, the text values with the lowest error scores show on the left; the text values with the highest error scores show on the right. 
- Alphabetical Text – Shows text values on the x-axis from left to right alphabetically in ascending order; that is, from A on the left to Z on the right. 
 Tip : Click Reset Plot to reset to the default High - Low Score filter view.
 Filter the Plot to Display Specific Country-, Site-, or Patient-related Data Points 
 By default, the plot shows the frequency with which each text value occurs within the selected variable. But you can also drill down further and filter the plot to view only data points that correspond with a specific country, site, or patient. 
- Navigate to the Summary section below the plot visualization.
 Note : By default, the plot shows all data points associated with the selected variable
- Do any of the following:
 Filter the plot to display specific country-related data points 
- Click the View By filter, select Country , and then either select a country from the Country  filter or click a specific country's row in the table. 
 Filter the plot to display specific site-related data points 
- Click the View By filter, select Site , and then either select a site from the Site filter or click a specific site's row in the table. 
 Filter the plot to display specific patient-related data points 
- Click the View By filter, select Patient , and then either select a patient ID from the Patient  filter or click a specific patient's row in the table below. 
- Click the View By filter, select Data: Top 100 Outliers , and then either select a patient ID from the Patient  filter or click a specific patient's row in the table. 
 Based on your filter selection, the plot visualization highlights the specified country, site, or patient-related data points and dims all other data points. 
 Numeric Analysis 
 Filter the Plot to Display Data Based on Range and Outliers 
 You can filter the Numeric Analysis plot visualization using the following options:
- Outer Values – Filters the plot so that only data points that are outside of the interquartile range show. For example, if a plot contains a high volume of data points, then you can use the Outer Values filter to show only data that is outside of the interquartile range to help you focus more on the data you need. 
- Outliers – Filters the plot to show only outlier data points. Selecting this option helps you better identify anomalies in your study data that may require further investigating or reporting. 
- Box Plot – Filters the plot to show the plot's lower whisker value, 25th percentile value, median value, 75th percentile value, and upper whisker value. Using the Box Plot filter helps you better see the variable's distribution of data. 
 Tip : Click Reset to reset to the default filter view. The default visualization shows all data points and the box plot and whiskers.

## Interpret Data Anomaly Detection Plots
 Your proficiency in reading and understanding Data Anomaly Detection plots greatly affects your ability to determine outliers , anomalies, risks, and trends in your study data. This determination helps ensure you take efficient, well-informed follow-up actions in how you further investigate or report your study data findings.
 Click a data analysis type below to learn how to interpret the plot based on which type of data analysis RBQM applies to the variable.
 Text Analysis Plot 
- The Y-axis shows the error or discrepancy score . 
- The X-axis show each unique text value as entered by the patients in the eCRF for the selected variable. By default, the text values list from highest error score to the lowest error score. 
- The number of times that the text value occurs within the variable shows on the plot in a blue rectangle, orange hexagon, or red pentagon. For example, . 
- Each color-coded shape is defined below:
- Blue Rectangle   – The text value's error score is less than 2.95. This means that the text value has a statistically normal number of occurrences within the variable. 
- Orange Hexagon   – The text value's error score is between 2.95 and 4.95. This means that the text value has a higher- or lower-than-normal number of occurrences within the variable. Thus, RBQM considers the data type an outlier. 
- Red Pentagon   – The text value's error score exceeds 4.95. This means that the text value has a significantly higher- or lower-than-normal number of occurrences within the variable. Thus, RBQM considers the data type an extreme outlier. 
- You can hover your cursor on a blue square, orange hexagon, or red pentagon to view the text value name and its error score. 
- You can click a blue square, orange hexagon, or red pentagon to display additional information about that data point in a separate panel to the right of the plot.
 Field Descriptions 
- Data Point  – The selected data point's raw text value as entered by the patients in the eCRF for the variable. 
- Data Point Score – A numeric score generated by Statistical Monitoring's high-dimensional data anomaly detection algorithms , which measures the discrepancy of an individual data point relative to the overall study data. Data point scores help you uncover outliers, anomalies, risks, and trends in your study data, which may require follow-up action. An error score of less than 2.95 indicates statistically normal data; between 2.95 and 4.95 indicates outlier data; exceeding 4.95 indicates extreme outlier data. 
- Occurrences  – The combined total number of times in which all patients entered the text value for the selected variable. 
- Patient  –  The patient ID for the patient represented in the data point.  
- Site  – The site the patient belongs to.   
- Country  –  The country in which the patient's site is located. 
- #  – The number of times the text value occurred per individual patient represented in the selected data point. 
- X  – Located in the upper-right hand corner of the panel. Click to close the panel. 
- The dotted red line, , represents the outlier threshold  and spans across the plot at the 2.95 error score mark. All text value data points positioned above the line are outliers. All text value data points below the line are in the normal range. 
 Numeric Analysis Plot 
- Each patient data point on the plot is represented by a blue square, orange circle, or red diamond:
- Blue Square  – The patient data point's  discrepancy score is less than 2.95. This means that the patient data point has a statistically normal numeric value within the variable. 
- Orange Circle   – The patient data point's discrepancy score is between 2.95 and 4.95. This means that the patient data point has a higher- or lower-than-normal numeric value within the variable. Thus, RBQM considers the numeric value an outlier. 
- Red Diamond   – The patient data point's discrepancy score exceeds 4.95. This means that the patient data point has a significantly higher- or lower-than-normal numeric value within the variable. Thus, RBQM considers the numeric value an extreme outlier. 
- You can hover your cursor on any blue square, orange circle, or red diamond to view the following data point-specific information:
- Patient  – The patient ID for the patient represented in the data point.  
- Value  – The raw value entered in the eCRF for the patient with regards to the variable. 
- Site  – The site the patient belongs to. 
- Country  – The country in which the site is located.

Discrepancy scores help you uncover outliers, anomalies, risks, and trends in your study data, which may require follow-up action. An error score of less than 2.95 indicates statistically normal data; between 2.95 and 4.95 indicates outlier data; exceeding 4.95 indicates extreme outlier data.

 Columns When Viewing By Data: Top 100 Outliers 
- Patient  –  The patient ID for the patient represented in the data point.  
- Country –  The country in which the patient's site is located. 
- Site  –  The site the patient belongs to. 
- <variable 1>   – The text or numeric value represented on the data anomaly detection plot's X-axis. 
- <variable 2> – Only appears on plots that compare two variables. This represents the second text or numeric value represented on the data anomaly detection plot's X-axis when the data anomaly detection plot shows text versus text , numeric versus numeric , or numeric versus text analysis . 
- Discrepancy Score   – A numeric score generated by Statistical Monitoring's high-dimensional data anomaly detection algorithms , which measures the discrepancy of an individual data point relative to the overall study data. Discrepancy scores help you uncover outliers, anomalies, risks, and trends in your study data, which may require follow-up action. An error score of less than 2.95 indicates statistically normal data; between 2.95 and 4.95 indicates outlier data; exceeding 4.95 indicates extreme outlier data.

 Filter the Plot to Display Specific Country-, Site-, or Patient-related Data Points 
 By default, the data anomaly detection plot shows all data points associated with the selected variable. But you can also drill down further and filter the plot to show only data points that correspond with a specific country, site, or patient. 
- Navigate to the Summary section below the plot visualization.
 Note : By default, the plot shows all data points associated with the selected variable.
- Do any of the following:
 Filter the plot to display specific country-related data points 
- Click the View By filter, select Country , and then either select a country from the Country  filter or click a specific country's row in the table. 
 Filter the plot to display specific site-related data points 
- Click the View By filter, select Site , and then either select a site from the Site filter or click a specific site's row in the table. 
 Filter the plot to display specific patient-related data points 
- Click the View By filter, select Patient , and then either select a patient ID from the Patient  filter or click a specific patient's row in the table. 
- Click the View By filter, select Data: Top 100 Outliers , and then either select a patient ID from the Patient  filter or click a specific patient's row in the table. 
 Based on your filter selection, the data anomaly detection plot visualization highlights the specified country-, site-, or patient-related data points and dims all other data points.

## Flag, Track, and Audit Reviewed Study Data
 You can mark outlier data points on plots as reviewed. Marking outlier data points as reviewed helps you and other team members identify which data has or has not been reviewed. This optimizes your overall team performance by preventing repeat work and helping your team recognize and focus on the data that still requires review.
 To learn more, see  Flag, Track, and Audit Reviewed Study Data .
## Log and Track Issues
 Authorized users working in Statistical Monitoring can log, track, and manage  issues while jointly reviewing Statistical Monitoring's study data analysis.   This yields the following benefits: 
- Streamlined issue logging. 
- Reduced recurrence of duplicate issues. 
- Clear line of sight of site or country  issues and issue status. 
- Reduced time and cost required to create and manage issues. 
- Enhanced work experience and productivity in a centralized location. 
- Improved ability to identify and mitigate risks to protocol compliance, patient safety, data integrity, and overall study quality. 
 Important : You  can only view or create issues for sites and countries assigned to you. 
 To learn more, see  Create, View, and Edit Issues from Data Anomaly Detection Plots .
