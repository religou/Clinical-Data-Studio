# Configure Modules To Assess Performance Metrics

## Configure Modules To Assess Performance Metrics
 The Task Oversight dashboard is a singular place to understand key operational activities like set up, data import, refresh, and data review as documented in Data Connect and Data Surveillance. You can configure modules whose performance metrics you want to track to appear on the dashboard.  
 Note : You need   View CDS Task Oversight added to your Cloud Administration profile to view Task Oversight. For more information, see Data Surveillance Building Blocks and Permissions .
## Configure Modules
 The slide-out panel now allows you to view and select all approved listings, all published patient profile designs, and custom graphs in the study, showing them, five at a time. You can also search or filter by specific names, for example   Listing124 . 
- Access Task Oversight. 
The Task Oversight dashboard appears.
 Note : The first time you login, the dashboard shows modules you have access to from the following:
- Patient Profiles. 
- AI Reconciliation. 
- Listings. 
- Custom Graphs 
- Vendor Queries, and 
- Data Connect. 
- Click Configure Widgets .
The Select Metrics to Display slide-out panel appears. 
- Select the modules you what to show metrics for:
- Patient Profiles. 
- AI Reconciliation. 
- Listings. 
- Custom Graphs. 
- Vendor Queries, and 
- Data Connect. 
- Click Apply .
Task Oversight shows your chosen modules and saves your preferences. The dashboard automatically shows the selections every time you log in.
 Note : You must select at least one module. 
## Assess Performance Metrics
 Each module you configure shows performance metrics relevant to actionable insights. Updates made to records, such as marking listings as reviewed or unreviewed, or similar actions in any of the modules, reflects in the metrics shown on the Task Oversight dashboard instantly.
