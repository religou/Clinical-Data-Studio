# Schedule or Trigger When KRI Dashboard Refreshes and Outputs the Latest Study Data Analysis

## Schedule or Trigger When KRI Dashboard Refreshes and Outputs the Latest Study Data Analysis
 Users with the proper permissions can: 
- Schedule when and how often the KRI Dashboard renders and reflects a specific study's latest study data analysis.  
- Manually trigger the KRI Dashboard to render and reflect a specific study's latest study data analysis. 
 When a refresh successfully processes:
- All users receive a notification email. 
- The notification is posted in the Medidata Notification Center. 
 Important : KRI Dashboard data refreshes occur independently and separately from data refreshes that occur in other RBQM capabilities such as QTL Dashboard and Statistical Monitoring.
 In Data Surveillance and RBQM, s tudy data automatically refreshes four times daily at approximately 9:00am (EST), 3:00pm (EST), 9:00pm (EST) and 3:00am (EST), and the data presented within the user interface is current as of 11:00 pm (EST) the previous day, 5:00 am (EST) the same day, 11:00 am (EST) the same day, 5:00 pm (EST) the same day, respectively. Each study data refresh produces a data snapshot. Updated data from Medidata Rave and activated datasets from Data Connect are available in 6 to 12 hours within Data Surveillance and RBQM. For more information, see Clinical Data Studio's Data Pipeline. 
## Set Data Refresh Schedule
 Users with the proper permissions can schedule when and how often the KRI Dashboard renders and reflects a specific study's latest study data analysis. Therefore, you can control when the KRI Dashboard renders your latest batch of study data to accommodate  your organization's data review schedule and pace. 
 Important : Only authorized users can view the KRI Scheduler page and set the data refresh schedule. 
- Access RBQM , and then click KRIs in the left-hand menu.
The KRI Dashboard shows . 
- Click KRI Scheduler .
- Select the following:
- Refresh Schedule – Select the frequency in which you want RBQM to trigger the data refresh. 
- Start  – Select the time of the month that you want the data refresh to trigger. The Start menu only appears if you select a Monthly , Bi-Monthly , or  Quarterly frequency. 
- Day  – Select the weekday within the specified weekly, monthly, or quarterly cadence that you want the data refresh to trigger. The Day menu does not appear if you select First Day of the Month or Last Day of the Month from the Start menu.
 Tip: Display This Week's Latest Study Data
 To show the current week's latest data, select the Weekly frequency, and then select the weekday that is two days ahead of the current day. For example, if today is Tuesday and you want to view the latest data for this week, select the Weekly frequency, and then select Thursday .
- Click Save .
 The KRI Dashboard will automatically, periodically refresh to show visual renderings of the latest study data analysis as scheduled.
 Note : The KRI Dashboard only refreshes if new or updated study data is uploaded for use in RBQM since the last successful data refresh.

 Depending on study data volume, there may be lag time between when the data refresh triggers and when the updated data renders in the KRI Dashboard. So newly rendered data analyses that you view in the KRI Dashboard can reflect the data snapshot from a day or two prior.

## Stop or Suspend Scheduled Data Refreshes
 You can discontinue or suspend scheduled data refreshes from occurring for closed studies or studies undergoing database lock or data clean up. 
- Access RBQM , and then click KRIs in the left-hand menu.
The KRI Dashboard shows . 
- Click KRI Scheduler . 
- In Refresh Schedule , select  None . 
- Click Save .
