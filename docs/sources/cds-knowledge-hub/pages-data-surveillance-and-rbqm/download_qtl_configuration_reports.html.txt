# Download QTL Configuration Reports

## Download QTL Configuration Reports
 You can download quality tolerance limits (QTL)  configuration reports, which contain pertinent configuration information about the QTLs in your study environment. The reports provide configuration details in a clear, easy-to-read, and exchangeable format.
- Access RBQM , and then click Configuration > QTLs in the left-hand menu.
- On the Quality Tolerance Limits page, click Report .
The Detect Configuration Manager - Config Report - QTLs XLS file downloads to your machine 
- Open the file.
 Column Descriptions 
- Parameter  – A study variable that is assessed at the study level. 
- Definition  – A dditional details that explain what the parameter is meant to monitor and how it is measured. 
- Status  – Indicates whether the QTL is currently active or inactive. Active QTLs are set so that their data gets filtered, calculated, and shown in the QTL Dashboard, Risk Assessment, and Risk Inventory . Inactive QTLs do not get calculated or shown in the QTL Dashboard, Risk Assessment, and Risk Inventory. 
- Expectation  – T he QTL's expected median value based on historical data. 
- Trigger Point – The minimum required number of patients that meet the QTL's conditions for RBQM to analyze and output the QTL's results in RBQM. 
- Final Population – Total number of patients expected to enroll in the study. 
- Numerator Expression – Details the numerator query's full condition set configured for the QTL. 
- Denominator Expression – Details the denominator query's full condition set configured for the QTL. 
- Date Added – The date the QTL was originally created. 
- Updated By – The person who last updated the QTL configuration. 
- Date Updated – The most recent date that the QTL configuration was updated. 
- Modification Note – The reason that the QTL configuration was updated. 
- Deactivation Date – The most recent date that the QTL was deactivated. 
- Deactivation Note – The reason the QTL was last deactivated. 
- Deactivated By – The person who deactivated the QTL.
