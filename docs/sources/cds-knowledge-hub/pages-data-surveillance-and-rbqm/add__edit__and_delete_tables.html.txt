# Add, Edit, and Delete Tables

## Add, Edit, and Delete Tables
 Tables are containers of study information that allow you to display subject data of up to 12 variables. You can add the following types of tables to your profile designs:
- Wide table 
- Patient information table 
- Transposed table 
## Wide Tables
 A wide table allows for up to 12 columns of data. You create wide tables for multiple record datasets that you do not need to display in a timeline, such as medical history. All data in a wide table must come from the same data set.
 You can: 
- Add wide tables to your design. 
- Copy wide tables between studies. 
- Select to display wide tables in a timeline and configure the timeline display  options. 
- Select to display numeric data in your timeline as a graph and configure the graph display  options. 
- Configure wide table display and highlight conditions. 
- Remove display and highlight conditions. 
- Append a single note to display at the bottom of the table in the patient profile view. 
- Resize the column width. 
- Edit wide table details, such as:
- Rename wide tables, 
- Rename variables, 
- Change a variable's placement within the table, and 
- Remove variables from tables.

## Display Wide Tables in Timelines
 You can select to display the data in your wide table in a timeline. Timelines allow you to visually compare specific data points over the duration of a study in a single output. For example, you can view visit dates, study days, adverse events, con meds, dosing, and so on in a single visual element. 
 Furthermore, timelines allow you to:
- effectively compare data against each other, and  
- view correlations in one output rather than having to cross-reference multiple data sets.

## Configure Wide Table Element Display Conditions
 You can configure tables and timelines to display  on a conditional basis. We provide this functionality because sometimes there are situations where an element is created to display data that may not apply to all subjects. For example, if an element is created to display pregnancy status data points, then you would want the element to only display  data that applies to female subjects.
 Therefore, you can create conditions—such as “dem.gender=Female”—so that Medidata Patient Profiles knows to hide this particular element in reports for male subjects. As a result, taking the previously mentioned example, the report will not display  an empty timeline for male subjects. This yields a cleaner, more aesthetic looking report.
 When adding or editing a wide table, do the following:
- To the right of the Wide Table section, click  Table Options .
- In the Conditional Options section, click   next to Element .
 Note : If display  condition variables are missing, a yellow marker appears next to Element . On hovering over the yellow marker, a message "This data variable does not exist in this study and needs to be replaced or removed." appears. 
- Click-and-drag a variable from the data sets, and then drop the variable in the Variable column. To use variables used in configuring wide tables to build display  conditions, see  Conditional Options In Tables Restored .
- Select an  Operator . 
- Select a  Value . 
- Click  , and select an expression. 
- Click  OK . 
- Click  Save  in the Wide Table section. 
 Note :  You can use conditional display  options with Hide "No Data" Elements to hide wide tables with no data. For more information, see  Hide Elements with No Data . 
## Configure Wide Table Row Display Conditions
 When designing profiles, there may be times when you must display the same data in two tables, but you must apply opposing conditions to the rows containing that data. For example, if you want to show significant adverse events (AE) in one table and nonsignificant adverse events in another table. In such case, you can build two tables with the same AE data set variables. On the first table, you can build a condition with ae.SAE=Yes. On the second table, you can have the condition of ae.SAE=No.
 Another example of applying row display conditions is if you know an adverse event table will have empty records, but it is unnecessary to display "No Data." You can create a condition where:
 "ae.AE Term = is not missing AND ad.AE Start Date = is not missing". 
 As a result, empty rows do not display  in the report.
 When adding or editing a wide table, do the following:

- In the Conditional Options section, click   next to  Row .
 Note : If display  condition variables are missing, a yellow marker appears next to Row . On hovering over the yellow marker, a message "This data variable does not exist in this study and needs to be replaced or removed." appears. 
- Click-and-drag a variable from the data sets, and then drop the variable in the Variable column. 
- Select an  Operator . 
- Select a  Value .

## Configure Transposed Table Element Display Conditions
 You can configure tables and timelines to display on a conditional basis. ## Configure Transposed Table Row Display Conditions
 When designing profiles, there may be times when you need to display the same data in two tables, but you must apply opposing conditions to the rows containing that data. For example, if you want to show significant adverse events (AE) in one table and nonsignificant adverse events in another table. In such case, you can build two tables with the same AE data set variables. On the first table, you can build a condition with ae.SAE=Yes. On the second table, you can have the condition of ae.SAE=No.
 Another example of applying row display conditions is if you know an adverse event table will have empty records, but it is unnecessary to display "No Data." You can create a condition where:
 "ae.AE Term = is not missing AND ad.AE Start Date = is not missing". 
 As a result, empty rows do not display  in the report.
