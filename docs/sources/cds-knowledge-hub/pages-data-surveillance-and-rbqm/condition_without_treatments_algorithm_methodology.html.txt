# Condition Without Treatments Algorithm Methodology

## Condition Without Treatments Algorithm Methodology
 The AI Reconciliation algorithm for the Conditions Without Treatments report assumes that patients take a treatment in response to a condition, when the condition expects a treatment. The algorithm is trained to identify a condition expecting a treatment where no treatment exists. For example, for a headache (condition) the expected treatment can be an aspirin (medication). So if a listing shows a headache, and no aspirin is added as treatment on the AE form, the listing is marked as a finding. Further, the treatment for a condition must treat the condition, and the treatment start date must lie in the same time frame of the condition start and end dates.
