# Data Anomaly Detection

## Data Anomaly Detection
 Data Anomaly Detection provides a graphical representation of RBQM's analysis for a single variable or pair of variables in your study data. You can use Data Anomaly Detection to determine  outliers , anomalies, risks, and trends in your study data, and further investigate or report your data findings as necessary. 
## What Is Data Anomaly Detection?
 Statistical Monitoring's Data Anomaly Detection capability provides a graphical representation of RBQM's analysis for a single variable or a pair of variables in your study data. Data Anomaly Detection renders as frequency distribution plots , box-and-whisker plots , or scatter plots . To learn more, see Data Anomaly Detection Plot Visualization Types . 
 Data Anomaly Detection is conducted across all data types (date, numeric, and text) and within all data contexts (visit-based, event-based, and single-record per patient). 
## What Is the Purpose of Data Anomaly Detection?
 You can use Data Anomaly Detection to determine your study data's  outliers , anomalies, unusual data associations, risks, trends, and missing data at the data point-, patient-, site-, and country-level. 
 Depending on the type of data finding, you can: 
- Create queries in Medidata Rave.
- Create issues. 
- Generate or update risks in the Risk Assessment.
## What Are the Benefits of Using Data Anomaly Detection?
 Determining the outliers, anomalies, risks, and trends in your study data puts you and your life sciences team in an optimal position to:
- Understand your study's operational performance at the site and country level, and
- Take mitigating actions on your study, such as:
- Cleaning data,
- Opening issues,
- Opening queries ,
- Issuing corrective actions, and
- Coordinating additional training.
## Who Uses Data Anomaly Detection?
 Different clinical research team members use Data Anomaly Detection for various unique purposes. For example, data managers might investigate data point- or patient-level inconsistencies. Central monitors might investigate site- or country-level data issues. Or medical monitors might investigate signals regarding patient safety.
## How Do I Read Anomalous Plots?
 Depending on the variable or variables you select to view, Statistical Monitoring applies several unique Data Anomaly Detection Plot Visualization Types . 
 Click a data analysis type below to learn how to interpret the anomalous plot based on which type of data analysis RBQM applies to the variable.
 Text Analysis Plot 
- The Y-axis shows the error or discrepancy score .
- The X-axis shows each unique text value as entered by the patients in the eCRF for the selected variable. By default, the text values appear from highest error score to the lowest error score.
- The number of times that the text value occurs within the variable shows on the plot in a blue rectangle, orange hexagon, or red pentagon. For example, . 
- Each color-coded shape is defined below:
- Blue Rectangle   – The text value's error score is less than 2.95. This means that the text value has a statistically normal number of occurrences within the variable. 
- Orange Hexagon   – The text value's error score is between 2.95 and 4.95. This means that the text value has a higher- or lower-than-normal number of occurrences within the variable. Thus, RBQM considers the data type an outlier. 
- Red Pentagon   – The text value's error score exceeds 4.95. This means that the text value has a significantly higher- or lower-than-normal number of occurrences within the variable. Thus, RBQM considers the data type an extreme outlier. 
- You can hover your cursor on a blue square, orange hexagon, or red pentagon to view the text value name and its error score.
- You can click a blue square, orange hexagon, or red pentagon to view additional information about that data point in a separate panel to the right of the plot.
 Field Descriptions 
- Data Point  – The selected data point's raw text value as entered by the patients in the eCRF for the variable.
- Data Point Score – A numeric score generated by Statistical Monitoring's high-dimensional data anomaly detection algorithms , which measures the discrepancy of an individual data point relative to the overall study data. Data point scores help you uncover outliers, anomalies, risks, and trends in your study data, which may require follow-up action. An error score of less than 2.95 indicates statistically normal data; between 2.95 and 4.95 indicates outlier data; exceeding 4.95 indicates extreme outlier data.
- Occurrences  – The combined total number of times in which all patients entered the text value for the selected variable.
- Patient  –  The patient ID for the patient represented in the data point.  
- Site  – The site the patient belongs to.  
- Country  –  The country in which the patient's site is located. 
- #  – The number of times the text value occurred per individual patient represented in the selected data point.
- X  – Located in the upper-right hand corner of the panel. Click to close the panel.
- The dotted red line, , represents the outlier threshold  and spans across the plot at the 2.95 error score mark. All text value data points positioned above the line are outliers. All text value data points below the line are in the normal range.

## How Does Statistical Monitoring Analyze the Data in Data Anomaly Detection?
 Statistical Monitoring automatically runs analytics on new or updated standardized and preprocessed study data from the Medidata Data Fabric to generate data analysis and visualization outputs. To learn more about how Statistical Monitoring receives and analyzes study data, see Clinical Data Studio's Data Pipeline . 
 On the Data Anomaly Detection page, depending on the variable or variables you select to view, Statistical Monitoring uses five different types of data analysis :
- Text Analysis 
- Numeric Analysis 
- Text Versus Text Analysis 
- Numeric Versus Numeric Analysis 
- Numeric Versus Text Analysis 
 Each type of data analysis renders using one of three specific data visualizations: 
- Frequency Distribution Plot 
- Box-and-whisker Plot 
- Scatter Plot 
 Statistical Monitoring's analytics uses a unique data anomaly detection methodology  that: 
- Identifies all the outlier  study data values, 
- Calculates a discrepancy score  for each outlier data value based on how unusual that data value is, and 
- Flags the data values on the data anomaly detection plot as normal, outlier, or extreme outlier. To learn more, see Investigate Data Using Data Anomaly Detection Plots . 
 The single- and multi-value analysis (in addition to other algorithms) roll up to aggregate levels: Patient, Site, Country, Variable, Domain, and Risk Category.
 Statistical Monitoring's comprehensive, multidimensional data analysis and visualization allows you to effectively identify study areas requiring attention that might otherwise go unnoticed. Thus, Statistical Monitoring lends to clean data and efficiently run studies that are readily available for submission at the study's completion.
