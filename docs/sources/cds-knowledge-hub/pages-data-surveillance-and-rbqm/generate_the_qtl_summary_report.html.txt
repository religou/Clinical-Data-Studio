# Generate the QTL Summary Report

## Generate the QTL Summary Report
 You can create a summary report listing the Quality Tolerance Limits (QTLs) associated with risks to your study. This information is useful when creating or updating Clinical Study Reports (CSRs) for your clinical trial. The latest version number generated for the QTL Summary Report appears at the top of the Reports page. 
 Note : Your role must include the Generate Reports building block to access and work with the QTL Summary Report.
## Update Report Details and Participants
- Access RBQM , and then click Risk Assessment > QTL Summary in the left-hand menu.
- Click the QTL Summary Report tab. 
- Use the latest data that is available from the study-level risk assessment to update the QTL Summary details. You can edit these fields:  
- Sponsor - Enter one to 255 characters to identify the sponsor of the study. 
- Protocol Version Number - Enter one to 50 characters to identify the version number of the protocol used by the study. 
- QTL Summary Report Version - Enter one to 50 characters to identify the version number of the QTL Summary Report. 
- Click the check box next to participants assigned to read or review the report. If a participant is missing from the list, click Add to add the participant name . 
- Optional . Select Yes in the Review Required column to also assign the participant as a reviewer. 
 Note : The QTL Summary Details save automatically. When finished updating the details, click Generate QTL Summary Report . 
## Add or Edit a Participant Record 
 Click to add a new participant. Or you can update an existing participant record by clicking the participant name in the list.  
- Edit these  fields:
- Title  (optional) - Dr., Mr., Mrs., Ms., or Prof.  
- First Name - Enter up to 255 characters for the first name of the participant. 
- Last Name  - Enter up to 255 characters for the last name of the participant. 
- Participant's Role - Enter up to 255 characters for the role of the participant in the study.  
- Company Name - Enter up to 255 characters for the name of the company the participant works for. 
- Review Required - Select Yes or No . 
- Click Done  or  Add Another  to autosave the new participant information. Click Update to autosave changes to an existing record.  
 Note : When you add a participant, that name appears in all participant lists for all Risk Management reports. Similarly, removing a participant deletes the name from all participant lists in Risk Management.
## Generate the QTL Summary Report
- Access RBQM , and then click Risk Assessment > Details in the left-hand menu.
The Reports page > QTL Summary Reports shows. 
- Click  Generate QTL Summary Report . If you have not selected participants, a message reminds you to do so. When you click Yes to generate the report, a selection check box appears where you can check the boxes for one or more Quality Tolerance Limits associated with your study. 
- Click Generate Report . This opens the Generated QTL Summary Reports tab.
 Notes :
- You must enter data in any field not marked optional before generating the report. 
- You do not have to add a participant before generating a report. 
- After you click Generate Report , the number of reports increments by one, and the report version number (green icon) at the top of the Generated QTL Summary Reports list reflects the latest report version number. 
## View or Print the Reports
- Access RBQM , and then click Risk Assessment > Details in the left-hand menu.
The Reports page > QTL Summary Reports shows. 
- Click the  Generated QTL Summary Reports tab.
A list of reports appears. The number of generated reports appears in the heading.  
- Click the icon in the Date Assessment Performed , Date Report Generated , or Generated By column headers to change the sort order in the list. 
- Review these fields to find the report you want to view or print:
- Summary Report Name - Click to select the report and show report details. 
- QTL Report Version - The version of the report. 
- Sponsor - The name of the s ponsor of the study . 
- Protocol Version - The protocol version in use at the time of report generation. 
- Date Summary Generated - The date the report was generated.  
- Use the print feature associated with your PDF viewer software to download or print the report. 
- Acknowledge your review of the report by manually signing in the Signature check box at the top of a printed copy or using a signature feature if included in your PDF viewer software.
