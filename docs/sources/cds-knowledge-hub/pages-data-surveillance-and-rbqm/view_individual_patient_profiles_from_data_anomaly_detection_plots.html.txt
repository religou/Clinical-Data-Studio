# View Individual Patient Profiles from Data Anomaly Detection Plots

## View Individual Patient Profiles from Data Anomaly Detection Plots
 Statistical Monitoring users with authorized   access can view individual patient profiles from Statistical Monitoring's Data Anomaly Detection .  This enables you to: 
- Quickly drill into Patient Profiles directly from Statistical Monitoring's Data Anomaly Detection to help you better understand the patient's data in context. 
- Seamlessly perform data point analysis on specific patients to determine why the patient is an outlier . 
- Conveniently view data in a per-patient format to understand the patients’ journey throughout the trial. 
  You can also save and print the patient profiles as a PDF. 
## View Individual Patient Profiles from the Data Anomaly Detection Page
- If necessary,  Access the Data Anomaly Detection page . 
- Do either of the following:
- When viewing a Text Analysis plot  or Text Versus Text Analysis plot, click an individual data point to view more details.
 Important : You can only view a patient profile when working in a Text Analysis plot or Text Versus Text Analysis plot. To help you understand and identify which type of plot analysis Statistical Monitoring has conducted on the plot you are working in, see  Data Anomaly Detection Plot Analysis Types 
 A pane on the right side of the page appears. 
- When viewing any Data Anomaly Detection analysis type , scroll down to the Summary table, and then select Patient or Data: Top 100 Outliers from the View By filter. 
- In the Patient column, click the blue, hyperlinked patient ID for the patient you need.
The individual patient's profile opens in a new browser tab. 
## Export a Patient Profile to PDF
 You can view, save, and print patient profiles in PDF format. Doing so allows you to:
- View patient profiles while offline. 
- Send the patient profile to others who do not have access to Statistical Monitoring or Medidata Patient Profiles. 
- Click View PDF in the upper right-hand corner of the profile.
The PDF file downloads to your browser. Follow your browser's instructions for opening file and downloading to your local machine.
