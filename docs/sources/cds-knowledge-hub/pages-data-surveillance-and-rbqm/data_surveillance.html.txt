# Data Surveillance

## Data Surveillance
 Data Surveillance is a   comprehensive suite of data surveillance   software capabilities that   encompasses a drag-and-drop listings builder, automated query generation for Medidata Rave sourced data, issue management for non-Medidata sourced data, AI-powered data reconciliation, patient profiles, and visualizations.   Data Surveillance leverages AI to streamline data aggregation, standardization, and management workflows so that multiple users can act on real-time data in ways that reduce burden, shorten review timelines, increase quality, reduce risk, and improve patient safety.
