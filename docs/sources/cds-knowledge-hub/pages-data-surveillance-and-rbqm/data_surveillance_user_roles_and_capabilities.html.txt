# Data Surveillance Building Blocks and Permissions

## Data Surveillance Building Blocks and Permissions
 You can use Medidata Cloud Administration® to: 
- Manage access . 
- Configure roles and provide levels of access to Data Surveillance . 
- Assign roles to individuals, and remove roles with permissions needed to manage study groups. Study groups hold sets of studies belonging to the client division. 
- Manage team membership .
 Client division administrators must have the necessary building block assigned to allow them to configure roles. Every building block includes one or more permissions to define the Clinical Data Studio permissions listed in this article. 
## Data Surveillance Building Blocks and Permissions
 The building blocks granted by client administrators to roles in Cloud Administration help influence the content available on a Clinical Data Studio page.
 Important : Assigning these building blocks to roles in Cloud Administration is at the discretion of every customer.
 A role is assigned building blocks and all the permissions within those blocks. However, access to the permissions and the Clinical Data Studio pages associated with them is controlled by each user's context level assignment in Cloud Administration.
 The following table lists the building blocks and corresponding permissions for various operations within Clinical Data Studio.
