# External EDC Standard Concepts

## External EDC Standard Concepts
 Data integrations used in Ingestor use   Medidata Standard Concepts to tie together descriptive and process metadata. This metadata provides semantic meaning to inform external EDC data processing in the Medidata platform. 
## Medidata Standard Data Set Concepts
 Medidata defines the following standard data set concepts. Each of these Medidata-defined data set concepts has a fixed collection of fields. The required fields for each data set concept appear in the Complete OIDs List with their OIDs.

## Customer-Defined Data Sets
 You can define your own data sets for upload into Ingestor. Customer-defined data sets must include all the  Medidata Master Data Fields in addition to the data fields you want to import.
## Allowed Data Types
 You can use any of the following field data types in any data set.
 Text or Char 
 These are plain text fields of a defined maximum size.
 Float 
 Float fields are numeric fields that can include any real number. Fields of type float may have a maximal precision specified.
 Integer 
 Integer fields are numeric fields that can contain whole numbers. Depending on the field, there may be a range limit applied to the value.
 Date or Datetime 
 These fields contain date and datetime data. There are a limited range of allowed formats for dates and datetimes understood by Ingestor.
