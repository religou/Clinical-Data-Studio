# Medidata CTMS Data File Standards

## Medidata CTMS Data File Standards
 To ensure the successful import of Medidata CTMS data files to Ingestor, the files must follow specific file name and format conventions. The imported data corresponds to the appropriate fields in the respective Medidata CTMS application, such as Study Management. You can confirm the data changes in the respective Medidata CTMS application.
## General File Considerations
- Uploaded files must be in the comma-separated value (CSV) file format.
- Files containing empty data cause the import process to fail. 
- Any OID identifier referenced in these files must comply with the following rules: 
- Uppercase alphanumeric text only. 
- No spaces. 
- The OID must begin with an alphabetical character. 
- Underscores can appear in an OID, but not as the first character.

- Invalid File Names 
- CountryEnrollmentPlanning.csv 
## File Structure Standards
 Uploaded files must follow a specific file structure:
- Your files must include all listed column headers, but optional columns can include empty data. 
- Header records must be on the first row of each metadata file, and must the values specified in the below table's Column Header. 
- Headers with noted acceptance values must contain one or more of the listed values.   
- If a String-based value contains a comma in the string, you must enclose the entire value in quotations. For example: “Congo, Democratic Republic of“.
