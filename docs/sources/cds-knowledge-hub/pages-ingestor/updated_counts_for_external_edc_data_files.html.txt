# Updated Counts for External EDC Data Files

## Updated Counts for External EDC Data Files
## Description
 When reviewing the import job summary for External EDC import jobs, the Import Summary panel >  Data Processing section shows the following record counts: 
- Updated – The number of rows in the imported file that resulted in updated data. 
- No Changes – The number of rows in the imported file that resulted in no data changes compared to the previous file import. 
- Deleted – The number of rows in the imported file that resulted in deleted data. 
- Successful  – The number of rows in the imported file that resulted in created data. 
- Failed –  The number of rows in the imported file that failed to be created, updated, or deleted.   
 Feature/enhancement stories referenced in this article:
 MCC-746608 
## Affected Roles
 All platform roles with one of the following building blocks:
- View External EDC Data 
- Import External EDC 
- Manage External EDC Data 
## Advantages
 With the updated record counts, you can track the changes your imported files causes with greater precision. That precision affords you more details when auditing or troubleshooting needs arise.
## User Impact
 You can find the updated record counts while reviewing External EDC jobs' Job Files page> Import Summary panel> Data Processing section. This update retroactively affects the import summaries of your previously created jobs as well.
