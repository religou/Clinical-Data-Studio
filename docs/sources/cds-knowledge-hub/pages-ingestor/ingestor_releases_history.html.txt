# Ingestor Releases History

## Ingestor Releases History
 The following lists all  Ingestor releases (up to and including the current release) and the feature and enhancements introduced in each.
 Code Continuity Across Releases
 All Ingestor releases are cumulative. That is, each release or software update builds on the prior release's as appears in the release notes. For example, Software Update 2016.2.1  includes all the release  2016.2.0  code, which in turn is based on the  release  2016.1.0  code and so on. The release notes describe any updates between releases or s oftware updates (urgent or otherwise) .
