# Create Import Jobs in MEDS Ingestor

## Create Import Jobs in MEDS Ingestor
## Description
 MEDS Ingestor enables the creation of Data Import Jobs. The creation of data import jobs prepares MEDS Ingestor to import supported external data types into MEDS®. You can set import jobs for the specific studies that you configured data integrations for within  Experimental Design .

## Affected Roles
 All.
## Advantages
 Creating import jobs provides a pipeline to connect your data to MEDS. Because import jobs synchronize with Experimental Design , your external data connects seamlessly to the appropriate studies and environments set in Experimental Design. This connection results in a streamlined data integration process from your data source to Medidata's data repository that saves you time from otherwise manual integrations.
## User Impact
- In Cloud Administration, you can:
- Add the Create Import Job, Import Data, View Import Job, and View Import Summary permissions to your customer-defined platform role which grants access to MEDS Ingestor; and 
- Select MEDS Ingestor from the  Actions dropdown menu from within your assigned study environment. 
- In MEDS Ingestor, you can:
- Create new import jobs; and 
- Import CSV files into existing import jobs from your local drives. 
## Special Considerations
- You must have at least one published protocol in Designer in order to create import jobs. 
- MEDS Ingestor is in a nonfunctional beta release. You can upload and store files with MEDS Ingestor but MEDS Ingestor does not process the files or import the files into MEDS. 
- File import only works with single files.
