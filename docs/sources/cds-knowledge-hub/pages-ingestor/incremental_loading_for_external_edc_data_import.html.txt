# Incremental Loading for External EDC Data Import

## Incremental Loading for External EDC Data Import
## Description
 You can create external EDC import jobs or update existing external EDC import jobs with the Incremental import type. Import jobs with the incremental import type can Upsert – add or update existing items – or Delete items. The uploaded file's name determines if MEDS Ingestor upserts or deletes items. If the file's name contains "upsert", then upsertion occurs. If the file's name contains "delete", then deletion occurs.

## Affected Roles
 All platform roles with either the Import External EDC Data or the Manage External EDC Data building blocks. For details, see  Ingestor Roles and Permissions List .
## Advantages
 With incremental data loading, you can refresh subsets of your imported data without needing to upload large files containing largely unchanged data. 
## User Impact
 While creating external EDC import jobs, you can select the Incremental import type during the Job Settings step.
 While reviewing an external EDC import job's Job Configuration screen > Import Settings section, you can toggle the job's Import Type between Cumulative and Incremental.
 While uploading external EDC files, each file's file name determines how MEDS Ingestor processes the data file. Include "Upsert" in the file name to create or update records. Include "Delete" in the file name to delete records."
