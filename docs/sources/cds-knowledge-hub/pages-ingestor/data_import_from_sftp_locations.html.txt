# Data Import from SFTP Locations

## Data Import from SFTP Locations
## Description
 You can now configure import jobs to retrieve data files from SFTP locations. You must define an input folder path to receive files from and an output folder path to place Ingestor's post-processing files. Every 30 minutes, MEDS Ingestor imports the files from the Input File Path and exports various status files to the output folder path. When applicable, the exported files include processing files such as error lists, reconciliation reports, and success logs.
 In addition, SFTP details appear on each page containing import job details, including the Jobs List page and the Job Configuration page.

## Affected Roles
 All.
## Advantages
 With SFTP import, you have more flexibility in how to import data files onto the Medidata platform. Once you configure an import job to use an SFTP location, you only need to manage the connection, and do not need to search for files or manage file output. Moreover, you can retrieve and place files in a secure location that automatically updates without manual intervention. In addition, you can import large data files more consistently over SFTP instead of a browser since there is no concern from time-out errors or other issues.
## User Impact
 While creating import jobs, you can configure the job's SFTP settings at the SFTP Settings step. After clicking the SFTP toggle, you can set the import job's  SFTP Location, input folder path, and output folder path. After creating the import job, MEDS Ingestor imports the files from the input folder path every 30 minutes. The  various status files appear in the output folder path as they become available.
 You can also edit a job's SFTP settings from the job's Job Configuration page.

## Special Considerations
 To configure the list of SFTP locations, you must use MEDS Extractor. To access MEDS Extractor and use its SFTP configuration capability, your platform role must include the Extractor Admin building block. For details, see  Grant Access to Extractor  and Extractor Roles and Permissions .
