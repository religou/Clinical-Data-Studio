# Study Master Data File Standards

## Study Master Data File Standards
 To ensure the successful import of Study Level Master Data files to Ingestor, the files must follow specific file name and format conventions. The imported data corresponds to various Cloud Administration fields, and you can confirm the data changes in Cloud Administration.
## General File Considerations
- Uploaded files must be in the comma-separated value (CSV) file format.
- Files containing empty data cause the import process to fail. 
- Any OID identifier referenced in these files must comply with the following rules: 
- Uppercase alphanumeric text only. 
- No spaces. 
- The OID must begin with an alphabetical character. 
- Underscores can appear in an OID, but not as the first character.

## File Structure Standards
 Uploaded files must follow a specific file structure:
- Your files must include all listed column headers, but optional columns can include empty data. 
- Header records must be on the first row of each metadata file, and must the values specified in the below table's Column Header. 
- Headers with noted acceptance values must contain one or more of the listed values.   
- If a Char-based value contains a comma in the Char, you must enclose the entire value in quotations. For example: “Congo, Democratic Republic of“.

- If this entry matches an existing CDO ID, then Ingestor:
- Applies the CDO's Legal Name to the Site Name. 
- Uses the CDO's Main Address as the site's Mail Address. 
- If this entry does not match an existing CDO ID record, then Ingestor creates a CDO with a new Site while using the COD's Legal Name as the Site Name and links the CDO ID to the new site.

 | Other Phones 
 | The team member's alternative phone numbers. 
 | Optional 
 | String 
 | N/A 
 | Ingestor processes all phone numbers entered into this field as non-primary. 
 You can enter phone numbers in one of the following formats:
- Phone Number only – The phone number only, such as 07956463607 . 
- Phone Number with Usage Type – The phone number with the user usage type, such as Home::23459875023. While optional, you can enter the phone numbers' usage type by adding two colons '::' before the phone number. 
 You can enter multiple phone numbers by separating each number with a pipe delimiter '|', for example:
- Phone Number only – 07956463607|23459875023 
- Phone Number with Usage Type – Fax::+44 (097) 40393-82|Mobile::07956463607|Home::23459875023 
 If you do not specify usage types the Medidata platform attempts to link the phone number with a type based on what appears in the CDP record.
 You cannot set a phone number as both a primary phone number and an alternative phone number at the same time.
