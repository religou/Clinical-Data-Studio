# Enhanced Support for Windows-Based SFTP Servers

## Enhanced Support for Windows-Based SFTP Servers
## What Is New?
 Import jobs now support Windows-based SFTP servers.
 Feature/enhancement stories referenced in this article:
 MCC-1126559 
## What Is the Impact?
## Users/Roles
 All users
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Windows-based SFTP servers fail to process files since Ingestor does not automatically create the output folders. With the update, Ingestor now creates output folders for Windows-based SFTP servers.

 No changes to the user interface.
