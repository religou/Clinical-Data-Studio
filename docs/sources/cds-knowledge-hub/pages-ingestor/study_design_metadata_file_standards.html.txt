# Study Design Metadata File Standards

## Study Design Metadata File Standards
 Study Design Metadata (SDM) files follow a fixed format. The files you prepare must exactly match the specified file structures and column names. The required files include: 
- Visits – Lists all planned visits for the study. 
- Data Sets – Lists all data sets you intend to load for a study, regardless of data provider. 
- Schedule of Assessments (SOA) – Specifies which visits you intend to have data set data in the study. 
- Fields – Specifies the data fields to include in each data set. 
 For details about loading SDM data for CTMS, see  Import Non-Rave Data for Medidata CTMS .
## General File Creation Rules
- Metadata files must be cumulative. The uploaded file overwrites the corresponding metadata for the corresponding study. 
- Metadata files can only contain content for a single study. 
- Files must be in the comma-separated value (CSV), UTF-8 format. 
- Header records must be the first record in each metadata file. 
- Header records must be uppercase. 
- Field header values must match the values specified under Column Header for each of the below metadata file specifications. 
- If you use commas used in a field value – for example: Please list all events, issues, and problems – then you must double quotes to escape the additional comma: "Please list all events, issues, and problems". 
- Do not use double quotes for null fields, such as '' — instead, denote null fields by keeping the field empty. 
 Important : For each metadata file, fields marked as Required as according to its file specifications must have data. When preparing the content for the SDM file, the field must not be empty.

## Fields
 The fields SDM file specifies the data fields to include in each data set. The content in the fields files also provides key information to the system to process the data.
 Important : Any data pertaining to the Queries data file must follow a strict order for the sequence of rows:
- QUERYID 
- STUDYID 
- SITEID 
- SUBJID 
- VISIT 
- SVSTDTC 
- FRM_NAME 
- FRM_RPT_KEY 
- FIELD_NAME 
- QUERY 
- QUERY_OPEN_METHOD 
- QUERY_TYPE 
- QUERY_CREATED_DATETIME 
- QUERY_ACTION 
- QUERY_ACTION_TEXT 
- QUERY_ACTION_DATETIME
