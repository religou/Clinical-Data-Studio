# Updated Building Blocks for MEDS Ingestor

## Updated Building Blocks for MEDS Ingestor
## Description
 MEDS Ingestor updates its permission structure with new building blocks. The new building blocks grant users various permissions to create and manage new types of import jobs, and to import types of data. The new building blocks replace the previous version's building blocks.
 Feature/enhancement stories referenced in this article:
 MCC-745100, MCC-760854, MCC-760862, MCC-772438 
## Affected Roles
 All.
## Advantages
 With the updated building blocks, you have more precise control over MEDS Ingestor access. In addition, the updated building block names afford a clearer understanding about which building block grants what set of permissions.
## User Impact
 The following table describes the changes to Cloud Administration's building blocks pertaining to MEDS Ingestor.
 Important : If you previously had access to MEDS Ingestor, your role's permissions may not automatically update with this update. Review and update your role's permissions to ensure you have correct access to MEDS Ingestor features.
