# Review Job Notifications

## Review Job Notifications
 After creating one or more import jobs  with configured SFTP settings , you can view notifications about any import jobs that use SFTP locations from a job's Job Notifications page. The Job Notifications page shows any errors and warnings that occurred while the import job tried accessing the SFTP location or file path. A notification icon appears when there are new notifications available. Notifications refresh every 30 minutes. 
## Open Job Configuration Page
- Log into iMedidata.com . 
- Navigate to Ingestor through an assigned client division. 
- Select an import job to review.
 Tip : You can filter import jobs by different parameters, such as Study, Job Type, and Environment. To filter the import job list, click the Filter icon  for one of the parameters, and select which data to filter by.
- Click the Job Notifications tab.
 Tip : You can also access the Job Notifications page by clicking the alert icon from the jobs list.
## Notification Details
 Type 
 Description – The notification's type. Possible values: 
- Error 
- Warning 
 Message 
 Description –  The notification's message, including the subject line and details. 
 Category 
 Description –  The category the notification pertains to. Possible values: 
- STFP 
- FTPS 
 Last Occurrence Date 
 Description – The date and time the error or warning last occurred .
 Number of Occurrences 
 Description –  The number of times that the error or warning occurred. 
 Tip : You can dismiss notifications by clicking Dismiss  icon.
