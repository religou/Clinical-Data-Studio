# Automatic Retries for Failed File Uploads

## Automatic Retries for Failed File Uploads
## What Is New?
 Ingestor now automatically attempts to retry file uploads that fail. This occurs for imports done through the Ingestor interface and through SFTP.
 Feature/enhancement stories referenced in this article:
 MCC-1196223 
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 By reattempting file upload, Ingestor saves you direct intervention when files fail to upload due to minor issues.
