# Data Connect

## Data Connect
 Data Connect is a part of Clinical Data Studio, and unifies data discovery, ingestion, transformation, and exports. It provides interoperability across various data sources and systems. Users can explore internal and external datasets, import non-Medidata data sources, and transform datasets into industry or custom data models. Users can then activate  non-Medidata datasets for down stream Medidata experiences, or export and share datasets to external systems.
