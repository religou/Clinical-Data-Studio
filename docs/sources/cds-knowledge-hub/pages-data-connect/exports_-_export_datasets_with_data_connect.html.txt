# Exports: Export Datasets with Data Connect

## Exports: Export Datasets with Data Connect
## What Is New?
 Users can now access Extractor's data export capabilities through Data Connect's Export module. Data Connect inherits every Extractor capability, and includes the Transformed Data export type that exports datasets created through the Transformations module. 
## What Is the Impact?
## Users/Roles
- All users with access to Data Connect 
- All Extractor users 
 Important : Existing Extractor users must now access their export jobs through Data Connect. This change does not affect any existing job configurations, but only changes how you access your jobs.
## Workflow Process
 There is no impact on the workflow process. The existing workflow to create and manage export jobs is unchanged. 
## Other Applications
 Extractor and its data export capabilities is no longer accessible directly through the Medidata landing page. Users must access its capabilities through Data Connect.
## How Do I Benefit?
 The integration with Data Connect enables a seamless data management and. export experience for Data Connect users.
## Where Do I See the Change?
 Data Connect includes the Exports tab where users can access its data export capabilities. Extractor is no longer accessible and is instead replaced by Exports.

 Extractor is no longer accessible as a standalone capability. All users must use Data Connect's Exports module to create and manage export jobs.
