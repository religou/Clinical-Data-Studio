# Transformations - Automated Visit Mapping

## Transformations - Automated Visit Mapping
## What Is New?
 As a part of the Data Connect's 2025.1.0 release, the Transformations module now automatically maps the visits based on the Visit name.
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 This update reduces the burden on the user and potential user error to activate a dataset for DQM.
## Where Do I See the Change?
 Users can access these functionalities from the Variable Mapping screen on the transformation project.

 Users cannot remove automatically mapped visits.
