 Transformations
 Summary of Changes 
 | 
 As highlighted in the Release Newsletter : 
 Data Connect now supports a versionless schema for Veeva data sources, consolidating multiple dataset versions into a single view. 
 While in Datasets, when previewing or profiling Veeva datasets, an All option is now available in the version list and is selected by default. 
 In addition, while in Transformations, the system shows an All badge next to  versionless folders in the Data Source panel, and nodes in the canvas lineage to indicate the dataset type. 
 Benefit to Users 
 | This change enables you to access versionless Veeva EDC data without needing to manually upgrade Veeva EDC datasets. By selecting the All view, you automatically receive the latest data points and column updates from Imports, eliminating the need to manage infrastructure for separate versions. 
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 All Data Connect and Workbench users interacting with Veeva data sources. 
 Impact to Workflow Processes 
 You no longer must select specific versions – for example: v1 or v2 – to view the latest data. The workflow now starts on the All view, which includes all consolidated data and new columns. 
 Impact to Applications 
 No impact to other applications.
 Impact on Interface 
- Source Panel and Canvas: An ALL badge appears next to versionless folders and nodes .
- Data Preview: The version list now includes an All option, which appears first and is selected by default .
 Impact to Existing Data or Settings 
 Existing projects using specific versions now use the versionless schema. Field UUIDs include updates to reflect the latest versionless form.
