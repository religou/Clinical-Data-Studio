# Data Connect Roles and Capabilities

## Data Connect Roles and Capabilities
 To grant yourself or other users permission to use Data Connect, you must use Medidata Cloud Administration® to: 
- Add and edit roles . 
- Configure roles and provide levels of permission to Data Connect . 
- Assign roles to individuals, and remove roles throughout the client. 
 Important : When assigning users to a role, you must assign users to the study level. 
 You must have the necessary building blocks assigned to configure roles. Every building block includes one or more permissions to define the Data Connect capabilities listed in this article. In addition, you can only see data for the environments you have permission to use.

## Data Connect Building Blocks and Permissions
 The building blocks granted by client administrators to roles in Cloud Administration help influence the content available on a Data Connect page.
 Important :
- Assigning these building blocks to  roles in Cloud Administration is at the discretion of every customer. 
- When you add a building block to an existing role, the role does not automatically work with the new associated permissions. You must remove the role from the user and re-add the role to apply the permissions. 
 A role is assigned building blocks and all the permissions within those blocks. However, access to the permissions and the Data Connect pages associated with them is controlled by each user's context level assignment in Cloud Administration.
 The following table lists the building blocks and corresponding permissions for various operations within Data Connect.
 Important : To export data with the Rave and Audit CTMS data types for a given study, you must also use Cloud Administration's Manage Access tools to set Site and Country Access to all sites and countries.
