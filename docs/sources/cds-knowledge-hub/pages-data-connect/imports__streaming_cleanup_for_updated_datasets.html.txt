# Imports: Streaming Cleanup for Updated Datasets

## Imports: Streaming Cleanup for Updated Datasets
## What Is New?
 When you use Data Connect's Imports experience to create a new dataset version, the system automatically deactivates the streaming of older datasets into other experiences such as Data Surveillance. 
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 There is no change to the existing process. 
## Other Applications
- Data Surveillance   and   RBQM   – Downstream capabilities such as Data Surveillance and RBQM automatically stop receiving streaming data when a user creates a dataset version.   
## How Do I Benefit?
 Downstream capabilities such as Data Surveillance and RBQM automatically stop receiving streaming data when a user creates a dataset version. Users can now use the updated dataset version automatically in Data Connect's Transformations. 
## Where Do I See the Change?
 Users can access these functionalities from Data Connect's Datasets tab.
