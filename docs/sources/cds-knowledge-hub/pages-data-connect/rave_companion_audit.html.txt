 | Audit Action Type 
 | Text 
 | 256 
 | 
 The data's action type:
- TypedEntry – For text fields, this action type signifies that the user typed the form field entry within Rave Companion, which populated the eCRF. Rave Companion also shows this action type when the user selects a check box, dropdown, date, or datetime value using Rave Companion. 
- RaveFormEntry – This   action type signifies that the user entered form field data directly in the Rave eCRF, which then populated the corresponding form field in Rave Companion.
 Note:  Each time a user saves a Rave eCRF, the audit log creates a RaveFormEntry type audit entry for the Save field with  a value of "true." 
- ClickCaptureEntry – This action type signifies that the user entered form field data in Rave Companion using the click data capture functionality. 
- ConnectEntry – This action type signifies that the user populated form field data by selecting EHR data that MHRC delivered to Rave Companion.   This action type has a corresponding Request ID. 
- ConnectEntryAuto – This action type signifies that Rave Companion automatically selected EHR data to populate this form field, based on the user's selection of EHR data for another form field within the same form. This action type has a corresponding Request ID.
