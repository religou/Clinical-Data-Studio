# User Data Listings - Export Types and Methods

## User Data Listings - Export Types and Methods
 Use Cloud Administration or Visual Analytics to export your data. Each method uses different solutions, data sources, nomenclature, and terminology. The following table highlights each method with its corresponding solution, data source, nomenclature, and terminology so you can identify which method best fits your needs.

## Generate Reports with Visual Analytics
 You can use Visual Analytics to generate or schedule reports .

 Description

 Use the User History dashboard to view user assignments, role provisioning, and study invitation statuses . This dashboard shows administrators who make specific role changes and when the changes occur . 
 | User History Report 
 | eLearning Compliance Dashboard 
 | Report 
 | 
 The eLearning Compliance dashboard shows user training progress, course completion statuses, and overall compliance . Administrators use this dashboard to track training data at the study group level and across studies for all users, including removed users . 
 | eLearning Compliance Dashboard 
 | User Login and Navigation Dashboard 
 | Report

 The User Login and Navigation dashboard shows user interactions with applications, studies, and sites for active and inactive users . Administrators can use this dashboard to track user engagement, last login times, and navigation volumes .
