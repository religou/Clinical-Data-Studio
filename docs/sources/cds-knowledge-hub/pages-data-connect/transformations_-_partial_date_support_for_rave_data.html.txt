# Transformations - Partial Date Support for Rave Data

## Transformations - Partial Date Support for Rave Data
## What Is New?
 As a part of Data Connects 2025.1.0 release, the Transformations module now supports partial date fields as field object identifier. 
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to workflow process, however users can now add raw dates as FieldOIDs and interpolated dates as fieldoid_INT
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 The new updates provide full transparency for the user by capturing raw dates. 
## Where Do I See the Change?
 Users can access these functionalities from Data Connect's Transformations > Derived Dataset Project. 
## Where Do I Learn More?
 Use the following links to find new and updated content in support of this Feature:
- Add Partial Dates for Published Derived Datasets 
## What Else Should I Know?
 For derived datasets from Rave that has a DQM configuration, you must update the transformation project configuration to add the raw dates and republish the dataset for DQM.
 To view Medidata testing documentation for this release, refer to the Medidata Validation Portal .
