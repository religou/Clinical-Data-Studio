# Datasets and Transformations: Introducing Derived Dataset Templates and Platform Library for Templates

## Datasets and Transformations: Introducing Derived Dataset Templates and Platform Library for Templates
## What Is New?
- Derived Dataset Templates:   Specific templates are now available for derived datasets that help standardize and accelerate the creation of these datasets.
- Platform Library for Templates:   A new platform library is available for managing templates. 
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to the workflow process. However, you can create a project from a template by selecting From template  while creating a Transformation project.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Templates provide a standardized, reusable, and version-controlled mechanism to capture and apply this logic, ensuring uniformity and accelerating the setup process across diverse transformation needs. 
## Where Do I See the Change?
 Create a Project Using Templates : You can access this feature by clicking Add Project > From Template.
 Project Library : You can access the Transformation templates from Project Library on the main menu.

## What Else Should I Know?
- You need access to building blocks: 
- Manage Library Templates : To c reate or modify templates 
- View Library Templates : To view and use templates 
- Only the Librarian or Admin can create and edit templates. 
- A user with access to a study has access to all templates for that study’s client. 
- The global navigation does not match the template access view.
