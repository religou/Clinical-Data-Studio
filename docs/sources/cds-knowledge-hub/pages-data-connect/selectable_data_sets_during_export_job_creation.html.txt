# Selectable Data Sets During Export Job Creation

## Selectable Data Sets During Export Job Creation
## Description
 When creating an export job of any type, you can now select individual data sets to extract.  
## Affected Roles
 All roles with the ability to create export jobs. For details, see MEDS Extractor Roles and Permissions.
## Advantages
 You can now configure export jobs to extract only the specific data sets you need, which reduces both the processing load and time. 
## User Impact
 While creating export jobs, at the Select Data step, you can now select individual data sets for each data type that you applied to the export job.
