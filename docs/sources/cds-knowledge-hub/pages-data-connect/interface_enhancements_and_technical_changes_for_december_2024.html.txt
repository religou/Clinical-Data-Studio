# Datasets and Transformations: Interface Enhancements for December 2024

## Datasets and Transformations: Interface Enhancements for December 2024
## What Is New?
 As a part of December 2024 release, the Datasets and Transformations experiences feature various enhancements including:
- Updates to transformation projects (SDTM, Custom Data Model, Derived Datasets and, Unit Conversions) when in read-only mode. When the user is in read-only mode, all user actions are disabled and a banner appears on the status of the project. 
- Date picker removed for Run Now action on the Validation Frequency page. 
- Updates to the Activation tab for a dataset that includes showing a banner when a new version of a dataset is available.
