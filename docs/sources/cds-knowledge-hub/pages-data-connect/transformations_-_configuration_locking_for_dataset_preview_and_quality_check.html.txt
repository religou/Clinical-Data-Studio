# Transformations - Configuration Locking for Dataset Preview and Quality Check

## Transformations - Configuration Locking for Dataset Preview and Quality Check
## What Is New?
 For transformation projects, users can update the configuration while the system is processing the Dataset Preview and Quality Check for another configuration update.
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 The update minimizes false positive error messages for Quality Check and provides consistency between current configuration and live data preview or validation. The update improves the overall performance of the live data preview and Quality Check generation.
