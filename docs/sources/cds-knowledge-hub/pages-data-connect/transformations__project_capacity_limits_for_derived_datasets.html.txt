 Summary of Changes 
 | 
 As highlighted in the Release Newsletter : 
 Data Connect now includes a Project Capacity progress bar within Derived Datasets projects. This visual indicator shows the total execution time consumed by the project's operations against a hard limit of 60 seconds. 
 The system calculates capacity usage as you build a derived dataset on the canvas . The progress bar provides visual feedback using the following color indicators: 
- Green : 0% to 74% capacity 
- Yellow : 75% to 90% capacity 
- Red/Orange : 91% to 100% capacity 
 Benefit to Users 
 | This enhancement provides critical visibility into a project's complexity and execution time. By monitoring the Project Capacity bar, you can ensure your configurations remain within system limits, allowing you to optimize operations and successfully publish projects without encountering processing issues. 
 Summary of User Impact 
 | 
 Impact to Users and Roles 
 All Data Connect users configuring derived datasets 
 Impact to Workflow Processes 
- Monitoring Capacity : You can now monitor the Project Capacity meter in the top header bar to track usage . 
- Validation Blocking : If a project exceeds 100% capacity, the system blocks you from adding more nodes to the canvas. You must decrease the project scope, such as by reducing nodes or modifying operators, to unlock the canvas . 
- Publishing: While the Publish button remains enabled, attempting to publish a project that is over capacity leads to a validation error. 
 Impact to Applications 
 No impact to other applications.
 Impact on Interface 
- Progress Bar: A labeled Project Capacity linear progress bar appears in a persistent location on the header . 
- Info Icon: An info icon next to the bar shows a tooltip explaining that reaching maximum capacity prevents publishing . 
- Error Messages : Specific error messages appear when you reach capacity, such as: "This configuration exceeds the project's capacity limit and it cannot be published" . 
 Impact to Existing Data or Settings 
 The system exempts existing projects that exceed the capacity limit as "legacy exceptions." It does not automatically unpublish these projects, but does open them in a Project Lock state.  In this state, you cannot add nodes, but can delete node or remove existing operators.
