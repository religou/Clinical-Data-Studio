# Datasets and Transformations: Technical Changes for November 2024

## Datasets and Transformations: Technical Changes for November 2024
## What Is New?
 Medidata routinely includes technical changes to Data Connect's Datasets and Transformations experiences to improve performance and backend processes. Datasets and Transformations introduce the following internal code changes for the November 2024 release:
- Enhancements to streaming performance . 
- Codelist count removed from the field table. 
- Updates to standardize ID creation across dataset versions. 
- New master pipelines created for data activation.  
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
No impact to the workflow process.
## Other Applications
No impact to other applications.
## How Do I Benefit?
 These updates result in improved scalability, efficiency and, active monitoring of the Flink jobs therefore allowing us to reduce the cost of Flink jobs. When a source dataset has a new version, users do not need to review the patients again for listing results created with the new dataset version.
