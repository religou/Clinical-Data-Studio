# Export Configuration Compatibility by Data Type

## Export Configuration Compatibility by Data Type
 You can create exports to extract different types of data from the Medidata platform. Some configuration options differ between data types. The below tables highlight the job configuration options for each data type.
 For details on the different data types, see  Available Exportable Data Objects .
## Data Export Type Compatibility
 You can set exports to extract data cumulatively or incrementally:
- Cumulative – Each export instance exports all available data. 
- Incremental – Each export instance only exports data changes since the previous run. The first incremental run is cumulative. 
 For details about configuring an export's data export type, see Set Data Export Type .

## Repeating Export Compatibility
 You can set exports to run immediately, schedule export to run at a future date, or schedule exports to repeat at a regular frequency. Repeating options include:
- Minutely – The export runs each minute, starting from the start date and time. 
- Hourly  – The export runs each hour, starting from the start date and time. 
- Daily – The export runs at the selected hour each day, starting from the start date. 
- Weekly  – The export runs on the selected hour on the selected days of every week.   The export first executes on the next selected day and hour on or after the scheduled start date. 
- Monthly  –   The export runs at the selected date and hour each month. Exports only run on the months containing that date. 
- Last day of month  –   The export runs at the selected hour on the last day of each month. This option ensures that exports run on the last day of every month, irrespective of the number of days in the month. 
 For details about scheduling jobs, see  Schedule Export .
