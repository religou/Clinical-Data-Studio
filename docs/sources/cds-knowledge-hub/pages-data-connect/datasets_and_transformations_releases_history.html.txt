## Datasets and Transformations Releases History
 The following lists all releases for Data Connect's Datasets and Transformations capabilities before the June 2024 release, and the features or enhancements introduced in each.
 Important : As of the 2024.1.0 release, Platform Workbench is a part of the Data Connect solution as its "Datasets and Transformations" capability. It is now "Data Connect - Datasets and Transformations" or "Datasets and Transformations." For details what the 2024.1.0 release entails, and following releases, see   Data Connect Releases History , 
 Code Continuity Across Releases
 All Platform Workbench releases are cumulative.   That is, each release or software update builds on prior releases as noted in the release notes. For example, the  Datasets and Transformations Standard Software Update 2023.1.1 includes all release Datasets and Transformations Feature Release 2023.1.0 code, which in turn is based on the release  2022.1.0 code and so on. The release notes describe any updates between feature releases, standard s oftware updates, or other types of releases.
