 | Introducing the Enhanced Release Notes Experience 
 | Data Connect
 | 2026.1.0

 The release notes include several formatting updates to address reported challenges and issues with the Medidata Release Notes experience. The changes appear across multiple pages for the release notes.
- Tabular Structure – Pages that describe changes, such as this article, now appear in a tabular structure with renamed or added sections.  
- New sections 
- Product – The product the change applies to. 
- Version – The code product version that the change applies to. 
- Change Type – The type of change: 
- Feature 
- Enhancement 
- Technical change 
- Functionality or Module – The area of the product that this section affects, such as a particular module within the product or a subsection within the module. 
- Impact to Existing Data or Settings – Any changes that an update introduces to existing data or settings that need review. 
- User Impact Assessment – A high-level summary of the change's impact. 
- Changed sections 
- "What's New?" is now "Summary of Changes" 
- "How Do I Benefit?" is now "Benefit to Users" 
- "What's the Impact?" is now "Summary of User Impact" 
- "Users/Roles" is now "Impact to Users and Roles" 
- "Workflow Process" is now "Impact to Workflow Processes" 
- "Other Applications" is now "Impact to Other Applications" 
- Where Do I See This Change? is now "Impact on Interface" and appears in the Summary of User Impact section 
- New Released Features Indices – Release notes now include new Released Features Index articles — one for a specific release, and another for the entire product across releases. These articles list all changes relative to the page's scope as a downloadable table. 
- Feature Release Notes Parent Page – For Feature Release Notes, the home page includes new links to other reference articles such as the released features indices and webinar details, where applicable.

 | Developer Center: New Python Library and Other Enhancements 
 | Data Connect
 | 2026.3.0
 | 
 | Developer Center 
 | 
 As highlighted in the Release Newsletter : 
 Data Connect introduces the Python SDK and updates the R SDK.  Both software development kits (SDKs) are available as beta releases in Developer Center . 
 The Python SDK library: 
- Provides access to Data Connect data. 
- Lets you register data products created in Python back in Data Connect through the Library.  
- Is now compatible with a native IDE for running the transformation script. 
 The R SDK library now:
- Presents a data frame containing invalid records from dry publish and publish operations. 
- Updates the Dry Publish and Publish responses to include valid record counts and duplicate record counts. 
- Creates a new version of a Custom Code dataset if you modify any key fields after the initial Publish operation. 
 The Documentation page now includes new Python library documentation and updated R library documentation.

 | Transformations: Quality of Life Enhancements in Data Connect 2026.1.0 
 | Data Connect
 | 2026.1.0
 | Enhancement (Updated Functionality) 
 | Transformations > Derived Datasets
 | 
 As highlighted in the Release Newsletter : 
 The R02 release introduces several usability enhancements designed to improve project management, data visibility, and transformation capabilities. 
- Archived Dataset Awareness: Data Connect now provides visual indicators and warnings when you interact with archived datasets. If a project uses a dataset from an archived project, the system shows a warning about potential state data.
- Archive Impact Analysis: Before you archive a project, a confirmation message details the datasets and downstream processes impacted by the action. In addition, archiving a project that saved as a template prevents future use of that template. 
- Project Filtering: You can now filter the project list to view only those projects created from a template. 
- Substring Transformation: You can now extract a substring using a self-defined delimiter during data transformation. 
 | Transformations: Project Capacity Limits for Derived Datasets 
 | Data Connect
 | 2026.1.0
 | Feature (New Functionality)
 | Transformations > Derived Datasets

 As highlighted in the Release Newsletter : 
 Data Connect now includes a Project Capacity progress bar within Derived Datasets projects. This visual indicator shows the total execution time consumed by the project's operations against a hard limit of 60 seconds. 
 The system calculates capacity usage as you build a derived dataset on the canvas . The progress bar provides visual feedback using the following color indicators: 
- Green : 0% to 74% capacity 
- Yellow : 75% to 90% capacity 
- Red/Orange : 91% to 100% capacity

 | Transformations: Enhanced String Transformations for Derived Variables 
 | Data Connect
 | 2026.1.0
 | Enhancement (Updated Functionality)
 | Transformations > Derived Datasets
 | 
 As highlighted in the Release Newsletter : 
 The R02 release introduces enhancements to string transformation functions used in derived datasets. 
- Simple Concatenate (Ignore nulls): The Simple Concatenate transformation is now called Simple Concatenate (Ignore nulls) . This function now automatically skips null values during concatenation, ensuring that the specified delimiter does not repeat when data points are missing. 
- Substring with Delimiter: The Substring transformation now includes the ability to define a specific delimiter, allowing you to extract substrings based on character patterns rather than just fixed positions.
