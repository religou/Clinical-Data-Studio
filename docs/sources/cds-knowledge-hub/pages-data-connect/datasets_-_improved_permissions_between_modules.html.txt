# Datasets: Improved Permissions Between Modules

## Datasets: Improved Permissions Between Modules
## What Is New?
 Data Connect includes compatibility improvements between the Datasets, Transformations, Imports, and Exports modules. Users can only use the capabilities that they have been granted access to use, including: 
- Specific data project types such as SDTM projects. 
- Specific Data Connect capabilities such as Exports.

## How Do I Benefit?
 The improved permissions ensures that users can access Data Connect capabilities consistent with their organization's technology strategy.
