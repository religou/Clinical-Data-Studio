# Imports: Upgrade Dataset Version in Collections

## Imports: Upgrade Dataset Version in Collections
## What Is New?
 When you upgrade an existing dataset in Data Connect's Datasets, Imports now updates the dataset version in the Collection.
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 When you import a dataset and add it to a Collection, Data Connects creates a collection in data catalog. However , when you upgrade to a new version, Imports supports the datasets by upgrading the version of that dataset in the collection.

 No changes to the user interface.
