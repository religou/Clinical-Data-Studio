# Dataset Latency

## Dataset Latency
 Because the data can come into Data Connect from different sources, they can have different refresh cycles. This time also considers how long it takes for the record count to stabilize, that is: for the number of records that appear in the dataset to be consistent with the expected number of records.
 For example, a Rave dataset with 22M records can take up to 12 hours to appear and stabilize after loading them the first time.
