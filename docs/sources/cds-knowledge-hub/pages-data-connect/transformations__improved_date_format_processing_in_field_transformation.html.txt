# Transformations: Improved Date Format Processing in Field Transformation

## Transformations: Improved Date Format Processing in Field Transformation
## What Is New?
 When field transformations convert date strings into the Date format, acceptable strings are no longer case sensitive. Previously transformations could only convert strings in the case-sensitive ddMMMyyyy format such as "10Jan2024", but now it can accept other raw value strings in the same format such as "10JAN2024" or "10jan2024". 
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Users no longer need to modify raw date strings in the ddMMMyyyy format before using them in Data Connect. 
## Where Do I See the Change?
 There is no change to the user experience. This does affect how Data Connect processes date strings for datasets.
