# Datasets and Transformations: Internal and Technical Changes for December 2024

## Datasets and Transformations: Internal and Technical Changes for December 2024
## What Is New?
 The Data Connect - Datasets and Transformations 2024.2.0 Feature Release introduces internal code changes: 
- Improved concatenation for null values in Field Transformations. 
- Improved support for case-sensitive values for MMM fields (MMM, Mmm, mmm) in Field Transformations. 
- Math division consistency 25, 5 (that is, max length, significant digits to display) for field transformations. 
- Internal code changes to account for deleted applications in the database. 
- Improved results for math calculations in Field Transformations (Derived Datasets, SDTM, Custom Data Models) for an integer source type. 
- New addition of Pinnacle 21 validation tab for domains that support manual values.
