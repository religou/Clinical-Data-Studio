 Summary of Changes 
 | 
 As highlighted in the Release Newsletter : 
 Support for Alternative Country Names : Imports now support alternative country names. Alternate country spellings automatically map to the appropriate ISO code. 
 In addition, this release provides the infrastructure updates to support the following future capability: 
- Updates to Support Bulk Query Veeva Direct Connect : You can now generate bulk queries within the Data Surveillance and RBQM modules of Veeva EDC for data imported with Veeva Direct Connect. You can also retrieve and use the full history of available Veeva EDC queries.
. 
 Benefit to Users 
 | Alternative Country Names: You can reduce data entry errors using alternative country names (such as "United States of America" or "USA") that automatically map to standard ISO codes. 
 Bulk Query Veeva Direct Connect: Once available, this feature enables the access and use the full history of Veeva EDC queries directly within the Data Surveillance and RBQM modules.

 User Impact Assessment 
 The impact of the change on system behavior and on the user's interaction with it.
- Low – There is no change to current software behavior.
- Moderate – Change includes corrections or improvements that may change user interaction with the software, such as minor UI or minor functionality changes.
- High – Change includes software changes which require review of existing settings, workflow and/or operational procedures to ensure correct user interaction with the software.
