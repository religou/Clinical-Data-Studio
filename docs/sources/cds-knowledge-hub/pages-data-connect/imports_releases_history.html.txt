 Code Continuity Across Releases
 All Imports releases are cumulative.  That is, each release or software update builds on prior releases as noted in the release notes. For example,  Software Update 2020.2.1  includes all release 2020.2.0 code, which in turn is based on the release 2020.1.0 code and so on. The release notes describe any updates between releases or s oftware updates (urgent or otherwise).
