# Data Lake House Integration with Sync

## Data Lake House Integration with Sync
## What Is New?
 Platform Workbench includes access to Sync capabilities. Sync is Medidata's new third-party data source import capability. With Sync, you can: 
- Configure data source connections for a study environment to import data through SFTP.  
- Configure data import criteria for Sync to identify and use for data transfer. 
- View a given import's progress and the status of the imported fields. 
 The Medidata platform includes all data sources uploaded with Sync, including non-Medidata data sources, in its lake house. Platform Workbench presents these data sources as data sets, you can perform data transformations on and across these data sources.
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to the workflow process. This is a new capability.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 You can import non-Medidata data sources for your data projects through an integrated import experience. 
## Where Do I See the Change?
 Platform Workbench includes the Import tab where you can access Sync's capabilities. You can also access Sync's capabilities from by Datasets tab by clicking Add Dataset > Import.
