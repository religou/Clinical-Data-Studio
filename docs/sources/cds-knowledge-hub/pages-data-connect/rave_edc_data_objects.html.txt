# Rave Data Objects

## Rave Data Objects
 Rave data objects contain raw electronic case report form (eCRF) data from Rave. While configuring exports, you set which Rave data to extract.
 Important : Your Rave URL configuration can affect your ability to access exported data. For details, please contact your Medidata representative or Medidata Support.

 Date 
 The extracted format changes depending on the field's format in Rave: 
- ISO 8601 Date – Formatted in Rave as <Field_OID>_DT. If the original date value is a complete date, then the extracted date value appears in the ISO 8601 format. 
- Strongly Typed Date – Formatted in Rave as <Field_OID>_DTC. The extracted date value appears in the YYYY-MM-DD format. If the date is a partial date, then "–-" appears for the missing values. 
- Interpolated Date – Formatted in Rave as <Field_OID>_DTI. The extracted date value appears in the ISO 8601 format. If the date is a partial date, then the extracted date is interpolated. For values missing in Rave, the extracted file makes the following substitutions:
- If the day is missing, then the extracted file substitutes "01" for the day. 
- If the month is missing, then the extracted file substitutes January as the month. 
- If the year is missing, then the extracted file does not show the date.

 Medical Coding 
 For fields coded with Coder, verbatim terms for coding decisions appear in the <Field_OID>RAW field. Likewise, preferred termed appear in the <Field_OID>PT field. When coding decisions are unavailable, values for preferred terms are automatically loaded by the system.
