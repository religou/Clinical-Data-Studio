# Transformations: Automated Mapping for SDTM Data Models and Unit Conversion

## Transformations: Automated Mapping for SDTM Data Models and Unit Conversion
## What Is New?
 Users can now have Data Connect preselect certain data when building transformation projects. This occurs for the following project types: 
- SDTM-like Datasets – Data Connect can pre-maps variables for the selected domain. 
- Unit Conversions – Data Connect can provide SI unit suggestions based on the selected analyte. 
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to the workflow process. This update augments the existing data transformation project workflow and does not introduce new steps.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 The automated mapping speeds up project creation by inserting AI-suggested data based on common user scenarios.
## Where Do I See the Change?
 AI-enabled suggestions appear when users edit newly created SDTM-like data projects and unit conversion projects. For unit conversion projects, the suggestions specifically appear after selecting an analyte while configuring unit conversion groups.
 While editing custom SDTM-like datasets:
- The Run Auto-Mapping button appears on the dataset mapping screen. Clicking the button causes Data Connect to automatically map variables using using artificial intelligence (AI) capabilities. 
 While applying unit conversions for unit conversion projects: 
- After selecting an analyte, Data Connect automatically inserts the appropriate SI unit. 
- When manually selecting SI units, Data Connect provides suggestions based on users' selection history.
