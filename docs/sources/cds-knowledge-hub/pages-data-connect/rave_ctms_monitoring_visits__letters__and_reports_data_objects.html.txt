# CTMS Monitoring Visits, Letters, and Reports Data Objects

## CTMS Monitoring Visits, Letters, and Reports Data Objects
 CTMS Monitoring Visits, Letters, and Reports data objects contain visits, letters, and report data related to site monitors' activities. The data include visit report submissions and comments, and contact details made with the sites across studies. 
 Note : All data are for cumulative and incremental extracts.
 Important : Your Rave URL configuration can affect your ability to access exported data. For details, please contact your Medidata representative or Medidata Support.
