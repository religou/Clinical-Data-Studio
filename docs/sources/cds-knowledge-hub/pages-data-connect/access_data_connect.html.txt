# Access Data Connect

## Access Data Connect
 Note : You require permissions to access and perform specific actions in each Data Connect capability. To learn more, see  Data Connect Roles and Capabilities .
 To access Data Connect: 
- Do one of the following:
- If you are not yet logged into Medidata:
- Log in to iMedidata.com 
- Click the Data Connect tab in the tab bar below the Medidata Home page welcome message. 
- In the Clients table, click the client name containing the study you want to access. 
- In the Study Groups table, click the study group name containing the study you want to access. 
- In the Studies table, click the study you want to access.
 The Data Connect > Datasets page shows by default. 
- If you are currently working in another Medidata app:
- Click the Data Connect tab in the tab bar below the study banner.
The Data Connect > Datasets page shows by default.
