# Datasets and Transformations: Interface Enhancements for August 2024

## Datasets and Transformations: Interface Enhancements for August 2024
## What Is New?
 As a part of the August 2024 release, the Datasets and Transformation experiences feature various enhancements including:
- Updates to SDTM and custom template searching capability. 
- Activation locking when another user is editing a dataset with the Transformation experience. 
- The ability to filter by category while configuring unregistered patients, visitors, or sites. 
- Updates to the analyte mapping library. 
- Live validation on derived dataset custom variables. 
- Improved version interface changes for dataset and activation. 
- Upgrade the activation pipelines for newer dataset versions.
