# Create Export

## Create Export
 You can create exports at the client level or the study context level.  By creating an export at the client level, you can extract data from every study within the client. By creating an export at the study level, you can extract data from a subset of studies within the client. 
 After you create the export, and the export successfully runs, you can then download extracted datasets. 
## Create Export
- Access Data Connect , and click   Exports   in the left-hand menu. 
- Click Create Export . 
- Complete the Create Export wizard.
 Tip : For a walkthrough on completing the wizard, see  Select Data Source  and follow the workflow.
