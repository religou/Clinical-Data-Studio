## Exports: Interface Enhancements and Technical Changes for November 2024
## What Is New?
 As a part of November 2024 release, the Exports experience feature various enhancements including:
- Updates to user interface components and labels to provide a uniform experience across the Data Connect. 
- The blocking of the execution functionality while an execution is already in progress.
