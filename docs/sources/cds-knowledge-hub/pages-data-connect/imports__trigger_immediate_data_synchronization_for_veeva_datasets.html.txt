# Imports: Trigger Immediate Data Synchronization for Veeva Datasets

## Imports: Trigger Immediate Data Synchronization for Veeva Datasets
## What Is New?
 Users can now sync Veeva EDC datasets immediately.
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to the workflow process. 
## Other Applications
 No Impact to other applications
## How Do I Benefit?
 Users had to wait until 12 hours to sync the new ZIP file in the data source to process the new datasets. With this enhancement, users can trigger Veeva EDC dataset synchronization on demand and import the latest datasets from the data source.
## Where Do I See the Change?
 No changes to the user interface.
