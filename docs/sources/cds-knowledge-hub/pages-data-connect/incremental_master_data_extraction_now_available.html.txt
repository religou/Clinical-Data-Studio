# Incremental Master Data Extraction Now Available

## Incremental Master Data Extraction Now Available
## Description
 While creating recurring export jobs to extract Master Data, you can set the job to extract incrementally. Incremental extracts only contain the added or updated data since the previous run. Incremental extracts do not contain updates about deleted data. The first run of an incremental job is always cumulative. 
## Affected Roles
 All roles that can create Master Data export jobs. To create Master Data export jobs, your platform role must include the Master Data or Extract Cloud Admin Data building blocks. 
## Advantages
 With incremental data extractions, you can select to see only the changes since the last job execution. This saves you time from comparing the previous extract to the current extract to check for data changes. 
## User Impact
 While configuring export jobs that include the Master Data or Audit Master data, you can select the Incremental export type during the Data Export Type step.
