# Rave Data Extract File Type Differences

## Rave Data Extract File Type Differences
 You can configure exports to export data files as comma-separated values (CSV) files, as  SAS V5 Transport files (XPT), or as JSON files. The extracted data is identical between both file types, but the file structure differs. This article describes differences between the CSV and XPT format for the Rave (RAW) data type . 
 For details on extracting data, see  Extracting Data with Exports . 
 Note : SAS V5 Transport file export is only available when exporting Rave RAW data. When you select the SAS file type for Rave RAW data, the exported file outputs as a compressed file containing both CSV and XPT files.
