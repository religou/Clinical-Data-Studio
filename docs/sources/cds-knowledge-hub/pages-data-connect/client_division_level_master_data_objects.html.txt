# Client Division Level Master Data Objects

## Client Division Level Master Data Objects
 You can export Client Division Level Master Data data objects detailing client division people, client division users, and client division organizations.  
 Important : Your Rave URL configuration can affect your ability to access exported data. For details, please contact your Medidata representative or Medidata Support.

- Cloud Administration's Locked status mapp to the data extract's Administratively Complete status.
