## Datasets and Transformations: Performance Enhancement for QC
## What Is New?
 Medidata routinely includes technical changes to Data Connect's Datasets and Transformations experiences to improve performance and backend processes. Datasets and Transformations introduce the following internal code changes   for the Data Connect 2025.3.0   release . 
- You can now add or delete up to 10 derived variables simultaneously for SDTM (Study Data Tabulation Model), derived datasets, and custom target projects. 
- When you add a custom variable,
- QC and data preview do not get triggered by default. 
- The newly added variable is marked by default as yet to be validated instead of failed. 
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Add or Delete Variables in Bulk : This streamlines the process of managing these variables. 
 QC Updates : This optimizes back-end processes and provides performance improvements.  
## Where Do I See the Change?
 Add or Delete Variables in Bulk:  Users can see this option on the List View page of a Transformation project. 
 QC Updates :   Users can see this option in the   Field Transformations screen when adding conditional functions.
