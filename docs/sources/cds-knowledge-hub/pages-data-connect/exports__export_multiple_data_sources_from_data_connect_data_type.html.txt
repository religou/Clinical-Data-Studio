# Exports: Export Multiple Data Sources from Data Connect Data Type

## Exports: Export Multiple Data Sources from Data Connect Data Type
## What Is New?
 Users can now export multiple data sources from the Data Connect data type.
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to workflow process however, when you export Data Connect data type, you can select multiple datasources.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Users can now create an export with Data Connect data type and select all the data sources in one export instead of creating multiple exports for the Data Connect data type.
## Where Do I See the Change?
 The interface updates apply to Source Settings and Datasets screens of the Create Export and Edit Export workflow. The interface updates also reflect in the Settings screen of the export. 
## Where Do I Learn More?
 There are no additional relevant resources.
## What Else Should I Know?
 To view Medidata testing documentation for this release, refer to the  Medidata Validation Portal .
