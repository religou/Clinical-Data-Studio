# Datasets and Transformations: Technical Changes

## Datasets and Transformations: Technical Changes
## What Is New?
 The Data Connect - Datasets and Transformations 2024.1.4 Standard Software Update introduces internal code changes: 
- The implementation feature flags to control the dataset activation capability. When users attempt to access the dataset activation capability when that feature flag is turned off, the following message appears: "Activation is currently not available, if you need support, please reach out to Medidata help desk."
