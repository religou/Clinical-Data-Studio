# Date Time Variable Formats Supported

## Date Time Variable Formats Supported
 Date time variables you create can be used in various capabilities within Data Surveillance, RBQM, and Data Connect. Date variables include
 several date format variations that contain or omit the time. Key date parts include: year, month, day; and for time: hour, minute, seconds, and milliseconds. Data Surveillance, RBQM, and Data Connect support the following datetime formats: 
 | MMM- dd- yyyy 
 | dd/mm/yyyy HH:nn:ss 
 | yyyy-MM-dd HH:mm:ss 
 | yyyy- mm- dd- HH:nn:ss 
 | yyyy- mm- dd- HH+:nn:ss 
 | dd-MM-yyyy HH:mm:ss 
 | yyyy mm dd 
 | yyyy- mm- dd- HH:nn:ss 
 | yyyy-MM-ddTHH:mm:ss.SSS 
 | yyyy- mm- dd- 
 | mm- dd- yyyy HH:nn:ss 
 | yyyy-MM-ddTHH:mm 
 | yyyy/mm/dd 
 | MMMddyyyy 
 | yyyy-MM-ddTHH:mm:ss 
 | dd- mm- yyyy 
 | MMMddyyyy HH:mm 
 | yyyyMMdd HH:mm:ss 
 | dd/mm/yyyy 
 | dd-MMM-yyyy HH:mm 
 | yyyy-MM-dd HH:mm 
 | dd.mm .yyyy 
 | yyyy-MM-ddTHH:mm:ss
