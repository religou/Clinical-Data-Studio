# Data Connect Releases History

## Data Connect Releases History
 The following lists all Data Connect releases (up to and including the current release) and the features or enhancements introduced in each.
 Important : All Data Connect Module Release Information Now Covered in One Data Connect Release Notes 
 Prior to the Data Connect June 2024 release, Datasets, Transformations, Imports, and Exports were each released as separate products with their own sets of release notes. As of Jun-26-2024, all release notes content for all Data modules—that is, Datahub, Transformations, Imports, and Exports—will be documented under one Data Connect Release Notes document per release beginning with the Data Connect June 2024 Feature Release Notes.  To view released features prior to the Data Connect 2024, see: 
- Datasets and Transformations Releases History 
- Imports Releases History 
- Exports Releases History 
 Code Continuity Across Releases
 All Data Connect releases are cumulative. That is, each release or software update builds on prior releases as noted in the release notes. For example, Software Update 2020.2.1 includes all release 2020.2.0 code, which in turn is based on the release 2020.1.0 code and so on. The release notes describe any updates between releases or software updates (urgent or otherwise).
