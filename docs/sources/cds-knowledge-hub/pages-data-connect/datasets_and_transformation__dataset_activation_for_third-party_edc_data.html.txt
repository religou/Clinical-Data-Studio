# Datasets and Transformations: Dataset Activation for Third-party EDC Data

## Datasets and Transformations: Dataset Activation for Third-party EDC Data
## What Is New?
 Data Connect’s Dataset capability, users can activate third-party EDC datasets for Data Surveillance. 
## What Is the Impact?
## Users/Roles
 All.
## Workflow Process
 No impact to the workflow process.
## Other Applications
 No impact to other applications.
## How Do I Benefit?
 Users can now activate the imported third-party EDC datasets for data surveillance and experience an improved dataset activation experience of the EDC data. The status banner helps to troubleshoot issues that need resolution before activation.   
## Where Do I See the Change?
 Users can access these functionalities from Data Connect's Dataset tab and Activation tab of a dataset.
