 Summary of Changes 
 | 
 As highlighted in the Release Newsletter : 
 | Derived variables 
 | 
- From the Canvas after creating a dataset, you can now select  Add Derived Variable from the Operator list. 
- Helper fields: 
- Calculated Fields are now called Helper Fields. They are available on the same screen as the Derived Variable. This variable does not appear in the output dataset/node. You can use it with multiple derived variables. 
- Logic Condition: 
- Using multiple data types no longer requires Helper fields for data type conversion. Data Connect auto detects data types when you enter a Value.  
- The Concatenate option now has both Simple and Advanced options. 
- The Substring menu selection has By Position and By Delimiter options. 
- You can enter expressions while using the Math calculation. 
- Rank operations have new names: 
- RANK is now GROUP [First/Last].
- GROUP is now GROUP STATS [Min/Max/Avg/Sum]. 
- New Keys is now Grouping fields. 
- Select fields is now Select output fields. 
 | Field count 
 | 
- The Data Preview screen includes a field count beyond the count of records. 
 Benefit to Users 
 | Streamlines the creation of derived variables while adding more customization options.
