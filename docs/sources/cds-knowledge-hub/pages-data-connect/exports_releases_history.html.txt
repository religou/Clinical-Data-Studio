# Exports Releases History

## Exports Releases History
 The following lists all releases for Data Connect's Exports capability before the June 2024 release, and the features or enhancements introduced in each.
 Important : As of the 2024.2.0 release, Extractor is a part of the Data Connect solution as its Exports capability. It is now "Data Connect - Exports" or "Exports". For details what the 2024.2.0 release entails, and following releases, see   Data Connect Releases History , 
 Code Continuity Across Releases
 All Extractor releases are cumulative. That is, each release or software update builds on the prior releases as noted in the release notes. For example,  Software Update 2023.2.1 includes all the release 2023.2.0  code, which in turn is based on the  release  2023.1.0 code, and so on. Any updates between releases or s oftware updates (urgent or otherwise) appear in the release notes.
