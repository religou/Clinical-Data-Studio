# Import Third-Party EDC Data

## Import Third-Party EDC Data
 You can automatically ingest third-party EDC data for any Non-Medidata study with SFTP, FTPS and, S3 locations. You can configure visits, sites, and patients metadata with Data Connect's Imports experience.
 Tip :  If you use Veeva EDC, you can use Data Connect’s Veeva Direct Connect capability. For details, see  Import with Veeva EDC Direct Connect .

## General Limitations
- While you can import multiple form types, Data Surveillance only supports forms with patients, sites, and visits. 
 Important : Data Connect does not support multiple sites per patient. You must tag a single site as the primary site in the source system to ensure patients reflect the latest site. If you do not update the source system, then patients associated to the most current site appear as unregistered values in Datasets. 
## Special Considerations
- When you update the dataset in your third-party EDC system, you must reactivate the dataset in Data Connect to propagate the changes in your downstream applications. For details, see Activate Datasets . 
- Data Connect automatically tags third-party EDC datasets as a Derived Dataset when it requires extensive transformations before being available for activation. 
- Data Connect shows a banner when your Rave studies have not been onboarded for compatibility with third-party EDC datasets. 
- All third-party EDC studies must be in their own client – that is, completely separate from the Medidata platform. This is because the system assumes the source of the metadata is Data Connect. For example, if you import sites from Data Connect and use Cloud Administration to update client division organizations (CDOs) and sites, then data inconsistencies can occur. 
## Prepare Metadata Datasets
 Before you can import third-party clinical data, you must import the following three metadata datasets:  
- Visits – Adds all planned visits within the study. 
- Sites – Adds all sites expected for the study. 
- Patients – Adds all patients and their associated primary site. 
 You can only configure each metadata dataset once. If necessary, you can edit the mapping after creation to resolve errors. After creating the data source, you can configure and import clinical datasets for an EDC source as necessary.  
 You do not need to import metadata datasets and clinical datasets in a specific order. However, you cannot activate clinical datasets for Data Surveillance until you also successfully import the associated metadata.

## Connect EDC to Data Connect
## Add Data Source
- Access Data Connect , and click   Imports   in the left-hand menu. 
- Click   Add data source . See  Add Data Source for details on how to configure a data source. Use this data source to import metadata. 
## Add Metadata
- On the Data source screen, click Add Metadata > Select the metadata from the list.
- Visits  
- Sites 
- Patients
 Note : These steps use Visit metadata type to define the workflow. The steps to create metadata datasets for the other two metadata type are the same.
- On the Add Visit Dataset screen, click Select source file , and select a file to map the dataset specifications. See Add Dataset for more information. 
- Click Select file.  You can preview the data for the selected file on the right side of the screen. 
- Use the data preview and map the source field to target fields.
 Tip : Data preview contains built-in validation to show errors.
- Click Continue. 
- Define Importing Criteria. For details, see  Add Dataset . 
- Click Add Visits Dataset > Start Import recurrence. 
 Tip : To import the dataset later, select Start Later .
- Repeat for the Sites and Patients metadata.
